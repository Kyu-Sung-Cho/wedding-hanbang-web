# Gowun Batang (invitation design titles, names, letters)

Subset of the static Google Fonts files ("Version 2.000") published in the npm package
`@expo-google-fonts/gowun-batang@0.4.1`.
Tarball SHA-256: d0ada627cecb81586b9b4333f46ea898ff7d5c5ae3c99fecedacc3bda2249193

License: SIL Open Font License 1.1, included as OFL.txt (copied from the package's LICENSE_FONT).
The name table, including the copyright and licence records, is kept unchanged. No reserved font name.

Built by `apps/mobile/scripts/subset-invitation-fonts.py`:
the 2,350 KS X 1001 Hangul syllables, Latin, punctuation, compatibility jamo and common symbols.
This is the display serif; a syllable outside KS X 1001 falls back to the platform font for that glyph
only. Every Korean string in `@hanbang/shared/invitation` is covered (`invitationFonts.test.mjs`).
Hinting, glyph names and vertical metrics are removed.
