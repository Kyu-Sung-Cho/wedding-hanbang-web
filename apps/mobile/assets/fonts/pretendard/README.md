# Pretendard v1.3.9

Unmodified official Pretendard font files from:
https://github.com/orioncactus/pretendard/releases/tag/v1.3.9

Downloaded archive:
https://github.com/orioncactus/pretendard/releases/download/v1.3.9/Pretendard-1.3.9.zip

License: SIL Open Font License 1.1, included as LICENSE.txt.
Copyright and reserved font names are preserved. No subsetting, renaming or modification.

Web uses web/variable/woff2/PretendardVariable.woff2 with font-weight 100 900
and font-display swap. Static public/static/alternative/Pretendard-Bold.ttf
is provided for Satori-generated share images, which do not accept WOFF2.
Native uses public/static/alternative/Pretendard-*.ttf for explicit weights.

These assets replace the actively loaded Paperlogy and scoped decorative font
families. Historical font assets remain for compatibility with cached older pages;
they are not the default typography.
