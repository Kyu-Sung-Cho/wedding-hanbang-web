# 웨딩한방 마스터 청사진 — 최종 통합본 (2026-06-10)

> 이 문서가 최상위. 오늘 나온 6개 분석(STRATEGY_REVIEW / COMMUNITY_KEY_CONCEPT / QUOTE_LEDGER / EONNI_OS / COMMUNITY_ENGINE / WINWINWIN_VERDICT)을 하나로 통합.
> 파운더 확정 결정 반영: ①AI 페르소나 위장 해체 ②계약-법률 서비스 금지 ③견적 등기소 보류 ④커뮤니티·친언니 우선 ⑤궁극 모델 = 업체 입점 윈윈윈(보증료 재정의).

## 1. 포지셔닝 — 한 문장

> **"웨딩의 '웨'자를 몰라도, 추가금에 안 당하고, 결혼식까지 — AI 친언니 아모라가 옆에서 다 챙겨주는 곳."**

- 적(敵) 하나: **추가금·정보 비대칭·막막함** (검증됨: 진짜 마진은 기본가가 아니라 추가금 평균 174만 = 기본금의 50%, 피해 57.8%가 위약금/계약해제, 가격공개 의무화 준수율 0%)
- 대체하는 것: **비동행 플래너(130~180만원)의 5기능** — 순서·리마인드·비교기준·시세판단·결정보조 — 의 무료화 (96.7%가 비동행 선호, 시장이 이미 이 방향)
- 슬로건 후보: "추가금이 안 무서운 결혼 준비" / "결혼 준비, 견적서대로 끝난 적이 없습니다"
- 절대 쓰지 않는 슬로건: "더 싸게" (다이렉트 카페가 선점, 볼륨 싸움에서 짐)

## 2. 제품 구조 — 3개 층, 하나의 플라이휠

```
┌─[1층: 유입] 커뮤니티·공개 콘텐츠 — "남들이 실제로 얼마 냈는지"─────────┐
│  시세 분포(조건 태깅)·예절 위키 25파트(비로그인 SEO)·오늘의 한 질문      │
│  give-to-get: 1탭 투표(입구) → 견적 제보(정밀층)                        │
└──────────────┬─────────────────────────────────────────────────────┘
               │ "내 상황은? 아모라에게 묻기" (본문+금액 주입)
┌─[2층: 관계] 아모라 + 라운지 — "친언니 OS" (12~18개월 리텐션 코어)──────┐
│  모멘트 루프: D-3 챙김 → D-1 대본 → D+1 안부 (상견례·투어·본식)          │
│  갈등 중재(작동 중)·결정 기억·주차 카드·견적→예산 자동 반영              │
│  추천의 순간: 전날 밤 먼저 온 대본 카드 → 스크린샷 공유                  │
└──────────────┬─────────────────────────────────────────────────────┘
               │ 견적 제보의 업체명 → vendor_leads (수요 증거 자동 축적)
┌─[3층: 거래] 업체 + 보증 — 윈윈윈 (S1~S3 통과 후에만)───────────────────┐
│  입점 명분: "법정 가격공개(준수율 0%) 대행 무료 도구"                    │
│  수익: 5% = 중개비가 아니라 보증료 (에스크로+추가금 사전확정·캡+차액보상) │
│  첫 카테고리: 혼수 단품(한복·예복·예물 — 워크인 우위, 채널충돌 최소)      │
│  중립 방화벽: 통계-입점 쿼리 절연, 단일 공개 수수료, 순위 무반영          │
└─────────────────────────────────────────────────────────────────────┘
플라이휠: 커뮤니티 데이터 → 아모라 정확도↑ → 수요 증거 → 업체 입점 → 공시가·보증 → 데이터 정확도↑ (반복)
```

## 3. 세팅 순서

### Phase 0 — 이번 주 (정리·기반, 전부 1인 가능)
| # | 작업 | 이유 |
|---|---|---|
| 1 | AI 페르소나 자동화 해체 → 공식(AI 표시) 계정 전환 | 법적 전제 (심사지침 2026-06 시행) |
| 2 | 죽은 코드 2종 부활: `AiCommentBox` 렌더+트리거 확장, `buildChatHref` 본문·cost_data 주입 | 유입 0명이어도 즉시 전환율↑ |
| 3 | 견적 스키마에 `booking_channel`·`quote_stage`·`contract_ym`·검증등급 추가 | 데이터 오염 방지 — 그로스보다 먼저 |
| 4 | 동기방 contracts API `select("*")` 익명성 구멍 수리 (집계만 반환) | 신뢰 전제 |
| 5 | 랜딩 허수("후기 120만+") 제거 → 실측 카운터, hiddenCosts 출처 연도 명기 | 표시광고 안전 + 자기 원칙 |

### Phase 1 — 30일 (친언니 + 깔때기 코어)
6. proactive 라우트 배선(GET 1줄) + 모멘트 D-3/D-1/D+1 (상견례·드레스투어·본식 우선)
7. 아모라 2질문 온보딩(상견례 날짜 확보 필수 — 모멘트 연료) + 대시보드 주차 카드 1장
8. "오늘의 한 질문" 1탭 투표 + give-to-get % 분포 + 표본<5 공개 시세 폴백
9. 견적 입력 → 라운지 `budget_items` 자동 반영 (커뮤니티→라운지 첫 데이터 파이프)
10. 운영자 핀 API + 큐레이션 주 5장
11. **D-1 브리핑 캡처-공유 카드** (성장 루프의 핵심 아티팩트)

### Phase 2 — 90일 (유입 + 공급)
12. 예절 25파트 + 시세 페이지 비로그인 공개 + SEO (유일한 유입구 개방)
13. 시세 봉투(가격 블러 + `quote_unlocks`) — 2단 게이트의 정밀층
14. 프로그래매틱 SEO 첫 50페이지 + 공유 카드
15. **S1: 업체 10곳 인터뷰(파운더 직접)** — "플랫폼 고객에게 도매가 줄 의향?" No 다수면 3층 보류
16. "가격공개 대행 무료 도구"로 업체 입점 시작 (과금 0) / 졸업 후기 / Resend D-1 이메일

### Phase 3 — 6개월+ (거래층, S1~S3 통과 시에만)
17. 혼수 단품 에스크로 + 추가금 보증 + 5% 보증료 (외부 PG 정산대행 구조)
18. 검증 프로필·옵트인 리드 (영구 원칙: 유료 순위·광고 금지)

## 4. 운영 세팅 (1인, 하루 1시간)
- 콘텐츠 20분(막막 질문 1개 플래너式 답변→핀) / 모더레이션 15분 / 큐레이션 15분 / 지식iN 답변 10분
- 단일 코호트(서울/경기 2026 가을본식)만 운영, 운영자 견적 30건 손입력(출처 표기)
- 첫 7일에 손노동 채널(지식iN·카페 정직글) 가입 전환율 실측 — 전체 모델의 생사 분기점

## 5. KPI (층별 하나씩)
- 1층: 주간 견적 제보/투표 건수, SEO 유입→가입 전환율
- 2층: **D-1 브리핑 받은 유저의 D+1 응답률** (북극성), 12주차 주1회 복귀율
- 3층: S1 인터뷰 Yes율(go/no-go), 이후 월 계약 건수
