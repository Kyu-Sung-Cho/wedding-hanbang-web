## 양방향 검증 보강

기존의 “추출 숫자 → source_quote” 검사는 유지했다. 반대 방향인 “원문 금액 발생 → 추출 행” 검사는 값 집합 비교에서 **발생 위치 비교**로 강화했다.

핵심 변경:

1. 같은 100만원이 서로 다른 두 행에 나오면 두 발생으로 센다. 한 행만 추출하면 나머지 한 행이 gap이다.
2. XLSX는 `시트!셀` locator를 유지한다.
3. 변환기가 같은 셀을 canonical 행과 Markdown 표에 두 번 표시해도 한 번만 센다.
4. 병합 헤더의 가격 열 범위를 확장한다.
5. `단위: 만원` 아래의 bare number를 KRW로 환산한다.
6. 벌·권·페이지·컷·시간·월·퍼센트·전화·사업자번호 같은 수량/식별자는 가격에서 제외한다.
7. `4~6월`, `9월~10월` 같은 기간 범위가 가격으로 떨어지는 회귀 테스트를 추가했다.

검증기 버전은 `v6-occurrence-money-coverage`, 추출 프롬프트는 `v6-occurrence-located-coverage`이다.

## 미검증 추출 프롬프트 v6

실제 코드에는 다음을 반영해 `v6-occurrence-located-coverage`로 올렸지만, API 추출 0건이므로 효과는 아직 검증되지 않았다.

1. XLSX source_quote에 `시트!셀` locator를 포함한다.
2. 같은 금액이 반복되어도 발생 위치별로 별도 추출한다.
3. 계약상 금액과 구매 상품 가격을 구분하고, 스키마에 안전한 위치가 없으면 상품 가격으로 가장하지 않는다.
4. 저해상도 이미지에서 금액·단위·조건 중 하나라도 불명확하면 추측하지 않고 `needs_review=true`와 정확한 위치를 남긴다.
5. 수량·기간·퍼센트는 가격으로 만들지 않는다.
