### A — 이 후보에 포함

- 안전: 본인의 발길질·손목 감금·가격·살해 협박과 새로 생긴 자해 생각을 유한한 긍정 사건 표현으로 판정. 인용·부정·가정·제3자·과거와 현재를 구분한다. 위험 단어만으로 모든 대화를 위기라고 처리하지 않는다.
- 장소: 다른 사람이 요청했다는 보고·따옴표 안의 요청·명시적인 추천 거절로 검색을 시작하지 않는다. 독립적인 현재 요청은 앞뒤 순서와 무관하게 유지하고, 보고된 지역을 현재 요청의 지역으로 빌리지 않는다.
- 공유 할 일 제안: 제품 목록의 명시적 제안을 기존 확인 카드에 연결한다. 미리보기만 요청한 턴에는 실행 도구를 허용하지 않는다. 모델의 표식으로 다른 항목·추가 조건을 조용히 채택하지 않는다. 이 변경은 동시 수정 DB CAS의 완료를 의미하지 않는다.
- 저장 메모: PATCH/DELETE는 사용자가 확인한 원래 메모를 필수로 비교한다. 비교값은 원래 공백까지 그대로 유지한다. 충돌하면 최신 저장본을 다시 읽고 별도로 확인한다. 삭제는 확인 창을 거쳐 저장본과 메모에만 적용한다.
- 미전송 초안: 같은 탭의 30분 텍스트 복구. 안전 상담·첨부·별도 전달 맥락은 보관하지 않는다. 본인·커플·역할·파트너 경계를 유지한다. 같은 인증 소유자의 준비 정보가 잠시 null이 된 경우에만 초안을 유지하며, 로그아웃·잘못된 커플 전환에는 늦은 writer가 삭제된 초안을 되살리지 못한다. 인증 응답의 binding fence는 유지한다.
- 초안 처리방침 보완: 보관 항목·임시 저장소·복구 제한·삭제 방법·자동 공유하지 않음을 실제 렌더 결과에서 검증한다. 30분은 복구 기한이며 백그라운드 물리적 파기 보장으로 표현하지 않는다. 실제 hook과 고지는 같은 TTL 상수를 사용한다. 기존 가입 동의 판은 임의로 변경하지 않고 2026-10-12 기술 안내를 명시했다.
- 요청 본문: 피드백·이미지 URL API에 실제 스트림 byte 상한을 적용한다. 피드백 한도 조회 실패를 0회 사용으로 간주하지 않는다.
- 이동 경로: 가격 페이지 로고는 공개 랜딩으로 연결한다. 숨겨진 커뮤니티로 대화에서 우회 진입하지 않는다.
