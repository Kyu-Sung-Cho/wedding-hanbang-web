- **S8 넘겨주기는 의도적으로 미구현**이다. 동의하지 않은 제2인에게 화면을 투여하는
  것이라 R4(독립 동의 커플 3쌍) 통과 뒤로 미뤘다.
- 리뷰 플래그 4항목(CP3·DS3·DS4·ES1)에 카드·회수문장이 없는 것도 **의도**다.
  판정 전에 카피 비용을 태우지 않고, 특히 DS3의 업체 서술을 우리 발화로 승격시키지 않는다.

## 8. 이 세션에서 배운 것 (반복하지 말 것)

변이 검증으로 **작성자 본인의 테스트 구멍을 7개** 잡았다(세션 중 4개 + 감사 3개).
전부 같은 종류다 — **검사하는 척하지만 실제로는 안 하는 단정**.

| 구멍 | 정체 |
|---|---|
| 막간 인접 검사 | `index < total - 1`이라 마지막 **직전**을 통과시킴 |
| 라벨 존재 검사 | `hidden` 속성을 붙여도 `querySelector`가 찾아 "있다"고 판정 |
| 후보 불변 | 화면이 주장하는 문장을 라벨 없는 상태에서만 확인 |
| 공허한 통과 2건 | 대상이 없어서 빈 배열·빈 문자열을 비교 |
| 오염 차단 | 이름은 「장면 제목도 없다」인데 제목을 미검사 |
| 회수 렌더 | 스냅샷이 자기참조라 콘텐츠 전면 소실을 못 잡음 |
| 응답 독립성 | 워크스루가 항상 첫 라디오만 눌러 escape 경로 미도달 |

**처방**: 새 가드는 반드시 변이로 확인한다. 그 단정을 **거짓으로 만드는 코드 변경**을
상상할 수 없으면 그 단정은 공허하다. 그리고 **자기 코드는 자기가 검증하면 같은 맹점이
남는다** — 독립 감사가 3개를 더 찾았다.
