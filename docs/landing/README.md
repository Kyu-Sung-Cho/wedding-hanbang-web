# 랜딩 정본 시안

`NotebookBest.html` 은 랜딩의 **시각 언어** 정본이다. 2026-08-29까지 이 파일은
저장소 밖(워크스페이스의 형제 디렉터리)에 있었다 — 코드 20곳이 그것을 근거로
인용하는데 **저장소 루트 기준으로는 존재하지 않는 경로**였고, 지워지면 근거가
사라지는 상태였다. 그래서 안으로 들여왔다.

## 시안과 다른 것이 있다 — 의도된 것이다

시안 대조 CI 는 **만들지 마라.** 아래는 전부 파운더 결정이라, 기계로 대조하면
결정을 되돌리라고 요구하는 검사가 된다.

- `#price` 전용 섹션 → `#now` 안의 카드 한 장으로 내림
- 베타 틀 제거(`/beta` 페이지·사전등록 폼)
- 두 사람 승인 폐지
- 업체 수(406·829·831) 제거 — 푸터의 출처 고지로 대체
