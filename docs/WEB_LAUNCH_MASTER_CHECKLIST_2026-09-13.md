## 마감 방식

1. **기존 근거 연결:** 이 표의 완료 행을 유지한다. 확인 필요 행은 과거 운영 결과에서 이미 닫힌 부분을 먼저 승계한다.

5. **단일 판정:** 각 행에 실행 일시·대상 커밋·근거·남은 한계를 갱신한다. 필요한 코드 변경만 정상 검증/배포하고, W01에 최종 후보를 갱신한다. 미완료 또는 설명되지 않은 확인 필요가 남으면 ‘정식 출시 준비 완료’라고 표시하지 않는다. 선택 기능 X01/X02는 필수 완료 수에 넣지 않는다.
