# 업체 확보 플레이북

최종 수정일: 2026-05-11

## 목표

웨딩한방은 처음부터 또 하나의 유료 업체 목록 플랫폼으로 시작하면 안 된다. 첫 공급 목표는 신뢰 가능한 업체 지식 그래프를 만드는 것이다.

- 공개 기본 업체 정보
- 사용자가 언급한 업체
- 견적/계약/후기 증빙
- 투명하게 등록한 파트너 업체

업체에게 던질 핵심 메시지는 "광고하시겠어요?"가 아니다.

> 예비부부들이 이미 견적과 계약 조건이 합리적인지 확인하고 있습니다. 초기 등록을 통해 귀사 정보가 정확하고 투명하게 보이도록 관리해 주세요.

## 공급 단계

1. 원천 리드
   - 출처: 네이버 로컬, 카카오 로컬, 구글 플레이스, 웨딩박람회, 인스타그램, 사용자 언급, 추천.
   - `vendor_leads`에 저장한다.
   - 아직 공개 파트너나 검증 업체로 보여주지 않는다.

2. 선별 리드
   - 분야, 지역, 연락처/웹사이트, 포트폴리오, 영업 신호가 어느 정도 확인된 업체.
   - 서울/경기 스튜디오, 드레스, 메이크업을 먼저 본다.

3. 연락 완료
   - 카카오톡 채널, 인스타그램 DM, 전화, 방문으로 연락한다.
   - `contacted_at`, `outreach_channel`, `next_follow_up_at`를 채운다.

4. 온보딩
   - 업체가 `/vendor/register`에서 등록을 시작한다.
   - 사업자 정보, 가격 범위, 포함/미포함 항목, 취소/환불 기준을 요청한다.

5. 검증 업체
   - 사업자 증빙을 확인한다.
   - 가격 규칙과 숨은 추가금 기준을 검토한다.
   - 이후 검증 프로필로 표시할 수 있다.

## 초기 100개 업체 계획

사용자 불안이 크고 수요가 자주 생기는 분야부터 집중한다.

- 스튜디오: 35개
- 드레스: 25개
- 메이크업: 25개
- 웨딩홀: 10개
- 본식스냅/영상/예물/기타: 5개

지역 순서:

- 서울 강남/서초/청담
- 서울 기타 주요 지역
- 경기 분당/판교/수원/안양
- 인천
- 부산/대구는 이후 확장

## 첫 공급 스프린트

공식 제휴를 기다리지 말고, 합법적인 공개 정보와 사용자 제공 신호로 첫 공급 그래프를 만든다.

1주차:
- 공식 로컬 검색 API와 수동 박람회/업체 카드 입력으로 원천 리드 150개를 만든다.
- 서울 강남, 서초, 청담 및 인접 지역의 스튜디오/드레스/메이크업 60개를 우선순위로 둔다.
- 모든 리드는 `raw` 상태로 시작한다. 아직 파트너나 검증 업체로 부르지 않는다.

2주차:
- 상위 40개 업체에 투명성 메시지로 연락한다.
- 요청 항목은 딱 세 가지로 줄인다: 현재 패키지 가격 범위, 포함/미포함 항목, 취소/환불 기준.
- 응답 업체는 `onboarding`으로 이동한다.

3주차:
- 익명화된 아모라 견적진단과 공공 `참가격` 데이터를 바탕으로 첫 "서울 스드메 견적진단 리포트"를 만든다.
- 이 리포트를 업체에게 다시 보내서 웨딩한방이 예비부부의 불안을 실제로 이해하고 있음을 보여준다.

4주차:
- 5~10개 업체를 검증 프로필로 전환한다.
- 베타 약속은 좁게 유지한다: 정확한 프로필, 투명한 가격 규칙, 유료 순위 없음.

## 리드 출처

1. 공개 로컬 검색 API
   - 키가 준비되면 공식 네이버/카카오/구글 API를 사용한다.
   - `source = naver_local | kakao_local | google_places`로 저장한다.
   - `source_place_id`로 중복을 제거한다.
   - 비공개 데이터나 로그인 뒤 데이터는 스크래핑하지 않는다.

2. 사용자 언급
   - 커뮤니티 글이나 견적 질문에 업체명이 나오면 `mention_count`를 올린다.
   - 3회 이상 언급되면 `shortlisted` 후보로 올린다.
   - 견적/계약 증빙이 있으면 `proof_count`를 올린다.

3. 아모라 견적진단
   - 로그인 사용자의 견적진단에서 `vendor_name`이 있으면 내부 업체 리드를 생성하거나 갱신한다.
   - `quote_price_manwon`, 빠진 항목 수, 위험 플래그는 익명 집계 전까지 비공개로 유지한다.
   - 특정 업체에 고위험 진단이 반복되면 공개 비난이 아니라 정보 정정 요청 톤으로 먼저 연락한다.

4. 사용자 추천
   - 초기 사용자에게 이렇게 요청한다: "상담받은 업체명을 알려주면 비슷한 예비부부에게 가격 기준을 만들 수 있어요."
   - 보상: 우선 견적진단, 뱃지, 베타 혜택.

5. 웨딩박람회
   - 처음에는 구매자 입장으로 방문한다.
   - 업체 카드와 상담자료를 모은다.
   - 무료 투명 프로필 등록을 제안한다.

## 업체 리드 점수화

매주 원천 리드를 점수화한다.

- +4점: 사용자가 3회 이상 언급
- +4점: 아모라 견적진단에 업체명이 입력됨
- +3점: 공식 웹사이트 또는 인스타그램 포트폴리오가 명확함
- +3점: 패키지/포함 항목 정보가 공개되어 있음
- +2점: 서울/경기 스튜디오, 드레스, 메이크업 분야
- +2점: 첫 연락에 응답함
- -4점: 사업자 정체성이 불명확함
- -5점: 심각한 견적진단 위험 신호가 반복되는데 정정 의지가 없음

선별 기준: 7점 이상.

## 업체에게 줄 가치

업체에게 바로 유용한 것을 제공해야 한다.

- 무료 검증 프로필
- 무료 가격/패키지 정리
- "예비부부가 계약 전 가장 많이 묻는 질문" 리포트
- 초기 파트너 뱃지
- 베타 기간 등록비 없음
- 유료 순위 보장 없음

수요가 실제로 생기기 전까지 확정 예약을 보장한다고 말하면 안 된다.

## 신뢰 원칙

- 유료 파트너십은 반드시 표시한다.
- AI 추천은 왜 추천했는지 설명해야 한다.
- 협찬 업체가 견적 공정성 진단을 덮어쓰면 안 된다.
- 미검증 업체는 기본 정보로만 다룬다.
- 검증 업체는 포함/미포함 항목과 취소 기준을 공개해야 한다.
