## 1. 착지 A/B + UTM 링크 세트

| 코드 | 착지 | 가설 |
|---|---|---|
| **A** | `/check` (비로그인 견적 체크) | "도구가 먼저" — 가입 없이 가치를 주면 신뢰→가입 |
| **B** | `/wedding` (홈 → 온보딩) | "아모라가 먼저" — AI 친언니 컨셉이 직접 끌리는가 |

복사해서 쓰는 링크 (질문/글마다 `utm_content` 번호만 올리기):

```
# 지식iN — A (견적 체크)
https://hanbang.ai/check?utm_source=naver_kin&utm_medium=answer&utm_campaign=g1_w1&utm_content=a01
# 지식iN — B (홈/온보딩)
https://hanbang.ai/wedding?utm_source=naver_kin&utm_medium=answer&utm_campaign=g1_w1&utm_content=b01

# 카페 — A
https://hanbang.ai/check?utm_source=naver_cafe&utm_medium=post&utm_campaign=g1_w1&utm_content=a01
# 카페 — B
https://hanbang.ai/wedding?utm_source=naver_cafe&utm_medium=post&utm_campaign=g1_w1&utm_content=b01
```

- `/check`는 UTM 쿼리를 보존한 채 견적 체크로 리다이렉트됨 (next.config 확인 완료).
- 단축 URL(bit.ly 등) 쓰지 말 것 — 네이버가 차단하는 경우 많고 UTM이 끊김.
- 같은 글에 A/B를 둘 다 넣지 말 것 (오염). 글 단위로 A 또는 B 하나만.

## 3. 글 초안

### 3-1. 지식iN 답변 템플릿 (A — 견적 체크)

> 질문에 **실제로 먼저 성실히 답하고**, 도구는 마지막 한 줄. 답변 자체로 완결돼야 함.

```
스드메 견적은 "총액"보다 "뭐가 빠져 있는지"를 먼저 보셔야 해요.
견적서에 안 적혀 있다가 나중에 붙는 게 보통 이런 것들입니다:

- 스튜디오: 원본비(20~50만), 수정 장수 추가
- 드레스: 피팅비(샵당 3~10만), 헬퍼비(회당 20~30만)
- 메이크업: 얼리스타트비(5~15만), 부모님 메이크업 별도

정부 2024년 결혼서비스 실태조사에서 스드메 기본금 평균 346만 대비 실제 지불이
520만 — 추가금만 평균 174만원으로 나왔어요. 그러니 지금 견적이 싸 보여도
"포함 내역 리스트"를 서면으로 받아두시는 게 제일 중요합니다.

계약 전에 업체에 확인할 질문을 체크리스트로 정리해둔 무료 페이지가 있어요.
제가 직접 만들고 있는 서비스라 참고로만: [링크]
로그인 없이 분야·지역 고르면 빠지기 쉬운 항목과 소비자원 평균가를 보여드립니다.
```

### 3-3. 카페 정보글 (A — 시세/체크리스트형)

제목 후보:

```
안녕하세요, 내년 결혼 준비하면서 이것저것 알아보고 있는 사람입니다.
(투명하게 밝히면: 결혼 준비 서비스를 만들고 있는 개발자이기도 합니다)

견적서 여러 개 비교하면서 알게 된 걸 정리해봤어요.

1) 총액보다 "포함 내역"이 먼저더라고요
   - 같은 330만원이어도 원본비·피팅비·헬퍼비 포함 여부로 실지출이 100만 이상 갈림
2) 한국소비자원 참가격 기준 평균가 (2026-05)
   - (시세 페이지에서 카테고리 2~3개 숫자 인용 + 출처 명기)
3) 계약 전에 물어보고 서면으로 받아둘 것

체크리스트로 정리해둔 페이지: [링크] (무료, 로그인 없음)
```

### 3-4. 지식iN 운영 수칙

- 답변 복붙 금지 — 질문마다 첫 문단은 그 질문 내용을 직접 받아서 다시 쓰기

- 채택·반응 없는 패턴 3일 지속 시 답변 카테고리 교체 (예: 스드메 → 예식장/상견례)

## 4. 측정 — PostHog 세팅 (10분)

1. **Insights → New funnel**:
   - A 퍼널: `$pageview` (URL contains `utm_campaign=g1_w1`, `utm_content` starts with `a`) → `quote_check_submitted`
   - B 퍼널: `$pageview` (utm_content starts with `b`) → `signup_started`
2. **Breakdown**: `utm_source`로 나눠 지식iN vs 카페 비교.
3. **매일 볼 숫자 3개**: 캠페인 유입 수 / A 전환율 / B 전환율.

G1 공식 (30일차): `전환 = (quote_check_submitted 또는 signup_started) ÷ 캠페인 유입 ≥ 3%`
7일차 중간 판독: 유입 자체가 0~한 자릿수면 전환율 무의미 → 채널(글이 노출 안 됨)이 문제, 글 수를 늘리거나 채널 교체.
