## 🎬 Segment 2 — Demo 1: 예산 인터뷰 (0:15–0:40)

### 사전 셋업
- 빈 채팅 (또는 초기 인사만 있는 상태)
- 데모 계정으로 로그인된 상태
- 결혼 날짜 / 지역 / 하객수 등 미입력 상태 (아니면 인터뷰가 "이미 알아요" 모드로 빠짐)

### 비주얼 + 입력

**(0:15–0:20)** 사용자 입력 (5초)
> 사용자 키 입력:
> ```
> 예산 5천만원으로 짜줘. 강남 컨벤션, 5월 토요일, 하객 200명, 야외에서 둘이 사진 찍는 게 가장 중요하고 예단·한복은 평균만 해도 돼
> ```

**(0:20–0:35)** 아모라 응답 (15초)
> 응답 흐름:
> 1. 인터뷰 요약 (2~3초): "정리: 5천만원 / 강남 컨벤션 / 5월 토 / 200명 / 스튜디오·스냅 1순위 / 예단·한복 양보"
> 2. 계산 근거 1줄 (2초): "스튜디오·스냅에 평균 +25%, 예단·한복은 -30%, 예비비 8% 분리해서 짜봤어요"
> 3. 카테고리별 배분 표 (8초) — 카메라가 표에 줌인:
>    | 카테고리 | 금액 | 비고 |
>    |---|---|---|
>    | 예식장 | 1,800만 | 평균 38% |
>    | 스튜디오 | 375만 | +25% 가중 |
>    | 본식 스냅 | 250만 | +25% 가중 |
>    | 신혼여행 | 850만 | 평균 |
>    | 혼수 | 360만 | 평균 |
>    | 예물 | 400만 | 평균 |
>    | 드레스·메이크업 | 400만 | 평균 |
>    | 예단 | 25만 | -30% (양보) |
>    | 한복 | 50만 | -30% (양보) |
>    | 청첩장·답례품 | 90만 | 평균 |
>    | **예비비** | **400만** | **8% (숨은비용 대비)** |
> 4. 마지막 멘트 (3초): "이대로 적용할까요? 아니면 조정할 곳 있으세요?"

**(0:35–0:40)** 사용자 확인 + 적용 (5초)
> 사용자 입력: "응 적용해줘"
> 아모라: "적용됐어요. 예산 페이지에서 항목별로 진행 상황 추적할 수 있어요."
> 비주얼: 예산 페이지로 짧게 컷 → 카테고리 진행률 0% 표시되는 컷

### 자막 강조 포인트
- 화면 상단 자막: **"한국 평균이 아니라, 우리 우선순위로"**
- 0:33쯤 표 위에 highlight 박스: "양보 카테고리 -30% / 1순위 +25% / 예비비 8%"

### 내레이션 (선택 — voiceover 있을 시)
> "예산 짜달라고 하면 한국 평균이 아니라, 이 커플의 우선순위로 짜요. 양보할 곳은 줄이고, 중요한 곳에 몰빵하고, 숨은비용 예비비까지 자동으로요."

## 🎬 Segment 3 — Demo 2: 커플 자동 중재 (0:40–1:05)

### 사전 셋업 (영상 촬영 전 필수)
1. **두 디바이스 준비** — 신부 계정 (좌) / 신랑 계정 (우) split screen
2. **커플 연동 완료** 상태
3. **최근 10분 내 mediation 메시지 없음** — 쿨다운 통과 위해 채팅 새 세션 또는 5분 대기 후 촬영
4. 양쪽 디바이스 같은 커플 채팅방 (shared 탭)

### 비주얼 + 입력 (split screen)

**(0:40–0:55)** 갈등 시퀀스 (15초, 메시지당 3~4초)

좌측 (신부) → 상대방에게:
```
호텔 가자
```

우측 (신랑) → 상대방에게:
```
비싸 진짜 답답해
```

좌측 (신부):
```
왜 맨날 너만 그래
```

우측 (신랑):
```
절대 안 돼
```

(메시지 점수 계산:
- "비싸 진짜 답답해": emotion 2점
- "왜 맨날 너만 그래": blame 4점
- "절대 안 돼": disagree 3점
- 양쪽 발화 ×1.5 → 13.5점, fight 미hit이지만 카테고리 3개+점수 ≥ 10 → 즉시 트리거)

**(0:55–1:05)** mediation 카드 자동 등장 (10초)
- 마지막 메시지 후 1~2초 silence
- 양쪽 화면 동시에 mediation 응답 메시지 등장 (Realtime 동기화)
- 화면 줌인하면서 **4 카드 시퀀스 등장** (각 카드 animation-delay 120ms):
  1. **공감** (노란색) — "둘 다 결혼 시작이 부담스러우신 거 알아요"
  2. **양쪽 입장 통역** (하늘색) — "신부님은 평생 한 번이라 후회 없게, 신랑님은 결혼 후 재정 안정이 걱정"
  3. **객관적 근거** (회색) — "한국소비자원 기준 서울 호텔 평균 5,500만원, 컨벤션 2,800만원. 평일 호텔 -15%"
  4. **합의안** (로즈) — "토요일 → 평일로 바꾸고 호텔 가는 안 + 컨벤션으로 가고 신혼여행 +500만원 안 — 둘 다 검토해보세요"

### 자막 강조 포인트
- 1:00쯤 mediation 카드 상단 자막: **"서버에서 자동 감지 — 양쪽 디바이스 동시 표시"**
- 1:03쯤: **"공감 → 통역 → 데이터 → 합의안"**

### 내레이션
> "둘이 의견 안 맞을 때, 아모라가 양쪽 입장을 통역해요. 누구 편도 들지 않고 객관적 근거로."
