## 중간 대안 (사업자 없이 가능)

- **문자(SMS)**: 솔라피는 개인 발신번호 등록 가능(본인 인증) — 사업자 없이도 시작 가능,
  템플릿 심사 없음. 건당 SMS ~9원. 원하면 알림톡 전 단계로 즉시 배선 가능.
- **모바일 푸시(Expo)**: 모바일 앱 출시 시 무료 — 잠금화면 알림으로 "카톡 느낌"에 가장 근접.

## 설계 원칙 (재개 시에도 유지할 것)

- 같은 셀은 어떤 채널로든 **평생 1회** (chat_messages 유니크 인덱스가 원장)
- 발송 전 채팅 선삽입 — 알림 클릭 시 대화방에 메시지가 기다리는 UX
- opt-out 1터치 + 동의는 시각으로 기록 / 실패 재시도 없음(스팸 방지)
