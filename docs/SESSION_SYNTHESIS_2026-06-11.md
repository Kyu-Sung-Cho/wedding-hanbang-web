## 3. 업체 계약은 실제로 어떻게 굴러가는가 (출처 검증)

**핵심: 돈은 "소비자→대행사"가 아니라 "업체→대행사" 방향이 본류.**

### 웨딩홀 (신부 ↔ 홀 직접 계약)
- 투어/상담 → 가계약 → 본계약(계약금) → 예식 3~4주 전 보증인원 확정 → 예식 직후 잔금. 중도금 단계는 표준에 없음.
- 계약금: 표준약관상 "예식비용 10% 이하"지만 **실무는 30만~400만원 제각각**(정액제 흔함). 계약일 15일 이내 청약철회 시 위약금 없이 전액 환급(2020 신설, 현행).
- 위약금(2025-12 개정 소비자분쟁해결기준): 150일 전 이전 = 계약금 전액 환급 → 이후 총비용의 10%→20%→40%→50%→70%(당일). [출처: 법제처 생활법령 easylaw.go.kr csmSeq=1894; 공정위 2025-12-18]
- 보증인원: 미달도 전액, 감액 사실상 불가, **2025년부터 "각보증"(신랑/신부 따로)** 확산 — 총원 채워도 한쪽 미달 시 추가 식대. [news1.kr/society/women-family/5900047]

### 스드메 (3경로: 대행 패키지 / 플랫폼 / 워크인)
- 대행 모델 계약 당사자 = "고객–대행업체". **비동행 플래너가 소비자에게 "무료"인 이유 = 수입이 업체 리베이트.** (96.7%가 비동행 이용)
- 실제 요율(경향신문 2019-06-23 내부문건, khan.co.kr/article/201906230859001): 웨딩홀 하객 1명당 2~3천원(플래너·컨설팅 5:5~6:4 배분), 스튜디오 결제액 20~30% 페이백, 예복 15%+VAT, **메이크업 워크인 정가가 컨설팅가의 2배**(33만 vs 77만) — 업체가 워크인을 비싸게 불러 컨설팅 경유를 사실상 강제.
- 추가금 적층: 기본금 평균 ~346만 위에 원본비 20~50만, 헬퍼비 회당 20~30만, 얼리스타트 5~15만, 피팅비 샵당 3~10만. 공정위 2024-11 실태조사(500명): **계획 대비 평균 144만 추가, 28%는 200만+, 74.2% "부적절"**, 추가금 경험률 87.8%. [dailian.co.kr/news/view/1428081, economist.co.kr]

### 규제 타임라인 (빠르게 강화 중)
2024-11 불공정약관 18개사 시정(원본비·피팅비·얼리스타트비 기본 포함) → 2025-04-03 결혼준비대행업 **표준계약서**(권고, 강제력 없음; korea.kr 156682367) → 2025-11-12 **가격·위약금·환급기준 표시 의무화**(과태료 최대 1억) → 2026-03 결혼서비스법 상임위 통과(신고제·보증보험).
- **가격공시 준수율 처참**: 시행 4개월 후 전국 예식장 753곳 중 17곳, 대행 3곳만 공개. 계도종료(2026-05-12) 1개월 후 과태료 부과 보도 0건 → **명분은 실재하나 업체 절박함은 아직 낮음("옵션")**.

## 4. 수수료·슈퍼앱, 정말 가능한가 — 검증된 판정

**가능하다. 단 조건·순서가 정해져 있고, "수수료가 주 엔진"은 데이터가 반박한다.**

1. **웨딩 중개수수료 단독은 천장 낮고 적자가 디폴트.** 아이웨딩 웨딩사업 정점 2018년 117억 → 최근 45~48억·영업적자. 792억 매출·코스닥 상장은 자회사 화장품(롬앤, 전체 98%)이 만든 것. 웨딩북 158억 투자·10년 적자. **순수 플랫폼 영업흑자 0건.**
2. **돈 번 유일한 형태 = "트래픽 자산→수익".** 다이렉트결혼준비(730억·121명)는 "카페가 커져서 업체 붙인 것"이 아니라 **기존 사업자가 카페를 영업채널로 만든 역방향**. 포인트 제도로 바이럴 설계. 즉 "중립 플랫폼"이 아니라 "트래픽 쥔 대행사".
3. **수수료를 받는 순간 유일한 무기와 충돌.** 우리 포지션="업체 돈 안 받아 신부 편". Layer 3가 이를 깎음. + 2019년 웨딩북 가격공개에 대형 컨설팅사 거래중단 압박(공정위 신고) = **채널 보복은 기록된 사실**.

### 가능한 수수료 모델의 정확한 형태
- **순위를 팔지 마라. 신뢰를 팔아라.** 화해 "앰블럼"(신뢰마크 라이선스비) 모델이 정답에 가장 가까움. **강남언니 판례: 성사 수수료=의료법 위반 유죄, 광고비=합법.** 웨딩은 알선금지 없어 수수료 자체는 합법이나, 판례는 "건당 중개비"보다 "정액 노출/검증 라이선스"가 안전함을 시사.
- 검증된 공급자 과금: 오늘의집 시공(성사수수료 0%, 정액광고 월 20~80만), 캐치테이블(건당수수료 없는 월구독 3.3~9.9만), 화해(앰블럼+커머스). **전부 "건당 중개비"가 아님.**
- 진짜 5% 수수료를 받게 된다면 "중개비"가 아니라 **"추가금 사전확정·캡 + 차액보상 보증"의 보험료**. 결제는 **외부 PG 정산대행**(직접 정산 시 PG 등록 자본금 3억+형사처벌). 첫 카테고리 **혼수 단품(한복·예복·예물)** — 채널 충돌 최소.

### 슈퍼앱 비전 (사장님 목표: "생각하는 시점부터 본식까지 전부")
끝 그림은 슈퍼앱이 맞고 충분히 클 수 있다. **그러나 순서를 어기면 죽는다.** 성공 사례 전부 하나를 먼저 깊게 파서 트래픽을 만든 뒤 거래로 확장: 화해(성분DB 3년 무수익), 오늘의집(콘텐츠 2년, 커머스 첫 주 매출 0), 강남언니(후기·가격 먼저, 7개월 첫매출 200만). 동시에 다 하려는 게 4/10을 만든 "1인 수퍼앱 함정". → **비전은 슈퍼앱, 실행은 좁게, 확장은 게이트 통과로.**

## 5. 업체 0 → 첫 수수료 0→1 계단

**원칙: 각 단계는 공급자에게 과금하지 않고, 다음 단계 조건을 증명할 때만 올라간다.**

- **Phase A — 업체 0명, 소비자만 (지금~3개월).** 업체 한 곳도 불필요. 파는 것=정보: 시세 공개(marketPrices 14×11) + 예절 위키(etiquetteData 26챕터) + 견적 진단(quoteCheck) **로그인 없이 공개** → SEO. 화해 "성분DB 3년"에 해당. 데이터는 운영자 손 시드(다이렉트 포인트 모객의 **중립 버전** — 우리는 업체 돈 안 받아 "제보 중위값"을 정직하게). 아모라로 리텐션. 지식iN·카페 실명 답변으로 첫 유입. **게이트 G1**.
- **Phase B — 업체 자기등록, 무과금.** 명분="법정 가격공개(준수율 753중 17) 대행 무료 도구". 업체가 자기 가격 입력 → 우리는 무료 트래픽 제공(오늘의집 아웃링크 방식). 보이콧 트리거 안 건드리고 공급 재고 축적. B2B 포털 코드 부활. ※단 업체 절박함은 아직 낮음 → 공정위 단속 시작 시 명분 급강화되는 "옵션", 무리한 영업 금지.
- **Phase C — 첫 수익, 수수료 아님.** 소비자 단건 결제(진단 리포트) 또는 화해식 검증 배지/옵트인 리드. 순위 절대 안 팜. 2,000만 계약 앞 1.5만원 지불이 곧 PMF.
- **Phase D — 진짜 수수료, S1 통과 시에만.** 에스크로+추가금 보증+5%(보증료), 혼수 단품부터, 외부 PG. 변곡점은 실재: 웨딩의여신 8개월 만에 강남홀 **먼저** 문의, 캐치테이블 월 200건 인바운드. **트래픽이 임계점 넘으면 업체가 먼저 온다.**
