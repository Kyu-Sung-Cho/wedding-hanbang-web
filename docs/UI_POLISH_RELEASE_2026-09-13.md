## 검증 증거

- UI 분리본의 네이티브 관련 7파일 89개 회귀 통과.
- 저장소 검사: ingest 858 통과 / 4 건너뜀, repository 754 통과 / 0 실패.
  건너뜀에는 로컬 원본 자료 부재와 Windows 파일 심볼릭 링크 권한 검사가 있다.
- `tokens:check`, `git diff --check`, 기존 DB 정적 릴리스 fence 통과.
  정적 fence는 운영 DB 실행·배포 인가 증거가 아니다.
- 웹 production build 성공: 정적 페이지 1,220개, 연구 경로 artifact 검사
  2,881개 파일 통과. 실계정 로그인/쓰기 검증과는 구분한다.
- 브라우저에서 실제 React 소스 + 실제 CSS + 합성 계정 상태로 6개 화면을
  320/390/768/1280px에서 확인했다. 24개 조합 모두 문서 가로 넘침 없음,
  Pretendard 로드 성공. 보드의 작은 화면은 기존 접기 동작을 유지한다.
- 320px의 긴 잔액 `3,477.777만원`이 잘리지 않고 표시됨을 확인했다.
- 운영 시험 계정에서 체크리스트 질문 링크가 자동 전송 없이 입력창에
  질문 한 줄만 채우는 것을 확인했다. 이 확인은 기준 배포에서 수행했다.
- 독립 검수에서 공개 Avatar 17개 호출의 props/크기, 공개·개인 경계,
  요약 계산·수정·취소·링크 유지 여부를 확인했다.

로컬 상세 증거는 Codex의 `visualizations/ui-release-20260913`,
`feature-summary-20260912`, `profile-avatar-20260913`에 보관한다.
시험 계정 화면·로그는 저장소에 포함하지 않는다.
전체 Turbo 검사, GitHub 검사, 실제 배포와 배포 후 확인 결과는 완료 후 덧붙인다.

## 별도 보존 작업: 개인 아바타와 확정 역할

`codex/amora-chat-colors-20260912` 작업에는 개인 아바타 편집/API/저장소,
명시적 `confirmed_role` 선택/API, 두 사람 말풍선 색 연결을 보존했다.
기존 `profiles.role`과 커플 슬롯은 가입 순서인 경우가 있어 색상 근거로 쓰지 않는다.

운영에는 새 테이블과 private bucket이 아직 없다. Hosted Storage 객체 정책은
현재 SQL 역할이 소유하지 않아 플랫폼 소유자 경로의 정책 적용이 필요하다.
새 정적 계약·사전/사후 조건·복구 계획과 격리 DB 검사는 준비했지만,
전체 DB/Auth/Storage 원본 복원 검증을 실행·증명하는 경로는 아직 미완료다.
`AGENTS.md`의 운영 DB·Storage 규칙과 `PRINCIPLES.md` P6에 따라 이 경계는
통과로 처리하지 않았다. 이번 UI 배포에는 관련 편집 버튼이나 API를 노출하지 않는다.
