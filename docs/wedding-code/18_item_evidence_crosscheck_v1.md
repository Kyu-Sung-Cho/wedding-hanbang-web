# WeddingCode 문항×증거 크로스체크 v1 (2026-07-05)

> 질문: "모든 문항이 검증됐고 신뢰도 높은 출처를 토대로 했는가?"
> 정직한 답을 층위로 나눈다. "검증"은 한 단어가 아니라 4개의 다른 것이다.

## 0. 검증 4층위 — 현재 상태

| 층위 | 무엇을 검증 | 상태 | 근거 |
|---|---|---|---|
| L1 시나리오 사실성 | 문항 속 상황·비용 항목이 실재하는가 | **✅ 비용·계약 계열은 A급 검증** / 관계 계열은 도메인 해석 | 실태조사 2024(A급)+참가격(A급) 기반 `hiddenCosts.ts` 44항목 — 제품 라이브에서 출처 표기 중 |
| L2 구성개념 근거 | 12개 구인이 문헌·데이터에 뿌리 있는가 | **⚠️ 부분** — A급 실정독 2건 확보(02a·02b), 커플역학 문헌(DYADIC_COPING 등)은 미정독 = hypothesis | `02a`, `02b`, `01 v0.2` |
| L3 문항 사전 품질 | 낙인·편향·모호성 사전 제거 | ✅ 완료 (합성 페르소나 10종 + AI 레드팀: High 0, 삭제 0) | `12`, `14` — 단 둘 다 **pre-human** |
| L4 심리측정 검증 | 신뢰도(α)·구인타당도 | **❌ 0 — 그리고 이 단계에선 0이 정상** | 신뢰도는 구인당 3~4문항×수백 명 응답 필요(Phase 5). 현 16문항(구인당 1.3)으로 신뢰도를 주장하는 순간 그게 사이비다 |

**결론: "모든 문항이 검증됐다"고 말하면 거짓말이고, "모든 문항이 검증 가능한 상태로
준비됐고 사실 진술은 A급에 뿌리를 뒀다"가 정확하다.** 남은 검증(L3의 human 확인,
L4)은 문서를 더 써서 얻을 수 없고 오직 사람 응답으로만 얻는다 — 그래서 드라이런이 다음 수다.

## 3. "이게 최선인가"에 대한 답

드라이런 직전 단계 기준으로 **문서·사전검증으로 얻을 수 있는 것은 사실상 소진했다.**
여기서 더 좋아지는 유일한 경로는 사람 응답이다:

1. 내부 완주 → 지인 5 → 20명 미니 (17번 킷)
2. Ⓘ 5문항의 공감/어색 피드백 집중 판독
3. 20명 통과 시 전문가 리뷰 발송(01 v0.2 + 02a/02b 동봉) — 그때 커플역학 문헌 보강
4. L4(신뢰도)는 Phase 5 전 시도 금지 — 구인당 3~4문항 확장판이 선행 조건
