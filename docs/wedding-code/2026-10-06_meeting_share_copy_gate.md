# 미팅 후 공유 표현 검수

## 초안과 대안

- 현재 `내 답과 함께 보내기` / `질문만 보내기`는 포함 내용을 말하지만 첫 선택의 목적과 마지막 버튼이 구별되지 않는다.
- `파트너에게 내 결과 보내기`는 상대가 답하기 전에 결과를 읽는 것으로 오해할 수 있어 제외했다.
- `파트너와 비교하기` / `테스트 질문만 보내기`를 선택지로, `파트너 초대 링크 보내기` / `질문 링크 보내기`를 각각의 실행 문구로 쓴다. 비교 선택에는 내 답이 포함된다는 안내를 명시한다.

## 적대적 검수

- 질문만 보낼 때 두 사람 비교가 만들어진다고 말하지 않는다. 내 답 포함 동의와 민감한 답의 공개 범위는 비교 선택에만 유지한다.
- 번호가 붙은 절차는 순서 안내다. 체크, 완료 색, 현재 단계나 수신 상태는 표시하지 않는다.
- 공유 창에 넘김, 복사 성공, 취소와 상대 수신 완료는 서로 다르다. 기존 실제 관찰 범위의 상태 문구를 유지한다.
- 상대가 답을 마친 뒤 결과 링크를 다시 보내야 원래 초대한 사람도 비교를 볼 수 있다는 안내를 유지한다.

## 주장 감사 및 최종 gate

E: 현재 공유는 로그인 없는 링크 방식이며, 수신 여부나 자동 결과 반환을 확인하는 기능이 없다. 제안된 이름은 현재 동작을 설명하는 범위다.

I: 행동별 이름과 순서를 분리하면 용도를 읽기 쉬울 것으로 기대한다. 실제 사용자 이해도 개선은 아직 확인하지 않았다.

작성 gate: 위 범위로 코드에 반영 가능. 체크 전 전송 차단, 답 없는 URL 분기, 선택별 실행 이름과 순서를 관련 테스트로 확인한다.
