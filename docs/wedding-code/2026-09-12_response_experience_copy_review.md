# 장면 경험과 현재 희망을 구별하는 응답 설명 — 2026-09-12

상태: 공개 v0.8 20장면의 로컬 수정 및 회귀 검증. 운영 배포·사람 타당도 검증 완료를 뜻하지 않는다. 문서 31은 RETIRED이며 현재 README의 공개 응답 요약 계약을 적용한다.

## 문제와 선택한 범위

D4-D는 할인 때문에 즉석에서 계약할 뻔한 경험이다. 기존 H/A 집계에서는 A에 들어가지만 이를 ‘먼저 할 일을 정하는 답’이라고 설명하면 실제 선택에 없는 정리 행동을 만들어 낸다. D1-B의 말하기 중단, D3-D의 곁에 있기, A3-B의 다른 사람 선택 의식, A4-C의 성의 있는 응대에 대한 안도도 기존 행동·취향 라벨만으로는 정확하게 설명되지 않는다.

검토한 대안:

1. 선택지나 가중치를 바꾸거나 해당 답을 집계에서 제외한다. 기존 공유 응답의 해석과 부분·동점 결과가 바뀌므로 이번 보완에서 제외했다.
2. 모든 `candid` 답에 경고를 붙이거나 결과를 감춘다. 솔직한 답이라는 이유만으로 경고할 근거가 없고 정상적으로 요약 가능한 경험까지 숨기므로 제외했다.
3. 답의 집계와 인용은 그대로 두고 결과 설명을 실제로 다룬 주제로 한정한다. 주제만으로 빠질 수 있는 경험은 그 원문을 선택했을 때만 별도 안내한다. 이 안을 적용했다.

M의 출력 설명은 ‘사진·분위기와 기대·인상’, H는 ‘마음과 대화’, A는 ‘할 일과 결정’에 관한 답이다. 마음을 들었거나 할 일을 정리했다는 행동 인증과 지금 원하는 도움으로 바꾸지 않는다. 제목·글자 뜻·반복 확인 문구·양쪽 답 수·부재 문구를 함께 맞췄다. 네 글자만 받은 코드 해설도 같은 한계를 유지한다. 미응답 선택의 부재를 실제 준비에서 확인을 생략한 행동으로 말하지 않는다.

`selfProfile`은 표시 인용 두 개로 줄이기 전의 실제 선택 원문 전체를 확인한다. A3-B/A4-C/B5-A/D1-B/D3-D/D4-D에만 원문별 안내를 붙이며, 해당 답을 고르지 않은 사람에게 그 경험을 지어내지 않는다. B5 연락 지연의 기존 안내도 이 공통 경로로 보존했다. 문항 번호가 같아도 이전 버전에서 다른 문장을 고른 경우에는 해당 경험 안내를 적용하지 않는다.

| D4-D | 즉석 계약을 할 뻔한 경험 | A 주제 설명과 선택 원문 한정 안내. |
