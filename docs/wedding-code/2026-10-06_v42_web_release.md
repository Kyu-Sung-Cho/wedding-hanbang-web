- 공유 선택을 ‘파트너와 비교하기’와 ‘테스트 질문만 보내기’로 구분한다. 실제 실행 버튼은 각각 ‘파트너 초대 링크 보내기’와 ‘질문 링크 보내기’다. 로그인 없는 초대 → 상대 응답 → 상대가 두 사람 결과 링크를 다시 보내는 절차를 보이며 자동 도착이나 전송 완료를 꾸미지 않는다.
- Lazyweb 개선 리포트는 합성 응답 화면 캡처를 보내 요청했지만 서버 합성 시간 초과로 종료됐다. 리포트 결과를 받았다고 주장하지 않는다. 승인된 DESIGN과 실제 화면을 기준으로 검수한다.

작성·적대적 검수·주장 감사는 [v4.3 문항 gate](./2026-10-06_v43_meeting_item_audit.md), [미팅 대응 계약](./2026-10-06_v43_meeting_completion.md), [공유 문안 gate](./2026-10-06_meeting_share_copy_gate.md)에 기록한다. 커플 관련 94개 검사와 새 판 원응답·화면 판 일치 및 불일치 거절 검사는 로컬에서 통과했다. 신규 검사 20개에 기존 및 v4.3 판 혼합 오류를 넣은 증명이 모두 성공했고 제품 대상 22개의 원본 SHA-256 복원을 확인했다. 전체 타입·린트·웹·저장소 검사와 새 SHA의 CI·Preview·화면 검수는 최종 실행 후 PR 본문에 영수증을 갱신한다. 이전 v4.2 전체 검사 성공을 v4.3 성공으로 복사하지 않는다. 첫 v4.3 CI 분할 검사에서 옛 기본판을 기대한 entry.test와 entry.v40.test의 AssertionError 5건을 확인해 기본·유입·재시작 기대만 v4.3으로 동기화했다. 명시 구판·fragment·invalid 검사는 유지했으며 해당 2파일 35검사가 통과했다. 제품 구현은 바뀌지 않았다. 진행 중이던 첫 전체 로컬 검사는 알려진 실패가 있어 중단하고 최종 검사 파일로 전체 관문을 다시 실행한다. 중단한 실행을 성공으로 기록하지 않는다.

## 승인과 범위
