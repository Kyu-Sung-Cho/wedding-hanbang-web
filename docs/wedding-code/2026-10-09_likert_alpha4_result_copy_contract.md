# Likert alpha.4 결과 표현 계약

상태: 구현 후보 / 사람 검증 0명. 보호 기준 alpha.3의 commit은 `09227b60b337c05cf4ae62b6538af7bdab8d9ba1`이다. 이 문서는 운영 배포 완료 증명이 아니다.

## 후보 비교와 선택

1. 질문을 비유로 꼬거나 새 잠재 성향을 추가하면 질문의 뜻과 범위가 바뀐다. 이번 범위에서 제외한다.
2. 기존 질문을 유지하고 실제 장면별 답의 차이·자기 확인·짧은 부탁을 선명하게 보완한다. **선택했다.**
3. 새 궁합·관계·능력 점수는 근거가 없으며 이번 범위에서 제외한다.

문항은 30개·12장면이다. text/context·문항/장면 ID·은행 배열 순서·5점 라벨·대표 글자/비율 계산·16캐릭터 대응을 유지한다. 문항 전수 감사에서 지출의 ‘우선 배정’·음식 제공 연출·가족 문항의 규범 동의·도움 질문의 반복을 오해 가능성으로 기록했다. 새로운 질문 문안은 새 ID·은행 revision과 구판 reader를 갖춘 별도 후보로 다루며 기존 답을 조용히 재해석하지 않는다.

## 결과 표현

- 주제별 두 줄을 ‘실제 장면의 답’과 ‘나에게 한 질문’으로 제공한다. 비교 가능한 전체 문항 답의 칸이 다른 장면을 대조한다. 같은 답의 이유까지 같다고 단정하지 않는다.
- 도움 영역은 L/A와 함께·혼자 쉬기의 원답을 모두 읽는다. 같은 CJOL·같은 비율에서도 장소별 도움과 쉬기 응답이 다르면 실제 원답으로 다른 관찰을 만든다.
- 수치 답이 없는 경우 별도 응답 상태 수를 표시한다. 부분 답은 수치가 있는 장면을 먼저 읽고 비교하지 않은 범위를 함께 알린다. 모름·비해당·건너뜀·미응답과 보통(3)을 섞지 않는다.
- 1·2로만 답한 경우 제시된 행동 외에 원하는 방법을 질문한다. 도움이 필요 없거나 돈에 관심 없다고 단정하지 않는다. 3만 남긴 경우 보통에 담은 뜻을 질문한다.
- 양쪽 높은 답과 낮은 답, 대표 글자와 독립 비율을 유지한다. 동의 비율을 강도·정확도·신뢰도·궁합·인구 비율로 표현하지 않는다.
- 부탁에는 실제 4·5로 동의한 행동만 담는다. 돈/가족/도움 요청의 문장을 짧게 정리한다. T는 합의 기준·한 사람의 초기 후보 공유 방식 수용이며 수행자는 따로 정한다. L은 내 이야기 전체를 듣는 도움이다. 혼자 쉬기를 관계 회피로 읽거나 여러 도움의 순서를 자동 지정하지 않는다.
- 캐릭터는 이번 답에 붙인 놀이 이름이다. 원답보다 사람의 성격·능력·숨은 이유를 말하는 서사는 만들지 않는다. 반복된 근거는 details로 펼쳐 읽되 질문·원답을 제거하지 않는다.

## 호환

측정 `likert-preferences-alpha.1`, 은행 `preferences-20261008-r2`, 현재 표현 `likert-letters-alpha.4`.

같은 측정·은행의 alpha.1/2/3/4만 명시 허용한다. alpha.1에는 기존 T/L 교정, alpha.2에는 기존 L/장면 설명 교정을 알린다. alpha.3에는 문항·원답·비율·대표 글자 계산 유지와 이번 문안/장면 설명 보완만 알린다. current4에는 교정 안내가 없다. 이전 저장 원본·날짜·cursor·사람 순서·원답을 읽기만으로 갱신하지 않는다. 미래5·다른 측정판·다른 은행은 계속 거절한다.

## 반례와 검증 경계

동일 CJOL의 세 장면 경청과 업체 연락 뒤 정리+혼자 쉬기, 같은 코드·같은 비율의 다른 지출 장면, L/A가 같고 휴식만 다른 답, 전부5/1/2/3, 유효 수치0, 첫 장면 빈값·뒤 장면 부분 답, T 수용과 수행자 분리, 두 쉬기 모두 높음, 구 alpha.3 초대/커플/저장 원본 불변을 검사한다.

구현 담당과 독립 카피/계약/계산 검수 담당을 분리한다. 초안 → 적대적 검수 → 주장 감사 → 수정 순서로 닫는다. 단위·타입·lint·빌드·CI·실제 화면 성공은 해당 수정본의 로그와 해시에 고정한다. 이전 alpha.3 통과를 새 표현판의 통과로 옮기지 않는다.

‘더 깊고 재미있게 읽힘’은 제품 목표이며 사람 대상으로 확인한 성과가 아니다. 전문가·인지면접·사용자 타당성 검증은 0명이다. 실제 hosted 외부 SDK outgoing 본문·375px 검증의 Playwright 기술 예외는 사용자 응답 대기다. 운영 배포·운영 QA는 그 관문 통과 전까지 미완료다. 과거 공유 환경의 50개 패키지 연결 복구는 수행하지 않았다.
