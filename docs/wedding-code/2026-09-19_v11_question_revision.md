## 문항을 고르는 판단

검토한 방향은 기존 문장에 안내만 더하기, 말투만 바꾸기, 비교하는 행동부터 맞춘 뒤 문장을 고치기다. 이미 가정 응답·가장 가까운 하나·한정 설명이 있으므로 세 번째를 택했다. 보기의 뜻이 겹치면 해요체로 바꿔도 문제는 남는다.

- 한 문항은 하나의 순간과 하나의 선택을 다룬다. ‘어떻게 했어요?’로 미경험자에게 실제 행동을 요구하지 않고 ‘나라면’의 가정 응답으로 맞춘다.
- 각 답이 돈·시간·지식의 서로 다른 제약을 떠안지 않게 한다. 함께 정하는 답에만 마감 위반이나 회의 중단을 강요하지 않는다.
- 두 답을 연달아 할 수 있더라도 질문에서 지금 고르는 순간이 분명해야 한다. 같은 뜻을 문장만 바꾼 보기는 다시 쓴다.
- 한쪽을 성숙한 사람, 다른 쪽을 무능하거나 무례한 사람처럼 만들지 않는다. 기존 candid 표식 개수를 맞추기 위해 흠을 끼워 넣지 않는다.
- 짧은 말만으로 맥락이 부족하면 장면을 보충한다. 글자 수를 줄이려고 주체·대상·시간을 생략하지 않는다.
- 결과는 실제로 고른 문장을 근거로 삼는다. 확인하자고 한 답을 확인 완료로, 피곤하다는 말을 정서적 능력으로 바꾸지 않는다.
