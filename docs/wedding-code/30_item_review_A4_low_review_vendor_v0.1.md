# WeddingCode A4 Item Review — 포트폴리오는 좋은데 후기가 적음

작성일: 2026-07-07  
상태: v0.5 문항 후보 확정 전 심층 리뷰  
대상: A축 `결정 기준` 4번 문항, 기존 q15

---

## 0. 결론

A4는 유지한다. 이 문항은 웨딩 준비에서 매우 현실적인 갈림이다. 포트폴리오는 마음에 드는데 실제 이용 후기가 적으면, 사용자는 취향 적합과 검증 가능성 사이에서 흔들린다.

다만 현재 문장인 "사진은 딱 마음에 드는데"는 조금 가볍고, "후기가 많은 곳도 찾아본다"는 선택지가 너무 안전한 정답처럼 보일 수 있다.

v0.5에서는 아래처럼 바꾼다.

> 스튜디오 포트폴리오는 우리 취향인데, 실제 이용 후기가 많지 않아요. 나는 먼저 -

- A. 최근 실제 촬영본과 포함 조건을 더 확인한다
- B. 우리가 원하는 색감·분위기와 얼마나 맞는지 다시 본다
- C. 비슷한 무드에 후기가 더 있는 곳도 같이 본다
- D. 후기 부족을 어디까지 감수할지 둘이 기준을 정한다

이 문항은 "후기 없는 곳은 위험하다"를 말하는 문항이 아니다.  
정확한 측정 의도는 **취향이 맞는 선택 앞에서 근거 확인, 무드 확신, 대안 탐색, 커플 기준 중 무엇을 먼저 잡는가**다.

---

## 1. 이 문항이 필요한 이유

A4는 A축의 마지막 문항으로 좋다. A1~A3가 비용과 큰 결정을 다뤘다면, A4는 취향과 근거 사이의 갈림을 다룬다.

웨딩 준비에서 후기는 매우 중요하지만, 후기만으로 결정할 수 없는 경우가 많다.

- 신규 스튜디오라 후기가 적다.
- 포트폴리오는 예쁜데 실제 촬영본이 적다.
- 후기는 많은데 우리 취향과 다르다.
- 블로그·인스타 후기가 광고인지 실제 경험인지 애매하다.
- 최근 후기와 예전 후기가 다르다.
- 포함 조건, 원본, 보정, 작가 지정 여부가 후기에 충분히 드러나지 않는다.

제품적으로 A4는 커뮤니티, 업체 페이지, 견적 체크, 아모라 질문 문구와 직접 연결된다. 사용자가 결과를 보고 바로 "그럼 이 업체에는 뭘 물어봐야 하지?"로 이어질 수 있다.

---

## 2. 근거 레이어

### 2.1 제품/시장 근거

웨딩 업체 선택은 포트폴리오와 후기, 견적 조건을 함께 봐야 하는 고관여 결정이다.

웨딩한방 제품 안에서도 A4는 이미 여러 자산과 연결되어 있다.

- 커뮤니티 후기와 빠른 후기 작성
- 업체 페이지의 후기 수·평점
- 견적 체크의 포함/별도 항목
- 아모라의 업체 질문 문구 생성
- 원본·보정본·작가 지정·촬영 조건 체크

따라서 A4는 "성향 테스트용 가짜 상황"이 아니라 제품 핵심 흐름으로 이어지는 문항이다.

### 2.2 온라인 리뷰/eWOM 근거

온라인 리뷰와 전자적 구전(eWOM)은 소비자 구매 의사결정과 신뢰 형성에 영향을 준다는 연구가 많다. 최근 메타분석도 온라인 리뷰의 평점/내용/형식 등이 구매의도와 관련됨을 보고한다.

다만 이 근거를 단순하게 쓰면 안 된다.

- 후기가 많다는 것만으로 품질이 보장되지는 않는다.
- 후기가 적다는 것만으로 위험한 업체라고 단정할 수 없다.
- 리뷰의 양, 최근성, 구체성, 출처 신뢰도, 내 조건과의 유사성이 함께 중요하다.
- 웨딩처럼 서비스 결과가 사람·날짜·조건에 따라 달라지는 경우, 포트폴리오와 실제 진행 사례를 구분해야 한다.

제품 적용:

- "후기 많은 곳이 정답"이라고 말하지 않는다.
- "포트폴리오를 먼저 보는 사람은 감으로 고른다"고 말하지 않는다.
- A4 결과는 후기 수 자체가 아니라, 불확실성을 줄이는 순서를 보여준다.

### 2.3 근거로 주장할 수 없는 것

아래는 금지한다.

- 후기가 적은 업체는 위험하다고 말한다.
- 후기 많은 업체가 더 안전하다고 단정한다.
- 포트폴리오를 먼저 보는 사람은 감성적/충동적이라고 말한다.
- 대안을 찾는 사람은 우유부단하다고 말한다.
- 후기가 적은 업체를 고르면 후회한다고 말한다.
- 웨딩한방 후기가 객관적 품질을 보장한다고 말한다.

정확한 표현은 이것이다.

> 이 문항은 후기 부족이라는 불확실성 앞에서 어떤 정보를 먼저 보아야 결정 준비가 되는지 보여준다.

## 3. 기존 문항 감사

### 3.1 현재 v0.5 초안

> 사진은 딱 마음에 드는데, 실제 후기가 많지 않은 업체가 있어요. 나는 -

- 실제 진행 사례와 포함 조건을 더 본다
- 우리가 원하는 무드와 얼마나 맞는지 다시 본다
- 비슷한 느낌에 후기가 많은 곳도 찾아본다
- 어느 정도 정보 부족까지 괜찮은지 둘이 얘기한다

### 3.2 좋은 점

- 실제 웨딩 준비에서 자주 나오는 고민이다.
- 근거 확인, 취향 판단, 대안 탐색, 커플 조율이 잘 나뉜다.
- 제품 자산인 후기/업체/견적 체크와 연결된다.
- 결과 공유 시 "상대는 이 업체를 어떻게 볼까?"라는 대화가 생기기 쉽다.

### 3.3 위험

| 위험 | 이유 | 처리 |
|---|---|---|
| "사진은 딱 마음"이 가벼움 | 취향 판단이 피상적으로 보일 수 있다 | "스튜디오 포트폴리오는 우리 취향"으로 전문화 |
| A가 정답처럼 보임 | 실제 사례와 조건 확인은 가장 책임감 있어 보인다 | B/C/D도 모두 유효한 첫 순서로 재작성 |
| C가 안전한 정답처럼 보임 | 후기가 많은 곳을 찾는 것이 덜 위험해 보인다 | "같이 본다"로 대안 탐색이지 회피가 아님을 표시 |
| D가 추상적임 | 정보 부족 허용치가 딱딱한 말이다 | "후기 부족을 어디까지 감수할지"로 자연화 |
| 후기 적은 업체 낙인 | 신규/소규모 업체를 위험으로 몰 수 있다 | 결과 문구에서 "위험" 대신 "불확실성" 사용 |

## 5. 채점 가중치

가중치는 확정 점수가 아니라 v0.5 실험용이다. 사람 응답 전까지 "진단 공식"이라고 부르지 않는다.

| 선택지 | 가중치 | 이유 |
|---|---|---|
| A | `ED+2`, `CR+1` | 실제 촬영본과 포함 조건으로 불확실성을 줄인다 |
| B | `AM+2`, `EM+1` | 포트폴리오의 무드와 우리 취향 적합을 먼저 본다 |
| C | `GN+1`, `ED+1`, `AM+1` | 비슷한 무드의 대안을 함께 찾아 비교한다 |
| D | `CP+2`, `DPR+1` | 둘이 정보 부족 허용 기준을 맞춘다 |

구인 약어:

- `ED`: evidenceDecision
- `CR`: costRisk
- `AM`: aestheticMood
- `EM`: experienceMeaning
- `GN`: guidanceNeed
- `CP`: coPreparation
- `DPR`: decisionPaceRisk

## 6. 결과 문구 가드레일

### 6.1 단독 결과 문구

A 선택:

> 포트폴리오가 좋아도, 최근 실제 촬영본과 포함 조건이 확인되어야 마음이 놓이는 쪽이에요.

B 선택:

> 후기가 많지 않아도, 우리가 원하는 색감과 분위기에 얼마나 맞는지를 먼저 보는 쪽이에요.

C 선택:

> 바로 포기하거나 고르기보다, 비슷한 무드에 후기가 더 있는 후보도 함께 비교하려는 쪽이에요.

D 선택:

> 정보가 완벽하지 않을 때, 어디까지 괜찮은지 둘이 먼저 기준을 맞추려는 쪽이에요.

### 6.2 금지 문구

- 감으로 고르는 타입
- 후기 없으면 불안한 타입
- 위험한 선택을 하는 타입
- 안전한 업체만 찾는 타입
- 우유부단한 타입
- 무드에 약한 타입
- 후기 많은 곳이 맞는 타입

이 문항은 업체 품질을 판정하지 않는다. 사용자가 불확실성을 줄이는 순서만 보여준다.

## 7. 커플 공유 문구

### 7.1 A와 B가 갈릴 때

> 한 사람은 실제 촬영본과 포함 조건이 보여야 마음이 놓이고, 한 사람은 우리 취향과 얼마나 맞는지를 먼저 보고 싶어 해요. 먼저 포트폴리오에서 마음에 드는 이유를 말하고, 그다음 업체에 확인할 조건 3개를 정하면 좋아요.

### 7.2 C가 강할 때

> 비슷한 무드의 다른 후보도 함께 보려는 쪽이에요. 장점은 후회 가능성을 줄인다는 것이고, 조심할 점은 후보가 너무 늘어날 수 있다는 거예요. 비교 후보는 2곳까지만 두면 좋아요.

### 7.3 D가 강할 때

> 정보가 완벽하지 않아도 되는 선을 둘이 먼저 정하고 싶어 하는 쪽이에요. "꼭 확인할 것"과 "부족해도 괜찮은 것"을 나누면 대화가 빨라져요.

### 7.4 한쪽은 A/C, 한쪽은 B일 때

> 한 사람은 불확실성을 줄이고 싶어 하고, 한 사람은 취향 적합을 놓치고 싶어 하지 않아요. 기준이 다른 것이지 마음이 다른 것은 아니에요. 취향 이유 2개와 확인 질문 3개를 같이 적어보세요.

금지:

- "후기 신뢰 궁합"
- "한쪽은 감성적이고 한쪽은 현실적"
- "후기 없는 곳을 고르면 위험"

허용:

- "실제 촬영본"
- "포함 조건"
- "색감과 분위기"
- "후기 부족을 감수할 기준"

## 8. 인터뷰 확인 질문

A4 직후 아래를 확인한다.

1. "스튜디오 포트폴리오" 상황이 바로 이해됐나요?
2. 아직 스튜디오를 알아보지 않은 사람도 답할 수 있었나요?
3. 선택지 중 정답처럼 보인 답이 있었나요?
4. 실제 촬영본/포함 조건 확인이 너무 모범답안처럼 보였나요?
5. 색감·분위기를 먼저 보는 답이 감으로 고르는 것처럼 느껴졌나요?
6. 후기가 더 있는 곳도 본다는 답이 더 안전한 정답처럼 느껴졌나요?
7. 후기 부족을 감수할 기준을 정한다는 말이 자연스러웠나요?
8. 이 문항을 상대에게 보내보고 싶다는 느낌이 있었나요?

특히 4번과 5번은 필수다. A4는 근거 확인과 취향 판단 양쪽 모두 낙인 위험이 있다.

## 9. 통과 기준

n=5 인지 인터뷰:

- realism 평균 4.0 이상
- clarity 평균 4.0 이상
- self-fit 평균 3.8 이상
- stage/category-fit 문제 1명 이하
- right-answer-risk "강함" 0명
- stigma-risk "강함" 0명
- "상대에게 보내보고 싶다" 4명 이상

n=20 미니 테스트:

- A 선택 비율이 65% 이상이면 근거 확인이 정답처럼 보이는지 확인
- B 선택 비율이 10% 이하이면 무드 선택지가 감성/충동으로 읽히는지 확인
- C 선택 비율이 50% 이상이면 후기 많은 대안이 지나치게 안전한 답으로 보이는지 확인
- D 선택 비율이 10% 이하이면 문장이 추상적인지 확인
- 스튜디오 단계가 멀다는 피드백이 20% 이상이면 "업체 포트폴리오" 대안 테스트

- A4는 A축의 균형을 잡는다. A1/A3가 비용 확인 쪽으로 강하고 A2가 의미 지출 쪽이라면, A4는 무드와 근거의 충돌을 보여준다.
- 후기/포트폴리오/조건 확인은 웨딩한방의 커뮤니티와 업체 페이지 자산으로 이어진다.
- 다만 후기 부족을 업체 품질 판단처럼 말하면 안 되므로, 결과 문구 가드레일이 반드시 필요하다.
