## 1) 지금 당장 (드라이런 전후) — 최우선 3개 + 반나절짜리 1개

### 1-1. 답잠금 질문 카드 (3심 전원 통과, 평균 8.0 / 견적 2.5~4일)
지금 단계에서 K-팩터를 만드는 유일한 장치. 드라이런 5명에게 "테스트 해봐"가 아니라 "이 카드 열어봐"를 줄 수 있다.

**화면·동작**
- 결과 화면에 "이 질문, 너라면?" 섹션: 본인이 답한 16문항 중 1개 선택 → 상황+A~D가 보이고 내 답만 가려진 공유물 생성.
- 공유는 **링크 퍼스트**: 카톡 공유가 주 채널이고 OG 이미지가 답잠금 카드 역할(PNG에는 클릭 가능한 링크가 없다는 판정 반영). 1080×1920 PNG는 인스타 스토리용 보조 자산으로 짧은 URL 병기.
- 딥링크 페이지 `/q/[shareId]`: 로그인 없이 그 1문항만 답변 → 제출해야 보낸 사람의 선택 공개(호혜 게이트).
- 공개 화면 규칙(판정 조건): **"정답 공개"가 아니라 "내 선택 공개"** 워딩. 일치/불일치 뱃지·이모지·비교 판정 일절 없음 — 두 선택을 나란히 놓고 "정답은 없어요, 서로 다른 게 정상이에요" 한 줄. 돈·가족 등 민감 문항이면 오늘의 대화 카드 톤의 브릿지 문구 1줄 추가. 이어서 "나머지 15개 상황에서 당신은?" CTA.

**데이터·API**
- 신규 테이블 1개: `question_shares(id, response_id, question_id, form_version, question_text_snapshot, sender_choice)` + 수신 답변 기록. **문항 텍스트 스냅샷 저장 필수**(20명 테스트 후 문항 개정 시 구 링크 보존).
- **발신자 답은 수신자 제출 전 초기 응답 페이로드에서 서버측 제외** — 클라이언트 블러로 가리지 않는다.
- API 2~3개(생성/조회/답변), 기존 rate limit 유틸 재사용. PostHog에 공유생성→1문항응답→전체테스트시작 퍼널 3이벤트.

**재사용**: shareCard.ts에 블러 템플릿 1종 추가, 기존 문항 UI, OG 태그.
**잘라낸 것**: 인스타 '투표 스티커+공개 카드' 2장 세트 → 딥링크 퍼널이 없는 브랜드 플레이라 20명 이후로 이연.

### 1-2. 선택 분포 거울 — 단독 문항 위젯 (3심 통과, 평균 8.3, 실행성 9점 / 견적 1.5~2일)
자체 응답을 수집하므로 응답 8건과 무관하게 가동되고, 데이터가 쌓일수록 저절로 좋아지는 제로 유지비 장치.

**화면·동작**
- 로그인 없는 단독 페이지 1개(가장 공감대 높은 문항 1개). 답하면 즉시 "지금까지 N명 중 X명이 같은 선택" + 출처 있는 시장 팩트 1개 + 본검사 CTA.
- **소표본 정직 표기**: n<30이면 백분율 금지, 절대수만("12명 중 8명"). 분포 출처 라벨 "웨딩코드 위젯 응답자 N명 기준" 명시(본검사 표본과 모집단이 다름).
- 소수파 카피 규칙: 평가어 금지, "소수 = 우선순위가 다른 것" 프레임 고정, "다수가 이렇게 해요" 류 설득 문구 금지.

**데이터·무결성(판정단이 지목한 유일한 실행 결함)**
- 응답 테이블 1개 + 집계 엔드포인트 1개(기존 service_role 쓰기 경로). **localStorage 응답 플래그 + IP 해시 일일 스로틀** 0.5일 — 정확성이 브랜드인 서비스에서 카운트가 부풀면 신뢰 자산이 직접 깨진다.
- 공개 전 드라이런 5명 응답으로 시드해 "1명 중 1명" 죽은 화면 방지.

**게이트**: 스와이프 피드·다수답 맞히기·본검사 아코디언 분포는 문항당 100건 도달 전 착수 금지. **'세상 유일 조합 0명' 라벨은 삭제**(아래 4번 참조).

### 1-3. 실용 팩트 미션 카드 — 다운스코프판 (3심 통과, 평균 7.3 / 견적 코드 2~3일 + 집필 2~3일)
파트너 미완료 상태에서도 혼자 받을 수 있어 지금 동작하고, 견적 체크 도구·아모라로 가는 다리.

**화면·동작**
- 결과 화면에서 준비 단계 선택(상견례 전 / 스드메 계약 전 / D-100) → 본인이 고른 문장(1인칭 인용만, "~한 당신은" 류 2인칭 프레임 금지)과 엮인 "사인하기 전 서로에게 물어볼 3가지" 카드 발급.
- **팩트 헤드라인은 검증 4종에만 허용.** 매칭되는 출처 팩트가 없는 질문 카드는 헤드라인 없이 정직하게 출고 — 슬롯 채우려고 무출처 통계를 만드는 순간 탈락 사유. 팩트에 연도 표기, 연 1회 갱신 체크.
- 렌더링은 기존 1080×1920 세로 1종만(정사각 피드 포맷은 20명 이후).
- 릴레이: 보낸 사람 답 비노출 중립 포맷이되, 판정단 지적대로 **개인화를 가시화** — 카드 하단에 "이 3가지 질문은 보낸 커플의 선택에서 나왔어요. 우리 커플의 3가지는 다릅니다" + 링크. 수신자는 16문항 전체가 아니라 단계 선택+핵심 3~5문항 경량 진입으로 즉시 자기 카드를 받고, 전체 테스트는 그 후 제안.

**콘텐츠**: 단계당 질문 3~5개 고정 풀로 캡(콘텐츠가 진짜 비용이라는 판정 반영).

### 1-4. 타임캡슐 T0 수집 (0.5일 — 지금 안 하면 나중에 보여줄 게 없음)
타임캡슐 재검 자체는 after_20이지만, 판정단 지적대로 **"3개월 뒤 우리에게" 한 줄 입력 + 이메일/알림 옵트인(보관기간·수신거부 포함)은 지금 결과 화면에 넣는다.** 재접촉 채널 확보는 재검 회수율의 전제조건이다.

**보류(now지만 뒤로)**: 주간 공개 문항 광장 — 가드레일 문제는 없으나 주간 운영 리듬이 필요하므로 위 3개 출고 후(3~4주차) 시작. 시작 시 규칙: "응답 커플"이 아닌 "이번 문항에 답한 N명" 표기, 라이브 16문항은 광장에 노출 금지(공개 문항은 소각 처리해 재검사 안정성 오염 방지), 시딩은 링크 자동삭제하는 카페가 아니라 인스타 스토리·오픈채팅 중심, 분포 카드 PNG에 URL 각인. 선자리 패스앤플레이는 문항 안전성 데이터가 0건이라는 판정에 따라 after_20으로 이동.

## 2) 20명 미니테스트 이후

우선순위 순서. 공통 전제: 20명 테스트로 **16문항 동결 + form_version 게이트** 확보, 파트너 완주 전환율 베이스라인 측정.

**2-1. 커플 비교 리포트 = "같음 셋, 다름 하나" (평균 8.2 — 이 단계의 앵커, 사다리 ④ 사양 그 자체)**
- 동시 오픈은 데드엔드 방지 폴백 포함: "둘 다 제출 완료 시 열림 + 첫 조회 리빌 연출"로 완화하거나 N일 후 단독 열람 허용.
- 같음 3개를 '우리 둘 다' 1인칭 복수 카드로 먼저 → 다름은 정확히 1개만 전면 노출하되 **선정 규칙 명시**(저강도 문항 우선 또는 커플 직접 선택 — 양가 돈 문제가 자동 선정되면 싸움 유발 장치가 된다).
- **어디에도 같음/다름 개수 카운트 금지**(세어지는 순간 사실상 궁합 점수). 아코디언에도, 공유 PNG에도.
- 엣지 케이스 3종 스펙 명시: 전부 같음 / 같음 0개 / form_version 불일치.
- 공유 PNG는 v1에서 '우리는 이 질문에서 갈렸다' 1종만(질문 원문 + "너희는 갈릴까?" CTA + 링크 각인). 기본 노출 카드는 동질감 카드로 두고 '갈렸다'는 선택제. 한쪽만 완료 시 '상대 기다리는 중' 티저 카드 공유 가능.

**2-2. 서로 맞히기 예측 게임 — 비교 리포트의 초대 오프닝 (평균 7.5)**
- pair API의 초대 생성 시점에 A가 하이라이트 5문항 봉인 예측 → B는 "내 답이 예언돼 있다"가 완주 동기 → 카드 뒤집기 공개. 파트너 완주 전환이라는 최약 고리를 직접 공격.
- 봉인은 **서버 강제**(B의 응답 전에는 어떤 페이로드에도 예측 미포함). 대화카드는 답변쌍별 192개가 아니라 문항당 16개.
- 공유 카드는 맨 점수·'너네는 몇 개?' 도발 금지 — **"통한 4개 + 오늘 밤 얘기할 발견 1개"** 발견 프레임으로 이원화(1/5 커플이 '서로 모르는 커플'로 낙인되는 것 차단).
- A의 보상 경로: A가 자기 결과 URL 재방문 시 공개+점수 카드 표시(알림 인프라 없이 해결).
- **'진실 혹은 허풍' 블러핑 모드 삭제**(4번 참조). 파장 다이얼은 명세에서 제거.

**2-3. 그 다음 순서로**
- **우리 팀 규칙 헌장**(7.5): 비교 리포트 배관 위에 얹어야 성립. 비동기 서명(Realtime 불필요), 규칙 문장은 낙인 없이 변환되는 조합만 30~40개 큐레이션+공용 폴백, 일치 3개 미만 커플에겐 일치 개수 노출 없이 공용 메뉴로 전환. PNG에 "나부터 3분" 솔로 온램프 CTA. 실코스트 M으로 재라벨.
- **단톡방 판**(7.0): couple_token 패턴 복제, 폴링 갱신(Realtime 금지), 문항 3개는 비예비부부도 답할 수 있는 보편형으로 재작성, 응답 3명 미만 블러+"2명만 더 오면 공개", 분포 공개 후 "다른 방에 판 깔기" CTA.
- **타임캡슐 재검 발송**(7.0): 마일스톤 트리거 삭제, 고정 30일 단일 재검. N≤20 구간은 스케줄러 없이 **파운더 수동 발송**. 발송 전 "열어볼까요?" 옵트인 완충(파혼 대비). 커플 양쪽 같은 날 도착으로 미니 동시성. 실제로 답이 바뀐 문항만 비포애프터 카드에, 무변화 커플엔 '한결같음' 긍정 카드 별도 설계. KPI는 바이럴이 아니라 **재검 회수율·안정성 데이터**.
- **선자리 패스앤플레이**(7.0): '같은 공간 커플·지인 즉석 모드'로 재포지셔닝(선자리는 마케팅 스토리). 8문항은 견적서·양가 전제를 뺀 가정형으로 재큐레이션, 종료 화면은 갈림 목록이 아니라 대화 카드 1장이 주인공(일치 개수 세기 쉬운 UI 금지 — 창발적 궁합 점수 차단), 익명 1-row 결과 저장으로 데이터 증발 방지, 플레이어 2를 솔로 테스트로 넘기는 CTA.

## 3) 재검사 안정성 확보 후 (사다리 ⑤)

**코드+캐릭터 IP 패키지 (3심 통과, 평균 7.0)**
- 네이밍: 알파벳 대신 전 구성어 긍정어인 순우리말 네 글자('도란차곡' 계열). 단 "긍정어라 낙인 구조적 불가능"은 과신 — **음절어마다 시댁·친구 놀림 시나리오 오남용 테스트를 네이밍 검수 절차에 포함**(절약 계열이 '짠돌이'로 변형되는 류).
- 캐릭터: 유형별 분화 대신 커플당 1마리 나무 기러기(목안) — 낙인 회피 + '약속을 기억하는 새'가 브랜드 핵심 가치(구두 약속·검증)와 정합. **v1 범위는 코드 카피 16종 + 일러스트 1종 외주 + 기존 PNG 렌더러 확장까지만.** 이모티콘·굿즈·청첩장 문구는 코드 바이럴 실측 후 — 1인 규모에서 별도 사업이다.
- 희소 라벨: 최소 표본 게이트(코드당 30커플 이상 등) 전 미노출, 노출 시에도 %서열 대신 "지금까지 N쌍 중 X쌍이 같은 코드" 중립 서술 + 흔한 코드에도 긍정 프레임 병기.
- **선행 과제(아직 존재하지 않는 작업)**: 12구인→4축 축약은 심리측정 작업이다. 20명+재검 데이터로 축 구조·축별 안정성을 먼저 검증하고, 4축으로 안 떨어지면 글자 수를 재조정한다는 탈출구를 문서에 명시. 20명 테스트 때 네이밍 변별력(자기 코드 회상·타인 코드 구분)도 함께 검증 — 이게 실질 병목.

## 4) 기각작에서 배울 점

**① 커플 주간 리추얼 + 대화 지도 (유일한 부분 탈락 — 바이럴 심사 4점)**
기각 사유: 1차 공유가 이미 페어링된 파트너에게만 가서 신규 유입 K-팩터가 0이고, 유일한 외부 공유물(완성 PNG)이 푸시 없는 12주 뒤에 있다 — 선례(Paired)가 증명한 건 리텐션이지 바이럴이 아니었다.
배울 점: **"매주 커플 밖으로 나가는 아티팩트"가 없으면 리텐션 기능은 확산 기능이 아니다.** 이 원칙은 살아남은 기능에도 적용 — 비교 리포트·예측 게임의 매 공개 화면에 제3자용 공유물을 붙이는 이유. 상호성 잠금 코어는 폐기가 아니라 비교 리포트 후속으로 흡수.

**② '진실 혹은 허풍' 블러핑 초대장 (예측 게임에서 절제)**
기각 사유: 의도적 거짓을 제품에 섞는 순간 "정확성이 브랜드" 포지션과 정면 충돌.
배울 점: **재미를 위해 정직성을 파는 아이디어는 즉시 탈락이라는 원칙이 실제로 작동했다.** 앞으로 모든 신기능 카피 검수의 1번 질문: "이 화면에 사실이 아닌 것이 하나라도 있는가."

**③ '세상 유일 조합 0명' 라벨 (분포 거울에서 절제)**
기각 사유: 4^16 ≈ 43억 조합이라 전원이 사실상 유일 — 수학적으로 참이어도 희소성을 연출하는 착시(별자리 화법)이고, 사용자가 알아채는 순간 공허해진다.
배울 점: **통계적으로 참인 것과 정직한 것은 다르다.** 살릴 거면 "16문항 조합은 43억 가지라 대부분 유일합니다"처럼 수학을 함께 공개하는 형태만 — 소표본 % 금지 규칙과 같은 뿌리.

## 5) 전체를 관통하는 공유 루프 한 장

```
[외부 유입 — 3개 입구, 전부 로그인 없음]
  분포 거울 위젯(단독 문항 URL) ── 단톡방·커뮤니티
  답잠금 카드 딥링크(1문항 페이지) ── 친구 1:1 카톡
  팩트 미션 릴레이(경량 3~5문항) ── 커플→커플
        │  공통 설계: 10~30초 마이크로 참여 → 즉시 보상 → "전체 16문항에서 당신은?" CTA
        ▼
[3분 테스트] ──► [미러 프로필 결과]
                    │  이 화면에서 갈라지는 4개 출구:
                    ├─ ① 답잠금 카드 생성 → 친구에게 (신규 유입 재생산)
                    ├─ ② 팩트 미션 카드 → 저장·릴레이 (신규 커플 유입)
                    ├─ ③ 타임캡슐 한 줄 + 연락 옵트인 (30일 뒤 귀환 예약)
                    └─ ④ 커플 초대 (+ after_20: 봉인 예측 5문항)
                              │  "상대가 내 답을 예언해놨다" = 수신자 완주 동기
                              ▼
                    [파트너 완주] ──► [비교 리포트: 같음 셋 다름 하나]
                              │  (오프닝: 예측 카드 뒤집기 → 발견 프레임 카드)
                              ├─ 커플 공동 PNG('갈렸다' 카드, CTA 각인) → 제3자 유입
                              ├─ 팀 규칙 헌장 서명 PNG(솔로 온램프 CTA) → 제3자 유입
                              └─ 30일 후 재검 → 비포애프터 카드 → 재공유
                                        │
                                        ▼
                              [재검사 안정성 데이터 축적] ──► 사다리 ⑤ 코드+기러기 IP
                                                              ("우린 도란차곡" = 최상위 공유 화폐)
```

루프의 핵심 논리 세 가지:
1. **모든 공유물이 수신자를 마이크로 참여(10~30초)로 받는다.** 전체 테스트를 먼저 요구하는 입구는 하나도 없다 — 호혜 게이트(답잠금·단톡방 판)나 즉시 보상(분포·경량 팩트 카드)이 먼저다.
2. **결과 화면이 허브다.** 친구 방향(답잠금), 커플 방향(초대+예측), 커뮤니티 방향(팩트 릴레이), 미래의 나 방향(타임캡슐)이 전부 여기서 출발하고, 커플 비교의 산출물이 다시 제3자 유입 입구가 된다.
3. **데이터 수집이 루프에 내장돼 있다.** 위젯·광장이 문항 반응 데이터를, 타임캡슐이 재검사 안정성 데이터를 기능의 얼굴로 쌓는다 — ⑤단계는 별도 프로젝트가 아니라 이 루프가 돈 결과물이다.

**착수 순서 요약**: 1주차 답잠금 카드 → 2주차 분포 거울 + 타임캡슐 T0(0.5일) → 3주차 팩트 미션(집필 병행) → 드라이런 5명에 답잠금 카드로 점화 → 4주차부터 광장 주간 운영 → 20명 미니테스트(문항 동결·완주율 베이스라인) → 비교 리포트+예측 게임 → 규칙 헌장·단톡방 판·재검 발송 → 안정성 데이터 확보 후 코드+기러기.
