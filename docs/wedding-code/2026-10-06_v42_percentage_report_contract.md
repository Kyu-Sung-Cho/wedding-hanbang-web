# 웨딩코드 선택 비율·주제별 결과 보완

상태: 수치·주장 감사, 로컬 구현, 관련 회귀·실제 화면 검수 완료 / 사람 대상 타당성·공개 배포와 별도.

## 요청과 선택

사용자는 퍼센트도 꼼꼼히 확인하고 각 결과를 전문적으로 만들어 달라고 요청했다. 세 후보를 검토했다: 상세 화면의 글씨만 변경, 글자 바로 아래에 실제 응답 비율과 판정 이유를 연결, 별도 통계 총점 만들기. 두 번째를 선택한다. 코드 풀이 옆에서 각 주제의 방향별 비율·실제 답 수·글자 판정 근거를 읽고, 기존 장면별 원문과 계산까지 확인한다.

숫자 표현은 정수 독립 반올림 / 합계 100으로 보정 / 최대 소수 둘째 자리 세 가지를 검토했다. 최대 소수 둘째 자리를 선택한다. 한 주제의 16문항을 모두 답한 경우 한 답은 6.25%이며 7/16·7/16·2/16 같은 사례가 43.75%·43.75%·12.5%로 그대로 읽힌다. 합계를 맞추기 위한 수치 조정은 하지 않는다. 다른 분모에서는 반올림으로 합계가 조금 달라질 수 있음을 설명한다.

## 확인한 계산

- 비율 = 문항값이 앞/뒤/0인 답 수 ÷ 해당 주제의 유효 답 수. 중간 반응뿐 아니라 양쪽 배분이 상쇄된 값 0도 있으므로 라벨은 ‘한쪽으로 기울지 않은 답’이다.
- 주제당 채점 16문항이며 마지막 자기 선택 네 문항은 이 비율에 포함하지 않는다. 건너뜀·해당 없음·누락을 분모에서 제외한다.
- 글자는 횟수 최다 방향이 아니다. 답이 둘 이상인 장면 묶음의 평균 강도를 같은 비중으로 합산한다. 동점이면 고르기 문항(recall/instant), 반응 문항, 장면 방향 수, 자기 선택 등 실제 보조 기준을 따른다.
- 1답 묶음은 묶음 평균의 가중합에서 제외되지만, 동점 보조 기준의 개별 답 합에는 쓰일 수 있다. 따라서 ‘글자 계산에서 완전히 제외’라는 기존 설명은 ‘묶음 평균 계산에서 제외’로 고친다.
- 감사에서 실제 새 은행으로 앞9/16·뒤7/16인데 강도 계산은 뒤쪽 글자인 사례를 재현했다. 비율은 양쪽 고정 순서로 모두 표시하고, 이런 개인 결과에는 횟수와 글자의 차이를 풀어 쓴다.
- 커플 데이터에는 현재 강도 합계가 없으므로 각자의 실제 횟수 비율과 표시 상태를 보여주고, 해당 데이터로 장면별 강도 기여를 만들어 내지 않는다.

## 구현·검수 기준

- 개인 코드와 두 사람 각각의 글자 풀이 아래에 선택 비율을 표시한다. 분자·분모와 답한 수를 함께 보이며 확신도·정확도·궁합 퍼센트로 부르지 않는다.
- 글자를 정하지 못했어도 실제 답의 분포는 볼 수 있으나 코드 판정과 분리한다. 답이 없으면 비율을 만들지 않는다.
- 반반·임시·표시 세기 하향·동점에서 선택 횟수가 글자를 확정한다고 설명하지 않는다. 개인 판정 이유는 실제 AxisResult 필드로만 만든다.
- 답이 두 개 미만인 장면은 묶음 평균에서 제외되는 사실을 접지 않고 표시한다. 동점 첫 기준의 기존 ‘두 가지 중 고르기’ 문구는 실제 recall/instant인 ‘고르기 문항’으로 고친다.
- 정적 산술·극단값·분모 없음·100% 미정·횟수/강도 불일치·동점·세기 하향·관점 전환 회귀와 실제 모바일 화면을 확인한다.

## 주장 감사

허용하는 해석은 이번 답의 방향, 강도, 장면별 분포, 다음에 함께 맞춰볼 질문이다. 응답하지 않은 성격·속마음·능력·관계 결과를 추론하지 않는다. 새 비율 표시가 측정 타당성이나 정확도를 입증하지 않는다. 기존 은행·채점·판·링크·저장 범위는 유지한다.

디자인은 DESIGN.md의 Pretendard·ivory·champagne·mauve 역할과 이전 Lazyweb clarify/craft 가이드를 적용한다. 숫자보다 라벨과 분모가 먼저 읽히고 색 외에도 글로 방향을 구별한다.

## 최종 적대적 검수와 수정

- 두 사람 비교에서 제외되는 원인에는 응답 관문도 있다. 미정·임시를 모든 제외의 원인으로 단정하던 새 문구를 고쳐, 이번 비교에서 제외했다는 확인 가능한 상태만 말한다.
- compact 비율을 세 개의 가로 행으로 바꿔 좁은 카드 안에 방향 이름과 큰 숫자·실제 분모가 대응하게 한다. 비율에서 뺀 답이 없는 compact 화면에서는 제외 사유를 반복하지 않는다.
- 모바일의 긴 개인 풀이 뒤까지 내려가지 않아도 주제별 나란히 보기를 열 수 있는 이동 버튼을 둔다. URL의 응답 해시는 유지하고 초점과 스크롤만 옮긴다.
- 전체 여덟 글자표는 주제별 근거 뒤로 옮긴다. 코드 바로 아래의 네 글자 정의는 계속 바로 보인다. 동점 안내는 실제 고르기·반응·계산에 포함한 장면 기준을 쉬운 문장으로 푼다.
- 중앙 문구 검사에서 글자 위치를 뜻하는 ‘자리’ 금지를 유지한다. `evidence.precisionNote`의 ‘소수점 둘째 자리까지’만 산술 의미로 허용하고 해당 표현을 별도로 검사한다.
