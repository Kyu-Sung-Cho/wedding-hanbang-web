# 웨딩코드 v4.1 구현·검수 기록

기록일: 2026-10-05 (한국 시각)

## 반영 범위

- 전체 68문항 중 67문항의 노출 문장을 수정했다. 여섯 응답 형식과 마지막 자기 선택 네 문항으로 구성하며, 채점 대상은 64문항이다. 상황·선택 비용·지난 행동을 묻고, 선택하지 않은 감정이나 결과는 만들어 인용하지 않는다.
- 네 주제와 16측면의 실제 응답 방향 개수·분모·반올림한 비율을 표시한다. 글자를 정한 가중 계산, 동점 기준, 반대 방향의 답을 따로 설명한다. 비율은 내면의 확률이나 정확도 수치가 아니다.
- 여덟 글자는 `V/S`, `W/D`, `U/F`, `H/A`로 서로 겹치지 않고, 각 사람의 코드 바로 아래에서 자리별 뜻을 읽을 수 있다.
- 두 사람 대화 카드에 실제 질문 상황·인용·물음과 양쪽 선택을 표시하고 다음 장면으로 이동한다. 같은 글자여도 측면별로 서로 반대 방향의 과반수가 있으면 그 장면을 함께 살펴보게 한다.
- 이번 코드의 행동을 묶은 놀이 별칭 16개를 붙인다. 예: `함께 살피는 수달`, `나눠 펼치는 여우`. 별칭은 새 심리 해석이나 유형이 아니다.
- 문항마다 번호를 표시하고, 공유 메시지에서 상대가 눌러야 하는 `두 사람 결과 링크 보내기`를 명시했다.
- v4.1은 별도 문항 원본·공유 부호·저장 키로 연결한다. 질문만 보내는 주소에도 판 이름을 넣는다. v4.0·v3.1 링크와 답은 각 원문의 판에서 읽으며 v4.1과 섞지 않는다. 퍼센트 인코딩된 정상 판 이름도 받은 결과를 유지한다.
- 개인정보 안내의 판 이름·보관 경계·공유 버튼 명칭을 실제 구현과 맞췄다.

## 남아 있는 제품 검증

문항 이해도, 정답처럼 보이는 선택지, 비해당 응답, 끝까지 답하는 부담, 재응답 변화, 결과가 대화에 실제로 도움이 되는지는 사람 자료로 확인해야 한다. 현재 사람 검증은 수행하지 않았다. 0a·0b·G3 통과, 과학적 성향 검사, 내면을 정확히 알아낸다는 주장이나 궁합·관계 예측은 하지 않는다.

로컬 기본 입구 전환은 검수를 위한 구현이다. 이 기록은 커밋·PR·운영 배포·사람 검증 완료를 뜻하지 않는다.
