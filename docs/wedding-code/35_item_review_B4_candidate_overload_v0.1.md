## 0. 결론

B4는 삭제하지 않고 수정 유지한다. 소재는 좋다. 웨딩 준비에서는 예식장, 스튜디오, 드레스, 메이크업 후보가 계속 늘어나면서 "더 보면 더 나아질 것 같고, 그래서 더 못 고르는" 상황이 자주 생긴다.

다만 기존 초안은 B3와 많이 겹쳤다. B3가 "서로 보는 기준이 다를 때 그 기준을 어떻게 합칠지"라면, B4는 **후보가 너무 많아졌을 때 더 찾지 않고 어떻게 줄일지**를 묻는 문항이어야 한다.

v0.5에서는 아래 후보를 쓴다.

> 후보가 계속 늘어나서 선택이 더 어려워졌어요. 우리는 먼저 -

- 둘이 먼저 뺄 기준을 정하고 후보를 줄인다
- 한 사람이 먼저 2~3개로 줄여서 함께 본다
- 각자 남길 후보를 하나씩 골라와 같이 비교한다
- 오늘은 새 후보를 더 보지 않고 남은 것만 정리한다

이 문항은 우유부단함이나 통제욕을 찾는 문항이 아니다. 핵심은 후보가 많을 때 압축을 누가, 어떤 순서로, 어디까지 할지다.

---

## 1. 이 문항이 필요한 이유

B축의 앞 문항들은 커플 준비 방식의 다른 장면을 다룬다.

- B1: 한 사람이 먼저 마음에 드는 곳을 찾았을 때 어떻게 공유할지.
- B2: 준비가 한쪽으로 몰렸을 때 어떻게 다시 맞출지.
- B3: 서로 먼저 보는 기준이 다를 때 어떻게 합칠지.
- B4: 후보가 너무 많아졌을 때 어떻게 줄일지.

B4가 필요한 이유:

1. 후보 과다는 실제 웨딩 준비에서 강한 피로 지점이다.
2. 커플 한쪽은 "더 찾아보자"고 느끼고, 다른 쪽은 "이제 줄이자"고 느낄 수 있다.
3. 후보를 줄이는 방식은 커플 URL, 비교표, 아모라 후보 압축 기능과 직접 연결된다.
4. "더 보기"와 "그만 보기"의 기준을 정하면 결과 리포트에서 바로 대화 카드로 바꿀 수 있다.

## 2. 근거 레이어

### 2.1 S8: 결정 방식과 대안 탐색

`docs/wedding-code/22_evidence_backbone_and_taxonomy_v0.1.md`의 S8은 결정 방식이 영역, 가치, 상황에 따라 달라질 수 있다는 근거다. B4에는 "후보가 많아졌다고 느끼는 상황에서는 기준 재설정, 후보 압축, 탐색 중단 같은 정리 방식이 달라질 수 있다"는 수준으로만 적용한다.

허용:

- "후보가 많을 때 사람마다 편한 정리 방식이 다를 수 있다."
- "더 찾는 것보다 먼저 줄이는 기준이 필요한 순간이 있다."

금지:

- "후보가 많으면 우유부단해진다."
- "후보를 많이 보는 사람은 욕심이 많다."
- "빨리 줄이는 사람이 더 결단력 있다."

### 2.2 S7: 공동 소비 의사결정

B4가 `coPreparation`과 `roleOwnership`을 같이 다루려면 S7이 보조 근거로 필요하다. 후보를 같이 줄일지, 한 사람이 먼저 압축할지, 각자 하나씩 골라올지는 모두 커플 공동 소비 의사결정에서 참여감과 영향감을 어떻게 나눌지의 문제다.

제품 적용:

- "같이 기준을 세우는 방식"과 "한 사람이 먼저 줄이는 방식"을 서열화하지 않는다.
- "한 사람이 먼저 줄인다"를 통제욕이나 배제로 해석하지 않는다.
- 최종 확인과 공유 방식이 있으면 분업도 유효한 준비 방식으로 둔다.

### 2.3 S9: 제품 자산 연결

B4는 다음 기능으로 자연스럽게 이어진다.

- 후보 압축: 2~3개로 먼저 줄이기.
- 비교표: 남은 후보만 표로 정리하기.
- 커플 URL: 각자 남길 후보를 골라와 함께 보기.
- 아모라 안내: "새 후보 탐색 중단" 기준과 제외 기준 정리.

단, S9는 제품 라우팅 근거다. "후보 압축 기능이 갈등을 줄인다"는 효과 검증 주장은 아직 UNVERIFIED다.

## 3. 기존 문항 감사

기존 초안:

> 후보가 계속 늘어나서 뭘 봐야 할지 헷갈려요. 우리는 -

- 둘이 같이 보며 기준을 다시 세운다
- 한 사람이 먼저 2~3개로 줄여본다
- 조건, 분위기, 비용을 나눠서 본다
- 오늘은 결정하지 말고 비교만 해둔다

좋은 점:

- 실제감이 있다.
- 후보 압축, 비교표, 아모라 안내와 연결된다.
- B축의 공동 준비와 역할 분담을 모두 건드린다.

위험:

| 위험 | 설명 | 수정 방향 |
|---|---|---|
| B3 중복 | 기준 맞추기, 한 사람이 줄이기, 표로 비교가 B3와 겹침 | "후보 과다를 멈추고 줄이기"로 초점 이동 |
| A축 누수 | 조건/분위기/비용이 CR/AM으로 읽힘 | 기준 종류를 나열하지 않음 |
| GN 누수 | 후보 압축을 도움 선호로 과대 해석할 수 있음 | 제품 라우팅만 GN적으로 쓰고 점수에서는 제외 |
| 회피감 | "결정하지 말고"가 우유부단처럼 읽힘 | "새 후보를 더 보지 않고 남은 것만 정리"로 변경 |
| 정답감 | "둘이 기준 세우기"가 가장 성숙한 답처럼 보일 수 있음 | 인터뷰에서 모범답안 위험 확인 |

## 4. v0.5 권장 문항

질문:

> 후보가 계속 늘어나서 선택이 더 어려워졌어요. 우리는 먼저 -

선택지:

| 선택지 | 문장 | 측정 |
|---|---|---|
| A | 둘이 먼저 뺄 기준을 정하고 후보를 줄인다 | 공동 기준, 구조화된 압축 |
| B | 한 사람이 먼저 2~3개로 줄여서 함께 본다 | 역할 주도, 최종 공동 확인 |
| C | 각자 남길 후보를 하나씩 골라와 같이 비교한다 | 분산 탐색, 공동 비교 |
| D | 오늘은 새 후보를 더 보지 않고 남은 것만 정리한다 | 탐색 중단, 속도 조절, 정리 |

예비 대안:

> 후보가 많아질수록 다 괜찮아 보여서 고르기가 어려워요. 우리는 먼저 -

- 둘이 꼭 볼 기준 3가지만 다시 정한다
- 확실히 아닌 후보부터 먼저 걷어낸다
- 비슷한 후보끼리 묶어서 차이만 본다
- 오늘은 최종 결정 대신 남길 후보만 표시한다

예비 대안은 더 말랑하지만, "다 괜찮아 보여서"가 취향 평가처럼 읽힐 수 있다. 1차 후보가 너무 딱딱하다는 피드백이 나올 때 테스트한다.

## 5. 채점 가중치

| 선택지 | 가중치 | 이유 |
|---|---|---|
| A | `CP+2`, `ED+1` | 둘이 함께 제외 기준을 정하고 후보를 줄이는 공동 정리 방식 |
| B | `RO+2`, `CP+1` | 한 사람이 먼저 압축하되 최종 후보는 함께 보는 방식 |
| C | `RO+1`, `CP+1` | 각자 하나씩 골라오는 분산 탐색과 공동 비교 |
| D | `DPR+1`, `ED+1` | 새 후보 탐색을 멈추고 남은 후보를 정리하는 속도 조절과 구조화 |

주의:

- `GN`은 제외한다. 후보 압축은 제품 라우팅에는 쓰되, "도움이 필요한 사람"처럼 공개 라벨화하지 않는다.
- `CR`, `AM`, `CA`는 제외한다. B4는 비용형/분위기형/우리 기준형을 묻는 문항이 아니다.
- `DPR`은 +1만 둔다. 이 문항은 계약 압박 상황이 아니라 탐색 중단/속도 조절 상황이다.

## 6. 결과 문구 가드레일

### 6.1 허용 문구

A 선택:

> 후보가 많아졌을 때는 둘이 먼저 제외 기준을 맞추고 줄여야 편한 편이에요.

B 선택:

> 후보가 너무 많을 때는 한 사람이 먼저 압축해두고, 함께 최종 후보를 보는 흐름이 편한 편이에요.

C 선택:

> 각자 남길 후보를 하나씩 가져와 비교하면 서로의 기준을 빠르게 볼 수 있는 편이에요.

D 선택:

> 새 후보를 더 찾기보다, 지금 남은 후보를 정리하고 속도를 잠깐 맞추는 게 편한 편이에요.

### 6.2 금지 문구

- "우유부단한 편이에요."
- "통제욕이 강한 편이에요."
- "회피하는 편이에요."
- "같이 기준을 세우는 커플이 더 건강해요."
- "한 사람이 줄이면 상대를 배제하는 편이에요."
- "후보 압축 기능을 쓰면 갈등이 줄어요."

결과 문구는 성격 평가가 아니라 **후보를 줄이는 순서**만 말한다.

## 7. 커플 공유 문구

A와 B가 갈린 경우:

> 한 사람은 둘이 먼저 제외 기준을 맞추면 편하고, 한 사람은 누군가 먼저 2~3개로 줄여오면 편해요. 오늘은 "절대 제외할 기준 2개"와 "같이 볼 최종 후보 3개"만 정해보세요.

B와 D가 갈린 경우:

> 한 사람은 후보를 먼저 줄이면 진행이 쉬워지고, 한 사람은 새 후보 탐색을 잠깐 멈춰야 마음이 정리돼요. 새 후보를 더 찾기 전에 지금 후보에서 남길 것만 표시해보면 좋아요.

C가 강한 커플:

> 두 분은 각자 하나씩 남길 후보를 가져와 비교할 때 대화가 쉬워질 수 있어요. 후보를 많이 늘리기보다, 서로 왜 남겼는지를 먼저 들어보세요.

D가 강한 커플:

> 지금은 더 찾는 것보다 멈추고 정리하는 시간이 필요할 수 있어요. 오늘은 최종 결정 대신 "남길 후보"와 "뺄 후보"만 나눠도 충분해요.

금지:

- "누가 더 결정을 못 한다."
- "누가 더 주도권이 세다."
- "이 조합은 궁합이 좋다/나쁘다."

## 8. 인터뷰 확인 질문

B4 직후 아래를 확인한다.

1. 이 문항이 B3의 "서로 보는 기준이 다를 때"와 다르게 느껴졌나요?
2. "후보가 계속 늘어나서 선택이 더 어려워졌다"는 상황이 실제처럼 느껴졌나요?
3. "둘이 먼저 뺄 기준을 정한다"가 가장 책임감 있는 정답처럼 보였나요?
4. "한 사람이 먼저 2~3개로 줄인다"가 효율처럼 느껴졌나요, 상대 배제처럼 느껴졌나요?
5. "각자 남길 후보를 하나씩 골라온다"가 공평하게 느껴졌나요, 일을 나누는 척처럼 느껴졌나요?
6. "새 후보를 더 보지 않는다"가 건강한 정리로 느껴졌나요, 결정 회피처럼 느껴졌나요?
7. 선택지 중 고르면 안 좋은 사람처럼 보이는 답이 있었나요?
8. 이 답을 상대에게 공유하면 대화가 열릴 것 같나요?

1번, 3번, 6번은 필수다. B3 중복, 모범답안, 회피감 중 하나라도 강하게 나오면 문항을 다시 쓴다.

## 9. 통과 기준

n=5 인지 인터뷰:

- realism 평균 4.0 이상
- clarity 평균 4.0 이상
- self-fit 평균 3.8 이상
- B3와 "같다"는 반응 0명 목표, 1명 이상이면 질문 문구 수정
- right-answer-risk "강함" 0명
- "새 후보를 더 보지 않는다"를 회피로 읽은 사람 0명 목표
- "상대에게 보내보고 싶다" 4명 이상

n=20 미니 테스트:

- A 선택률 50% 이상이면 "기준 세우기"가 모범답안처럼 보이는지 확인
- B 선택률 10% 미만이면 "한 사람이 줄이기"가 독단처럼 읽히는지 확인
- D 선택률 10% 미만이면 탐색 중단 선택지가 회피처럼 읽히는지 확인
- "우유부단/통제욕/회피로 느껴졌다" 응답 5% 초과 시 문항 실패
- "대화가 열릴 것 같다" 응답 70% 미만이면 커플 공유 문항으로 실패
