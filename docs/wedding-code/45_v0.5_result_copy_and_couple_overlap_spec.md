## 0. 목적

v0.5 점수를 사용자에게 바로 숫자/유형으로 보여주면 위험하다. 결과 화면은 성격 진단이 아니라, 결혼 준비 대화를 쉽게 시작하게 만드는 번역층이어야 한다.

이번 단계의 목표:

- 정규화 점수를 낙인 없는 한국어 문장으로 바꾼다.
- 커플 비교는 "궁합"이 아니라 "준비 방식 겹침도"로만 말한다.
- `decisionPaceRisk`, `guidanceNeed`는 공개 유형명이 아니라 행동 카드로만 사용한다.

## 2. 공개 축 문장

| 축 | 왼쪽 | 오른쪽 | 균형 |
|---|---|---|---|
| 결정 기준 | 확인 가능한 기준이 보여야 마음이 놓임 | 장면과 의미가 그려져야 움직임 | 조건과 의미를 함께 봄 |
| 준비 방식 | 같이 보고 기준을 맞추는 과정 | 맡아 정리한 뒤 함께 확인 | 같이 보기와 맡기를 섞음 |
| 조율 범위 | 둘의 기준을 먼저 세움 | 가족·하객 기준을 먼저 살핌 | 둘의 기준과 가족 기준을 함께 둠 |
| 지원 순서 | 막힌 지점을 먼저 들어야 함 | 할 일·마감·역할이 잡혀야 함 | 듣기와 정리가 모두 필요 |

---

## 3. 커플 겹침도

계산:

1. 각 축의 위치를 `leftScore - rightScore`로 둔다.
2. 두 사람의 축 위치 거리를 구한다.
3. `100 - distance / 200 * 100`을 축별 겹침도로 둔다.
4. 축별 겹침도의 평균을 전체 "준비 방식 겹침도"로 둔다.

표시:

- 75 이상: 대화가 쉽게 시작될 지점이 많아요
- 55 이상: 겹치는 부분과 맞춰볼 부분이 함께 있어요
- 55 미만: 먼저 맞춰볼 대화 주제가 뚜렷해요

금지:

- 궁합
- 커플 적합도
- 결혼 성공률
- 갈등 예측
- 위험 커플

## 4. 제품 연결

`decisionPaceRisk`:

- 계약 전 확인 카드
- 하루 숙려 리마인더
- 업체 질문 카드

`guidanceNeed`:

- 먼저 볼 3가지
- 견적 체크 CTA
- 후보 압축 카드

두 구인은 공개 정체성 문장에 쓰지 않는다.
