# 웨딩코드 v4.1 결과 읽기 계약

작성: 2026-10-04 · 상태: 로컬 구현·관련 검사 완료 / 사람 검증 전 / 미배포

## 결과가 답해야 할 질문

1. 네 글자가 각각 어느 주제와 어떤 응답 방향을 가리키는가?
2. 내가 실제로 고른 답 중 무엇이 그 방향에 기여했으며, 반대 방향의 답은 무엇인가?
3. 같은 글자 안에서도 장면별 선택이 달랐는가? 상대와는 어느 장면부터 대화하면 되는가?
4. 받은 링크에는 누구의 어떤 답이 들어 있으며, 상대가 내 결과를 보려면 무엇을 다시 보내야 하는가?

## 개인 결과

- 결과 첫머리에 미검증 고지를 한 번 보여 준다. 코드는 이번 질문에 남긴 답의 요약이며, 재응답 때 바뀔 수 있다.
- 코드 네 칸에는 순서대로 돈, 준비, 함께 정하는 사람, 지친 날의 주제를 붙인다. 여덟 대문자 `V/S`, `W/D`, `U/F`, `H/A`는 각각 뜻 하나만 갖는다. 글자를 못 정한 칸은 `·`로 둔다.
- 코드를 읽은 다음 이번 답의 네 주제 문장과 마지막에 직접 고른 쪽과의 차이를 먼저 보여 준다. 직접 고른 쪽은 네 측면의 가중합에 들어가지 않지만, 완전 동점의 후순위 기준이 될 수 있다.
- 각 주제에는 실제 응답 수를 분모로 한 앞쪽·뒤쪽·중립의 **질문별 선택 방향 비율**을 표시한다. 문항 형식에 따라 선택 강도가 다르고 네 측면의 값을 같은 비중으로 합치므로, 가장 큰 단순 비율과 결과 글자가 다를 수 있다. 비율은 글자가 맞을 확률, 마음의 비율, 안정성, 궁합 수치가 아니다.
- 글자에 기여한 장면 묶음과 반대로 작용한 묶음을 실제 계산값으로 골라 설명한다. 답한 문항 수와 방향별 수를 함께 보인다. 뚜렷하지 않거나 동점 기준으로 글자를 적은 경우에는 한 묶음의 답을 글자의 원인으로 단정하지 않는다.
- 문항 인용은 사용자가 고른 원문만 사용한다. `이렇게 나타날 수 있어요`의 예시는 이번 사람에게 일어난 일로 말하지 않는다.
- `꾸미는 말 + 동물` 별칭은 이번 코드의 준비 행동을 장난스럽게 묶는 놀이용 이름이다. 예: `함께 살피는 수달`, `나눠 펼치는 여우`. 응답에 대한 새로운 심리 해석이나 유형 이름으로 쓰지 않는다. 정확한 뜻은 네 주제의 글자 설명과 응답 근거로 보여 준다.

## 두 사람 결과

- 각 사람의 네 글자 아래에 자리별 주제와 글자 뜻을 바로 붙인다. 어느 사람이 `나`인지 모르면 사용자가 기준을 고르게 하고, 이후 사람 순서와 문장도 그 기준에 맞춘다.
- 첫 대화 카드에는 서로 다르게 고른 실제 질문 하나와 양쪽의 실제 선택 문장을 보여 준다. 다음 장면으로 이동할 수 있다. 답하지 않은 마음이나 이유는 만들어 내지 않고 각자 말하도록 질문한다.
- 전체 주제에서는 두 사람 각각의 응답 분포를 각자의 분모로 보여 준다. 같은 글자라도 두 사람이 같은 측면에서 **각자 답한 문항의 과반수를 반대 방향으로 고른 경우에만** 그 장면을 강조한다. 비해당·중립이 많아 과반수가 없으면 강조하지 않는다.
- 두 사람의 코드를 합치거나 맞는 글자 개수, 궁합 점수, 관계 예측을 만들지 않는다.

## 공유와 판 호환

- `내 답과 함께 보내기`에는 먼저 답한 사람의 응답이 포함된다. 상대가 답을 마치면 상대 화면에서 두 사람 결과가 열리고, 내 화면에는 자동으로 생기지 않는다. 내게도 보이려면 상대가 **두 사람 결과 링크**를 다시 보내야 한다.
- 두 사람 답이 든 결과 링크는 링크를 받은 사람이 읽을 수 있으므로, 보내기 전에 그 사실을 밝히고 명시적 선택을 받는다. 답은 URL의 fragment에만 둔다.
- 문항 문구가 바뀐 v4.1은 `v4.1-depth`로만 열고, 이전 `v4.0-tendency` 응답과 섞지 않는다. v4.1의 질문만 보내는 주소에도 버전 이름을 반드시 넣는다.

## 공개 판단

합성 응답 테스트, 문안 정적 검사, 화면 확인은 구현 오류를 찾는 증거다. 실제 사람이 질문을 같은 뜻으로 읽는지, 답이 재검사에서 얼마나 바뀌는지, 결과가 서로의 준비 기준을 이해하는 데 도움이 되는지는 아직 확인되지 않았다. 작업 트리의 기본 입구는 검수를 위해 v4.1로 연결했다. 운영 배포에서의 기본 입구 전환과 홍보 문구는 사람 검증 기록을 남긴 뒤 결정한다.
