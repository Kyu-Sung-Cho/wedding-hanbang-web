## Phase 0: Evidence Spec

Define the source set, source grades, claim status, construct definitions, exclusion rules, and safety boundaries.

## Phase 1: Expert Review

Ask domain reviewers to inspect construct definitions, question drafts, report language, and product mappings for clarity, usefulness, and safety.

## Phase 2: Cognitive Interview

Interview users while they answer draft questions. Identify misunderstood wording, ambiguous scenarios, stigma risk, and whether answers map to the intended construct.

## Phase 3: 100-Person Smoke Test

Run a lightweight test with provisional questions and report copy to measure completion, self-recognition, CTA interest, and negative feedback.

## Phase 4: Couple Pilot

Test paired responses from couples to understand partner invitation, couple-report interest, disagreement patterns, and whether the result supports conversation rather than labeling.

## Phase 5: Psychometric Pilot

Evaluate reliability, construct separation, item performance, response distribution, and whether any construct should be merged, split, renamed, or retired.

## Phase 6: Behavioral Prediction

Measure whether WeddingCode signals help predict product-relevant behaviors such as checklist engagement, quote-check usage, partner invite, Amora CTA, and community participation. Do not frame this as marriage success or divorce prediction.

## Provisional Smoke Test Metrics

- completion rate >= 60-65%
- "feels like me" average >= 4.0/5
- partner invite click >= 20%
- couple report interest >= 10%
- Amora CTA >= 10-15%
- /check CTA >= 5%
- negative/stigma feedback < 5%
