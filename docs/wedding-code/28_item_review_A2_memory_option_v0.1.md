## 0. 결론

A2는 유지한다. 다만 "두고두고 기억에 남을 것 같은 옵션"은 말이 너무 추상적이고 테스트 문항처럼 들린다. 상품 문항으로는 사용자가 바로 장면을 떠올릴 수 있어야 한다.

v0.5에서는 아래처럼 바꾼다.

> 본식 영상이나 앨범처럼 나중에 다시 볼 것에 비용이 더 들어요. 나는 먼저 -

- A. 시간이 지나도 우리에게 의미 있을지 생각한다
- B. 전체 예산에서 감당되는 금액인지 본다
- C. 비슷하게 남길 다른 방법이 있는지 찾아본다
- D. 둘이 어떤 장면을 꼭 남기고 싶은지 얘기한다

이 문항은 "추억에는 돈을 써야 한다"를 유도하는 문항이 아니다.  
정확한 측정 의도는 **오래 남을 선택 앞에서 의미, 예산, 대안, 커플 기준 중 무엇을 먼저 확인하는가**다.

## 1. 이 문항이 필요한 이유

A1이 견적서 앞에서 정보 처리 순서를 본다면, A2는 돈이 더 드는 의미 항목 앞에서 판단 순서를 본다.

웨딩 준비에서 이 장면은 자주 발생한다.

- 본식 영상 추가
- 앨범 페이지 추가
- 원본/보정본 추가
- 스냅/DVD 구성 변경
- 드레스·촬영 스타일 업그레이드
- 꽃·공간 연출 변경

이때 사람들은 단순히 "비싸다/싸다"로만 결정하지 않는다. 나중에 다시 볼 가치, 예산의 안정감, 비슷한 대안, 파트너와 남기고 싶은 장면이 함께 들어온다.

제품적으로 A2는 결과 화면에서 "우리가 무엇을 오래 남기고 싶은가"라는 대화 카드로 이어지기 좋다. 공유성과 실용성이 모두 있다.

## 2. 근거 레이어

### 2.1 시장 구조 근거

웨딩의 "오래 남는 항목"은 실제 추가 비용과 연결된다.

- 정부 결혼서비스 실태조사(2024)는 스드메 기본금과 실제 지불액 사이에 큰 추가금 차이가 있음을 보여준다.
- 한국소비자원 참가격은 스튜디오 원본 구매, 앨범 페이지 추가, 본식 촬영, 드레스 헬퍼비 등 기본품목과 선택품목을 나눠 다룬다.
- 따라서 "나중에 다시 볼 것에 비용이 더 들어가는 장면"은 가상의 심리 상황이 아니라 실제 웨딩 견적 구조와 연결된다.

### 2.2 소비자 심리 근거

경험 구매 연구는 경험이 만족, 기억, 사회적 연결과 관련될 수 있음을 보여준다. 다만 이 근거를 "웨딩에서는 돈을 더 써야 행복하다"로 쓰면 안 된다.

참고할 수 있는 해석:

- 경험적 구매는 물질 구매보다 만족·기억·사회적 연결과 더 강하게 연결된다는 연구 흐름이 있다.
- 동시에 특별한 생애 사건에서는 기념물이나 기록물처럼 물리적으로 남는 것이 시간이 지나 의미 연결을 유지하는 데 도움을 줄 수 있다는 연구도 있다.
- 웨딩 맥락에서는 사진과 영상이 "추억"인 동시에 "완벽해야 한다"는 사회적 압박으로 작동할 수 있다는 소비자정책 연구도 있다.

제품 적용:

- "오래 남는 것"을 과소비 정당화로 쓰지 않는다.
- "예산을 보는 답"을 차갑거나 덜 로맨틱한 답으로 만들지 않는다.
- 사진·영상·앨범은 만족의 근거이기도 하지만 압박의 근거가 될 수 있으므로, 결과 문구는 부드럽고 중립적이어야 한다.

### 2.3 근거로 주장할 수 없는 것

아래는 금지한다.

- 오래 남는 항목에 돈을 쓰는 사람이 더 행복하다고 말한다.
- 영상/앨범을 하지 않으면 후회한다고 말한다.
- 예산을 먼저 보는 사람은 추억을 덜 중요하게 여긴다고 말한다.
- 의미를 먼저 보는 사람은 현실감이 없다고 말한다.
- "남는 건 사진뿐" 같은 압박 문구를 쓴다.

정확한 표현은 이것이다.

> 이 문항은 오래 남을 수 있는 항목 앞에서 각자가 먼저 안정되는 판단 기준을 보여준다.

## 3. 기존 문항 감사

### 3.1 현재 코드

`apps/web/src/constants/weddingCodeForm.ts`의 q02:

> 두고두고 기억에 남을 것 같은 옵션인데, 추가 비용이 있대요. 이럴 때 나는 —

- A. 시간이 지나도 의미 있을지를 먼저 생각한다
- B. 예산 안에서 감당되는지부터 계산한다
- C. 비슷한 느낌의 다른 선택지를 찾아본다
- D. 어떤 장면을 남기고 싶은지 둘이 얘기한다

### 3.2 좋은 점

- 네 선택지가 의미, 예산, 대안, 커플 대화로 잘 나뉜다.
- 특정 성별이나 역할을 전제하지 않는다.
- "추가 비용"이라는 실제 웨딩 장면과 연결된다.
- 결과 카드에서 커플 대화로 이어지기 쉽다.

### 3.3 위험

| 위험 | 이유 | 처리 |
|---|---|---|
| 상황이 추상적임 | "옵션"만으로는 무엇을 말하는지 사용자가 상상해야 한다 | 본식 영상·앨범 예시를 넣음 |
| A가 더 로맨틱한 정답처럼 보임 | "기억에 남는다"는 프레이밍이 의미 선택을 밀 수 있다 | 질문에서 "나중에 다시 볼 것"으로 중립화 |
| B가 차갑게 보임 | 예산 계산이 추억을 포기하는 답처럼 읽힐 수 있다 | "감당되는 금액인지 본다"로 안정감 언어 사용 |
| C가 우유부단해 보임 | 대안 탐색이 결정을 미루는 답처럼 보일 수 있다 | "비슷하게 남길 방법"으로 목적을 분명히 함 |
| D와 A가 겹칠 수 있음 | 의미 생각과 장면 대화가 모두 추억 중심 | A는 개인 판단, D는 커플 기준 맞추기로 분리 |

## 6. 결과 문구 가드레일

### 6.1 단독 결과 문구

A 선택:

> 비용이 더 들더라도, 시간이 지나 다시 봤을 때 우리에게 의미 있을지를 먼저 생각하는 쪽이에요.

B 선택:

> 의미가 있는 선택이어도, 전체 예산 안에서 마음 편히 감당되는지 먼저 확인해야 안정되는 쪽이에요.

C 선택:

> 포기하거나 바로 고르기보다, 비슷하게 남길 수 있는 다른 방법을 먼저 찾아보려는 쪽이에요.

D 선택:

> 혼자 판단하기보다, 둘이 어떤 장면을 꼭 남기고 싶은지 먼저 맞춰보려는 쪽이에요.

### 6.2 금지 문구

- 추억형
- 현실형
- 낭만형
- 절약형
- 과소비형
- 영상/앨범은 꼭 해야 하는 타입
- 추억을 더 중요하게 여기는 타입
- 예산 때문에 추억을 포기하는 타입

이 문항은 "무엇을 해야 한다"가 아니라 "무엇을 먼저 확인하면 마음이 놓이는가"를 말한다.

## 7. 커플 공유 문구

### 7.1 A와 B가 갈릴 때

> 한 사람은 시간이 지나도 의미 있을지를 먼저 보고, 한 사람은 예산 안에서 마음 편히 감당되는지를 먼저 보고 싶어 해요. 둘 다 필요한 기준이라서, 먼저 "꼭 남기고 싶은 장면 2개"와 "넘지 않을 금액"을 같이 정해보면 좋아요.

### 7.2 A와 D가 함께 강할 때

> 두 분 모두 오래 남는 의미를 중요하게 보는 편이에요. 다만 혼자 마음속으로 판단하기보다, 어떤 장면을 꼭 남기고 싶은지 말로 꺼내면 선택이 훨씬 쉬워져요.

### 7.3 B와 C가 함께 강할 때

> 두 분 모두 마음에 든다고 바로 고르기보다, 예산과 대안을 확인하고 움직이는 쪽에 가까워요. 장점은 후회가 적다는 것이고, 조심할 점은 너무 오래 찾다가 결정이 늦어질 수 있다는 거예요.

### 7.4 한쪽은 A/D, 한쪽은 B/C일 때

> 한 사람은 "무엇을 남길까"를 먼저 보고, 한 사람은 "어떻게 감당할까"를 먼저 봐요. 기준이 다른 것이지 마음이 다른 것은 아니에요. 장면을 먼저 정하고 금액을 맞추면 대화가 부드러워져요.

금지:

- "둘은 추억 소비 성향이 달라요"
- "한쪽은 현실적이고 한쪽은 감성적이에요"
- "추억에 돈을 쓰는 쪽/아끼는 쪽"

허용:

- "먼저 안정되는 기준"
- "꼭 남기고 싶은 장면"
- "넘지 않을 금액"
- "비슷하게 남길 다른 방법"

## 8. 인터뷰 확인 질문

A2 직후 아래를 확인한다.

1. "본식 영상이나 앨범" 예시가 바로 이해됐나요?
2. 아직 그 단계가 아니어도 답할 수 있었나요?
3. 선택지 중 더 좋아 보이거나 더 책임감 있어 보이는 답이 있었나요?
4. 예산을 먼저 보는 답이 차갑거나 덜 낭만적으로 느껴졌나요?
5. 의미를 먼저 보는 답이 과소비나 허영처럼 느껴졌나요?
6. A와 D가 서로 다른 선택처럼 느껴졌나요?
7. 말투가 사람 말 같았나요, 아니면 AI가 만든 문장 같았나요?

특히 4번과 5번은 필수다. A2는 낙인 양방향 위험이 있다.

## 9. 통과 기준

n=5 인지 인터뷰:

- realism 평균 4.0 이상
- clarity 평균 4.0 이상
- self-fit 평균 3.8 이상
- stage-fit 문제 1명 이하
- right-answer-risk "강함" 0명
- stigma-risk "강함" 0명
- A와 D 구분 실패 1명 이하

n=20 미니 테스트:

- A 선택 비율이 60% 이상이면 의미 선택지가 너무 매력적으로 보이는지 확인
- B 선택 비율이 10% 이하이면 예산 선택지가 차갑게 보이는지 확인
- C 선택 비율이 10% 이하이면 대안 탐색이 우유부단하게 보이는지 확인
- D 선택 비율이 A와 강하게 겹치면 D를 커플 합의 문항으로 이동
- "상대 답이 궁금하다" 응답이 70% 미만이면 커플 대화 문항으로서 실패

## 11. 다음 결정

코드 반영은 16개 문항 전체의 v0.5 심층 리뷰가 끝난 뒤 한 번에 한다.

이유:

- A2는 A1과 함께 "결정 기준" 축을 만든다. A1은 정보 처리, A2는 의미 지출 판단으로 역할이 분리된다.
- A2를 너무 감성적으로 만들면 웨딩한방의 신뢰가 약해지고, 너무 계산적으로 만들면 공유성이 죽는다.
- 따라서 문항·결과·커플 공유 문구를 세트로 고정한 뒤 코드에 넣어야 한다.
