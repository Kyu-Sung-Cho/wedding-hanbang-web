## 확인된 피드백

- 선택지의 뜻과 경계가 분명하지 않았다.
- 견적 질문에서 금액, 취향, 포함 내용, 다른 사람의 경험이 한 질문 안에서
  뒤섞여 보였다.
- `무엇을 줄일지` 같은 표현은 무엇을 전제로 하는지 모르는 사용자에게 모호했다.
- 결혼 준비를 전혀 모르는 사람도 질문만 읽고 상황을 이해할 수 있어야 했다.

## candidate.3의 목적

candidate.2의 문장 길이와 말투는 개선됐지만 일부 선택지는 설계 개념을 짧게 줄인
표현에 가까웠다. candidate.3은 자연스러운 말투보다 다음 기준을 먼저 적용하려 한
후보였다.

1. 초보자가 처음 읽어도 상황을 이해할 수 있어야 한다.
2. 각 선택지는 다른 선택지와 무엇이 다른지 설명 없이 구분돼야 한다.
3. 취향, 포함 내용, 확인 자료, 다른 사람의 경험을 한 선택지 안에 섞지 않는다.
4. 사용자가 실제로 선택하거나 확인할 수 있는 말로 쓴다.

## A1에서 확인하려던 구분

손상된 기록상 A1은 처음 받은 촬영·드레스·메이크업 견적을 볼 때 무엇을 먼저
확인하는지 묻는 장면이었다. candidate.3은 다음처럼 서로 다른 확인 대상을
분리하려 했다.

- 최종 금액이 정한 예산 안에 들어오는가
- 원하는 사진 분위기와 맞는가
- 계약에 포함된 내용과 별도 금액은 무엇인가
- 실제 이용한 사람의 경험은 어떠한가

위 문장은 손상된 원문을 그대로 복원한 것이 아니라 당시 구분 의도를 요약한
것이다. 현재 문항으로 재사용하지 않는다.

## 당시 전체 문구 원칙

- 미완성 문장을 쓰지 않는다.
- `기준`, `방향` 같은 추상어를 구체적인 확인 행동으로 바꾼다.
- 한 선택지에는 하나의 판단 대상만 둔다.
- 업계용어가 필요하면 뜻을 문항 안에서 먼저 설명한다.
- 압축된 표현 대신 실제 행동이나 확인 문장으로 쓴다.
