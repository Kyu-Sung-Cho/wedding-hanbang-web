# 마지막 자기 선택 4문항 전수 감사

작성·적대적 검수·주장 감사 후 수정안. 원래 문항 ID, 순서, 두 방향, 키와 응답 강도는 유지한다. 마지막 자기 선택은 본인의 예상으로 표시하고, 앞선 응답 합이 여러 기준에서도 동점일 때만 최종 방향 기준으로 쓴다.

| 문항 | 확인한 문제 | 수정 |
| --- | --- | --- |
| self.money | V의 총액 한 가지를 전체 조건 기준으로 대표함 | 비용과 조건을 함께 명시하고 돈 결정이라는 상황 유지 |
| self.process | 각자 마무리한 뒤에만 맞추는 것으로 읽혀 중간 공유까지 금지하는 것처럼 보임 | 각자 맡되 필요할 때 맞춘다는 범위로 수정 |
| self.scope | ‘가족과의 사이가 어떻든’은 불필요하고 정서적 관계를 연상시킴 | 가족 의견을 듣는 시점과 둘의 안을 정하는 시점만 비교 |
| self.support | ‘둘 중 누가 지친 날이면 이야기를 들어요’는 내가 지쳐도 들어 주는 행동으로 읽힘 | 마음을 말하고 듣기 vs 남은 일을 덜 방법을 정하기, 동일한 지친 날의 첫 순서로 비교 |

적대적 검수: 가족 의견을 듣는 것이 복종이나 가족관계의 좋고 나쁨을 뜻하지 않으며, 도움의 첫 순서는 공감 능력·성실성을 뜻하지 않는다. 보기는 같은 상황의 한 기준이며 특정 응답을 좋은 답처럼 칭찬하지 않는다.

주장 감사: 이 네 문항은 본인의 자기 선택을 기록할 뿐 실제 행동과 숨은 내면의 일치를 증명하지 않는다. 사람 이해·재검사 자료는 없다.

최종 정적 검수에서 돈과 준비의 두 보기 길이 차이가 허용 범위를 넘어, 비용·계약 조건을 함께 살핀다는 말과 함께 맞춘다는 말을 보충했다. 의미·방향·강도는 유지하며 최종 68개 병합 검사 오류·경고는 0/0이다.
