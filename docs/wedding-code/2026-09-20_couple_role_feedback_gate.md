## 정확한 해석

B1·B3·B4·B5의 A는 함께, B는 내가, C는 상대가 고르기다.

| 조합 | 설명 |
|---|---|
| AA | 둘 다 함께 고르겠다고 답했어요. |
| BB | 둘 다 직접 고르겠다고 답했어요. |
| CC | 둘 다 상대에게 선택을 맡기겠다고 답했어요. |
| BC·CB | 한 사람은 직접 고르겠다고, 다른 한 사람은 그 사람에게 맡기겠다고 답했어요. |
| AB·BA·AC·CA | 함께 고르자는 답과 한 명이 정하자는 답이 나왔어요. |

BB의 다음 대화: “서로 꼭 반영하고 싶은 조건을 하나씩 말해 보세요. 그다음 함께 고를지, 한 사람이 맡을지 정해 보세요.”

CC는 누가 선택할지를 먼저 묻는다.

- B1: 방문할 세 곳은 누가 추리면 좋을까요? 꼭 가 보고 싶은 곳이나 빼고 싶은 곳을 먼저 말해 두세요.
- B3: 여행지는 누가 고르면 좋을까요? 꼭 하고 싶은 일정이나 피하고 싶은 조건을 먼저 말해 두세요.
- B4: 항공권은 누가 고르면 좋을까요? 결제 전에 서로 확인할 것도 정해 두세요.
- B5: 점심에 연락할 때 날짜를 누가 고를지 정해 보세요. 오후 6시 전에 식장에 알릴 사람도 함께 정해 두세요.

B2는 A=모두 함께 참석, B=하나씩 나누기, C=내가 모두 참석, D=상대가 모두 참석이다.

| 조합 | 설명 |
|---|---|
| AA | 둘 다 두 상담에 함께 가겠다고 답했어요. |
| BB | 둘 다 상담을 하나씩 나눠 가겠다고 답했어요. |
| CC | 둘 다 두 상담을 혼자 다녀오겠다고 답했어요. |
| DD | 둘 다 두 상담을 상대에게 맡기겠다고 답했어요. |
| CD·DC | 한 사람은 두 상담을 혼자 다녀오겠다고, 다른 한 사람은 그 사람에게 맡기겠다고 답했어요. |
| AB·BA | 두 상담 모두 같이 가자는 답과 하나씩 나눠 가자는 답이 나왔어요. |
| AC·CA·AD·DA | 두 상담 모두 같이 가자는 답과 한 명이 두 상담에 다 가자는 답이 나왔어요. |
| BC·CB·BD·DB | 상담을 하나씩 나눠 가자는 답과 한 명이 두 상담에 다 가자는 답이 나왔어요. |

B2의 다음 대화와 나머지 조합의 다음 대화는 현재 문항별 안내를 유지한다. 상담 참석과 업체 선택을 혼동하지 않는다.

## 적대적 검수·주장 감사 — 내부 통과

독립 읽기 검수와 원문 대조를 마쳤다. B4의 기존 위임 허용과 B5의 점심 연락·오후 6시 마감을 보존한다. 답만으로 갈등, 상호 보완, 담당자 확정이나 합의 완료를 말하지 않는다. BB·CC는 같은 보기를 골랐다는 집계를 유지하고, BC·CB는 다른 보기라는 집계를 유지한다. 이 설명은 두 사람의 실제 담당자를 저장하지 않는다.

공개 비교의 추천과 전체 나란히 보기, 로그인 비교에 같은 함수를 사용한다. 같은 답은 추천에 나타나지 않으므로 전체 비교에서도 설명을 제공한다. 새 안내가 생긴 뒤 “따로 적지 않았다”는 소개를 v1.2에 남기지 않는다. 역할 추천 제목은 “누가 맡을지 얘기해 보세요”로 쓴다. 구판·없는 보기·한쪽 미응답에는 새 해석을 붙이지 않는다.

문항·scoring gate는 기존 v1.2 검토를 유지한다. 위 copy gate는 코드 반영 전 내부 검토 통과이며 소비자 검증이나 배포 증거가 아니다.
