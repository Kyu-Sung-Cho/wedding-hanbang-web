## 범위와 완료 기준

문항별 판정은 [돈·준비 32개](./2026-10-06_v42_money_process_audit.md), [범위·도움 32개](./2026-10-06_v42_scope_support_audit.md), [자기 선택 4개](./2026-10-06_v42_self_audit.md)에 있다. 각 문서는 대안 비교 → 초안 → 적대적 검수 → 주장 감사 → 수정 순서로 정리했다. root는 두 수정안 32개씩을 직접 읽고 아래 오해를 다시 교정하도록 검수했다.

## 수정한 핵심 오해

- 돈: 여유금을 쓰는 곳, 안전한 계약 대 위험한 선택을 V/S로 묻던 부분을 고쳤다. 기본 조건을 양쪽 모두 확인한 뒤 비용 자료와 그날의 경험 중 먼저 볼 기준을 묻는다.
- 준비: 위임을 미루기·방치로 쓰거나, 같이 하기 보기에만 좋은 이유를 붙이던 부분을 고쳤다. 공동 진행과 맡은 몫의 진행을 같은 상황에서 비교한다.
- 범위: 전통 선호·하객 관계·원래 선택 고집을 U/F로 읽던 부분을 고쳤다. 같은 후보나 초안에서 가족 의견을 어느 단계에 모을지 묻는다. 두 식당 모두 참석 가능한 조건도 명시했다.
- 도움: 정리 습관·체력·미래의 감정 결과를 H/A로 읽던 부분을 고쳤다. 같은 힘든 장면에서 마음을 듣거나 남은 부담을 덜 첫 행동을 묻는다. 실제 메시지를 고르라는 질문은 실제 메시지 보기로 맞췄다.
- 회상: 결혼 준비 경험이 없는 사람이 답하기 어려웠던 8개는 최근 숙소·큰 구매·함께 맡은 일·의사결정·모임·도움·피로의 실제 과거로 넓혔다. 일상 경험의 웨딩 전이는 미검증이다.
- 자기 선택: 돈·준비 보기의 길이 차이가 정적 gate에 걸려 두 방향의 문장 길이를 맞춰 다시 검사했다.

[결과 읽기 계약](./2026-10-06_v42_result_contract.md)을 따른다. `check`, `worth`, `form`, `recover`의 이름·예시·대화 질문을 v4.2 범위로 바꾸며 v4.0/v4.1 설명은 보존한다. 선택 개수/답한 문항 수, 원문 질문, 실제 답, 한 글자가 모든 장면을 뜻하지 않는다는 설명을 함께 보인다. 심리 진단·내면 정확도·궁합·결혼 결과·희귀도는 주장하지 않는다.

## 통과 범위와 남은 검증

이 gate는 사용자가 요청한 **로컬 후보 코드 반영**을 위한 문서 검수다. 실제 사람의 문항 이해·안정성·유용성은 0건 / UNVALIDATED. 0a·0b·G3를 통과했다고 적지 않는다. 공개 검증 완료로 다루기 전에는 사람들이 상황과 각 보기의 뜻을 재진술하고 선택 이유·정답감·비해당 이유를 설명하는 자료가 필요하다. 반복되는 명단/연락 소재와 네 측면의 구분도 그 자료로 판단해야 한다.
