# 공개 응답 설명 정정 — 2026-09-11

상태: 공개 v0.8 20장면의 로컬 수정 후보. 운영 배포·사람 타당도 검증 완료를 뜻하지 않는다.
현재 README의 공개 장면 계약을 적용한다. 문서 31은 읽었으나 RETIRED인 Candidate 4 생성 규칙과 16문항 게이트를 재사용하지 않는다.

## 문제와 선택

B5:A는 전화에 응답하지 못해 답이 늦어진 경험이다. 기존 T 집계에 들어가지만 이것만으로 함께 검토했다고 말할 수 없다. 기존 결과 제목은 한 장면만 답해도 반복했다고 표현했다.

- 후보 A: B5 가중치나 문항을 바꾼다. 현재 공유 코드의 의미와 집계가 달라져 이번 수정에서 제외한다.
- 후보 B: 문항·가중치·코드·인용을 보존하고 출력 설명만 실제 집계로 한정한다. 현재 후보는 이 안이다.

T 설명은 ‘함께 확인하는 과정과 연락 경험에 관한 답’이라는 주제로 한정한다. 축 본문은 두 주제를 적어 실제 답 수를 보여주고, 동점 제목도 실제 공동 검토로 바꾸지 않는다. repeated/missingPhrases의 사용자용 문구도 같은 주제로 맞췄다. 연락 지연을 실제로 고른 경우에만 그 경험과 공동 검토의 차이를 기존 안내에 덧붙인다. 이 확인은 표시 인용 두 개로 축약하기 전의 실제 선택 문장 전체를 기준으로 하며, 고르지 않은 사람에게 지연 경험을 경고하지 않는다. 내부 분류가 맞으니 사용자가 이해해야 한다는 설명을 하지 않는다. 현재 원하는 연락 담당이나 공동 검토 범위는 직접 이야기할 질문으로 남긴다.

개인·두 사람 결과 제목은 각각 ‘내가 이번에 고른 것’, ‘각자 이번에 고른 것’으로 한다. 여러 장면에 답해도 같은 행동을 반복한 경험이 확인되는 것은 아니므로 단순 답 수만으로 반복을 주장하지 않는다.

## 적대적 확인과 한계

B5 단독·다른 세 선택·여러 장면 혼합·동점·미응답을 대조한다. 독립 검수에서 혼합 제목의 남은 해석, coPreparation 부재 문구, 모호한 이쪽 표현, 지연 미선택자에게 나가는 주의를 지적받아 후속 실패 회귀 후 보완했다. 배지에서만 과장을 지우고 아래 축 제목·집계 설명에 같은 단정을 남기지 않는다. 단독 및 커플 결과 렌더에서 원래 선택 문장과 답한 수가 함께 남고, 단독 결과의 기존 공유 답 문자열이 유지되는지 확인한다. 기존 직접 도움 설정은 미선택 기본값과 명시 확인 저장 경계를 유지한다.

이 보완은 원래 T 묶음의 서로 다른 상황을 더 정확히 설명하는 카피 수정이다. 문항 이해도·선택지 포괄성 자체를 해결하거나 전체 유형 해석의 타당도를 보장하지 않는다. 실제 배포와 화면 재검증은 별도 릴리스 영수증으로 확인한다.
