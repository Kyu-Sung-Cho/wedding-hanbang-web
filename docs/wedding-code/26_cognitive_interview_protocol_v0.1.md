## 0. 인터뷰 원칙

이 인터뷰는 사용자를 평가하는 자리가 아니다. 문항을 평가하는 자리다.

진행자는 아래 문장을 처음에 말한다.

> 오늘은 당신의 성향을 판단하려는 게 아니라, 웨딩코드 문항이 실제 결혼 준비 상황처럼 느껴지는지 확인하려고 합니다. 답변에 정답은 없고, 어색하거나 불편한 문장이 있으면 그게 가장 중요한 피드백입니다.

금지:

- "왜 그렇게 답했어요?"를 추궁하듯 묻기.
- 특정 답변이 더 좋다는 반응 보이기.
- 답변 후 바로 유형/점수 말하기.
- 커플 궁합, 결혼 성공, 이혼 가능성 언급.

---

## 1. 참여자 구성

최소 n=5.

권장 구성:

| 참여자 | 조건 |
|---|---|
| P1 | 결혼 얘기 시작 전/초기 |
| P2 | 예식장 알아보는 중 |
| P3 | 스드메/견적 경험 있음 |
| P4 | 가족 관여도가 높은 케이스 |
| P5 | 이미 계약 경험 있음 |

가능하면 성별, 지역, 예산대, 가족 관여도, 혼자/함께 답변 여부가 섞이게 한다.

---

## 2. 진행 방식

예상 시간: 35~50분.

순서:

1. 2분: 목적 설명과 동의.
2. 5분: 결혼 준비 단계/상황 파악.
3. 20~30분: 16문항 think-aloud 응답.
4. 5분: 결과 카드 컨셉 반응.
5. 5분: 공유/커플 대화 의향 확인.

진행 중 참여자에게 요청:

> 문항을 읽으면서 머릿속에 드는 말을 그대로 해주세요. "이게 무슨 말이지?", "이건 너무 모범답안 같은데?", "나는 이런 답이 없는데?" 같은 말이 제일 도움이 됩니다.

---

## 3. 사전 질문

1. 지금 결혼 준비 단계는 어디에 가장 가깝나요?
2. 업체 상담이나 견적을 받아본 적이 있나요?
3. 결혼 준비를 주로 혼자 하나요, 상대와 같이 하나요?
4. 부모님/가족이 준비 결정에 어느 정도 관여하나요?
5. 지금 제일 신경 쓰이는 준비 문제는 무엇인가요?

---

## 4. 문항별 확인 질문

각 문항 답변 직후 아래 5개 중 필요한 것만 묻는다.

### 필수 3문항

1. 이 상황이 실제 결혼 준비에서 있을 법하게 느껴졌나요?
2. 선택지 중 "이게 정답이겠네"처럼 보인 답이 있었나요?
3. 내 반응에 가까운 답이 있었나요?

### 필요 시 추가

4. 말투가 어색하거나 AI 같았던 부분이 있나요?
5. 이 문항이 나를 평가하거나 불편하게 만든 부분이 있나요?

기록 방식:

| 항목 | 척도 |
|---|---|
| realism | 1~5 |
| clarity | 1~5 |
| self-fit | 1~5 |
| right-answer-risk | 없음/약함/강함 |
| stigma-risk | 없음/약함/강함 |
| awkward-copy | 자유기록 |

---

## 5. 축별 집중 확인

### A축. 결정 기준

확인하고 싶은 것:

- 비용 확인 선택지가 너무 정답처럼 보이는가?
- 의미/무드 선택지가 낭비처럼 보이는가?
- 최신 가격 근거가 필요한 문항이 있는가?

추가 질문:

> 비용을 먼저 본다는 답이 "현실적인 정답"처럼 느껴졌나요, 아니면 그냥 한 가지 성향처럼 느껴졌나요?

### B축. 준비 방식

확인하고 싶은 것:

- 같이 보는 선택지가 더 사랑 있는 답처럼 보이는가?
- 맡아서 정리하는 선택지가 무관심/독단처럼 보이는가?
- 성별 역할로 읽히는 문장이 있는가?

추가 질문:

> "한 사람이 먼저 정리한다"는 답이 책임감 있게 느껴졌나요, 아니면 독단적으로 느껴졌나요?

### C축. 조율 범위

확인하고 싶은 것:

- 가족을 문제처럼 그리지 않는가?
- 커플 기준이 반가족처럼 보이지 않는가?
- 부모님/양가 표현이 자연스러운가?

추가 질문:

> 가족 이야기가 나오는 문항이 부담스럽거나 한쪽 편을 들게 만드는 느낌이 있었나요?

### D축. 지원 순서

확인하고 싶은 것:

- 공감 먼저 선택지가 더 좋은 사람처럼 보이는가?
- 실행 먼저 선택지가 차갑게 보이는가?
- 상대를 비난하는 문항처럼 읽히는가?

추가 질문:

> 이 문항이 "상대가 문제다"처럼 느껴졌나요, 아니면 "서로 기대하는 반응이 다를 수 있다"처럼 느껴졌나요?

---

## 6. 결과 카드 컨셉 테스트

아직 실제 동물명/유형명을 확정하지 않는다. 아래처럼 컨셉만 보여준다.

### 보여줄 예시

> 현재 답변으로는 "꼼꼼한 ○○"에 가까워요.  
> 이 이름은 성격 진단이 아니라, 결혼 준비 때 먼저 보는 기준을 기억하기 쉽게 만든 별명입니다.

질문:

1. 이런 식의 형용사+동물 별명이 있으면 공유하고 싶나요?
2. 별명이 나를 평가하는 느낌이 있나요?
3. 어떤 표현은 피해야 할 것 같나요?
4. "현재 답변으로는 ~에 가까워요"라는 표현이 충분히 조심스럽게 느껴지나요?

금지:

- 실제 동물명 16종 확정.
- "희귀 유형" 표시.
- "커플 궁합" 표시.

---

## 7. 커플 공유 컨셉 테스트

보여줄 문구:

> 상대와 비교하면, 두 분이 비슷하게 보는 지점과 먼저 맞춰보면 좋은 지점을 보여드려요. 점수로 누가 맞는지 판단하지 않고, 오늘 이야기해볼 질문을 제안합니다.

질문:

1. 이 결과를 상대에게 보내보고 싶나요?
2. 보내고 싶다면 왜인가요?
3. 보내기 꺼려진다면 어떤 부분 때문인가요?
4. "준비 방식 겹침도"라는 표현은 괜찮나요?
5. "커플 적합도"나 "궁합"이라는 말이 들어가면 느낌이 어떻게 달라지나요?

성공 신호:

- "이걸로 얘기해볼 수 있겠다."
- "상대 답이 궁금하다."
- "싸우자는 느낌은 아니다."

위험 신호:

- "평가받는 느낌이다."
- "상대가 이걸 무기로 쓸 것 같다."
- "궁합 낮으면 기분 나쁠 것 같다."

---

## 8. 종료 질문

1. 가장 공감된 문항은 무엇인가요?
2. 가장 어색하거나 AI 같았던 문항은 무엇인가요?
3. 꼭 빠져야 한다고 느낀 문항이 있나요?
4. 추가됐으면 하는 결혼 준비 상황이 있나요?
5. 이 테스트를 친구/상대에게 공유한다면 어떤 이유일까요?

---

## 9. 통과 기준

문항 단위:

- realism 평균 4.0 이상
- clarity 평균 4.0 이상
- self-fit 평균 3.8 이상
- right-answer-risk 강함 0명
- stigma-risk 강함 0명

전체 테스트 단위:

- 5명 중 4명 이상이 "상대 답이 궁금하다"고 말할 것.
- 5명 중 4명 이상이 "결혼 준비 이야기거리로 쓸 수 있다"고 말할 것.
- "궁합/적합도" 표현은 부정 반응이 강하면 완전 폐기.

수정 규칙:

- 한 문항에서 2명 이상이 어색하다고 말하면 카피 수정.
- 한 선택지가 4명 이상에게 정답처럼 보이면 선택지 재설계.
- 한 문항이 2명 이상에게 평가/낙인 느낌을 주면 문항 폐기 후보.
