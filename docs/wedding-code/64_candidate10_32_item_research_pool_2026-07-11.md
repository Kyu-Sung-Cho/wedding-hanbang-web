# WeddingCode candidate.10 32문항 연구 풀

- 작성일: 2026-07-11
- 상태: 사람 대상 검증 전 연구 후보
- 목적: 현재 실행 16문항을 최종안으로 고정하지 않고, 축별 대체 문항과 경쟁시키기 위한 최소 32문항 풀

## 1. 사용 규칙

- 실행 중인 A1~D4 16문항은 [`63_candidate10_evidence_based_rebuild_2026-07-11.md`](./63_candidate10_evidence_based_rebuild_2026-07-11.md)에 있다.
- 아래 A5~D8 16문항은 대체 연구 후보다.
- 한 참여자에게 32문항을 무조건 전부 보여주지 않는다. 균형 무작위 배정 또는 두 폼으로 나눠 피로와 순서효과를 관리한다.
- 각 문항은 한 축의 두 시작점만 비교한다.
- 어느 문항도 채택이 확정되지 않았다.
- 인지면접에서 선택지 누락, 모범답안, 혼입, 낙인 위험이 반복되면 삭제한다.

## 2. 결정 시작점 대체 후보

### A5. 식사 구성을 더할 때

질문:

> 식사 구성을 한 단계 올리면 전체 비용이 늘지만 초대 손님의 식사 경험은 달라질 수 있어요. 둘이 이야기를 시작할 때 먼저 꺼낼 것은?

- `left / 조건 먼저`: 인원까지 곱했을 때 늘어나는 전체 금액
- `right / 장면 먼저`: 초대 손님에게 어떤 식사 경험을 남기고 싶은지

근거: KCA 결혼서비스 가격 품목·최소 인원 장면, 제품 가설.

위험: `손님 경험`이 C축 주변 조율로 교차 해석될 수 있음. 교차적재가 확인되면 삭제.

### A6. 드레스 추가 선택

질문:

> 마음에 드는 드레스를 고르면 추가 비용이 생겨요. 선택을 다시 볼 때 먼저 확인할 것은?

- `left / 조건 먼저`: 추가 비용과 기본 가격에 들어 있는 범위
- `right / 장면 먼저`: 입었을 때 원하는 모습과 사진에 남을 느낌

근거: KCA 결혼서비스 기본·선택 품목 장면, 제품 가설.

위험: `추가 비용 확인`이 명백한 안전 답처럼 보이는지 확인.

### A7. 초대장 두 디자인

질문:

> 초대장 두 디자인이 남았어요. 하나는 가격과 제작 일정이 더 안정적이고, 하나는 우리가 원한 분위기에 더 가까워요. 먼저 볼 쪽은?

- `left / 조건 먼저`: 제작 가격·수량·받는 날짜
- `right / 장면 먼저`: 처음 받았을 때 전하고 싶은 분위기

근거: 큰 결정을 넘어 작은 웨딩 선택에서도 같은 시작점이 반복되는지 보는 제품 가설.

위험: 초대장 관심도가 낮은 사용자에게 무의미한지 확인.

### A8. 촬영일 변경 조건과 사진 분위기

질문:

> 두 사진 업체 중 한 곳은 일정 변경 조건이 더 분명하고, 다른 곳은 사진 분위기가 더 마음에 들어요. 다시 볼 때 먼저 확인할 쪽은?

- `left / 조건 먼저`: 날씨·일정 변경과 취소 조건
- `right / 장면 먼저`: 우리가 원하는 빛과 사진 분위기

근거: KCA 계약 변경·취소 장면, 제품 가설.

위험: 취소 조건이 안전상 우월한 답으로 느껴지는지 확인.

## 3. 준비 시작점 대체 후보

### B5. 업체 목록을 처음 만들 때

질문:

> 알아볼 업체 목록을 처음 만들려고 해요. 시작 방식으로 더 편한 것은?

- `left / 같이 맞춤`: 둘이 기준을 정하고 같은 목록에 함께 넣는다
- `right / 맡아 정리`: 한 사람이 기준에 맞는 곳을 먼저 모아 공유한다

근거: 사안별 부부 의사결정 연구, 제품 가설.

위험: 실제 관심도 차이가 성향 대신 답을 결정하는지 확인.

### B6. 업체에 전화해 확인할 때

질문:

> 업체에 전화해 날짜와 조건을 확인해야 해요. 더 편한 방식은?

- `left / 같이 맞춤`: 질문을 같이 정하고 통화 내용을 함께 확인한다
- `right / 맡아 정리`: 담당자가 질문하고 핵심 답만 정리해 공유한다

근거: 준비 노동 분담·사안별 의사결정 제품 가설.

위험: 전화 불안, 근무시간, 언어 능력이 성향처럼 측정되는지 확인.

### B7. 주간 체크리스트

질문:

> 이번 주 체크리스트를 정하려고 해요. 시작 방식으로 더 편한 것은?

- `left / 같이 맞춤`: 함께 목록을 보며 이번 주 우선순위를 정한다
- `right / 맡아 정리`: 분야별 담당이 이번 주 할 일을 정해 합친다

근거: 공동·위임 대처와 역할 분담 제품 가설.

위험: 이미 쓰는 도구 유무가 답을 좌우하는지 확인.

### B8. 초대 명단 자료 모으기

질문:

> 초대 명단에 넣을 연락처와 정보를 모아야 해요. 더 편한 방식은?

- `left / 같이 맞춤`: 한 목록을 같이 보며 빠진 사람과 정보를 확인한다
- `right / 맡아 정리`: 각자 맡은 사람들의 정보를 모은 뒤 마지막에 합친다

근거: 실제 초대 준비 장면, 역할 분담 제품 가설.

위험: 가족별 명단 분리가 너무 당연해 오른쪽으로 몰리는지 확인.

## 4. 조율 시작점 대체 후보

### C5. 식사 메뉴를 정할 때

질문:

> 우리가 좋아하는 메뉴와 가족·초대 손님이 편하게 먹을 메뉴가 달라요. 먼저 확인할 쪽은?

- `left / 둘의 기준 먼저`: 둘이 식사에서 중요하게 생각하는 기준
- `right / 주변 조건 먼저`: 가족·초대 손님의 연령과 식사 제약

근거: KCA 예식장 식사 장면, 한국 결혼 의사결정 연구.

위험: 알레르기·건강 제약이 있는 경우 오른쪽이 안전상 강제되는지 확인.

### C6. 예식 순서를 정할 때

질문:

> 우리가 원하는 예식 순서와 가족이 의미 있게 보는 순서가 달라요. 대화를 시작할 때 먼저 확인할 것은?

- `left / 둘의 기준 먼저`: 둘이 꼭 담고 싶은 순서와 이유
- `right / 주변 조건 먼저`: 가족이 의미 있게 보는 순서와 이유

근거: 한국 결혼 의사결정·의례 맥락 연구.

위험: `꼭`이 지나치게 강한지, 관련 의례가 없는 사용자에게 적용되는지 확인.

### C7. 장소 위치를 다시 볼 때

질문:

> 한 장소는 둘의 생활권에, 다른 장소는 가족·초대 손님이 오기에 더 편해요. 먼저 볼 쪽은?

- `left / 둘의 기준 먼저`: 둘의 이동과 준비 일정
- `right / 주변 조건 먼저`: 가족·초대 손님의 이동 조건

근거: KCA 예식장 지역·이동 장면, 한국 결혼 의사결정 연구.

위험: 초대 손님 수와 지역이 답을 사실상 강제하는지 확인.

### C8. 부모님이 의상 의견을 줄 때

질문:

> 둘이 고른 의상에 가족이 다른 의견을 줬어요. 다시 이야기할 때 먼저 확인할 것은?

- `left / 둘의 기준 먼저`: 둘이 그 의상을 고른 이유
- `right / 주변 조건 먼저`: 가족이 걱정하거나 바라는 부분

근거: 가족 참여가 있는 한국 결혼 의사결정 장면, 제품 가설.

위험: 의상 자기결정권 때문에 왼쪽이 도덕적으로 우월해 보이는지 확인.

## 5. 도움 시작점 대체 후보

네 문항 모두 `내가 스트레스를 받을 때 상대에게 먼저 받고 싶은 지원`으로 대상을 고정한다. 제공하는 지원과 원하는 지원을 한 축으로 섞지 않는다.

### D5. 예상보다 큰 비용표

질문:

> 예상보다 큰 비용표를 받아 당황했어요. 상대가 먼저 해주면 도움이 되는 것은?

- `left / 마음 먼저`: 놀란 마음과 걱정을 차분히 들어주는 것
- `right / 할 일 먼저`: 금액이 커진 항목부터 같이 찾는 것

근거: 정서·문제 중심 dyadic coping, KCA 비용표 장면.

위험: 금액 확인이 너무 당연한 다음 행동이어서 오른쪽으로 몰리는지 확인.

### D6. 업체 답이 늦을 때

질문:

> 중요한 질문을 보냈는데 업체 답이 늦어 불안해요. 상대가 먼저 해주면 도움이 되는 것은?

- `left / 마음 먼저`: 무엇이 가장 불안한지 들어주는 것
- `right / 할 일 먼저`: 다시 연락할 시간과 다른 방법을 정하는 것

근거: 정서·문제 중심 dyadic coping, 제품 가설.

위험: 실제 마감 긴급도가 답을 강제하는지 확인.

### D7. 가족과 의견이 엇갈렸을 때

질문:

> 가족과 결혼 준비 의견이 엇갈려 마음이 무거워요. 상대가 먼저 해주면 도움이 되는 것은?

- `left / 마음 먼저`: 어떤 말이 힘들었는지 내 편에서 들어주는 것
- `right / 할 일 먼저`: 다음 대화에서 말할 기준을 같이 정리하는 것

근거: 정서·문제 중심 dyadic coping, 한국 결혼 조율 장면.

위험: `내 편`이 가족 대 커플 대립을 강화하는지 확인.

### D8. 준비 마감을 놓쳤을 때

질문:

> 내가 맡은 준비 마감을 놓쳐 속상해요. 상대가 먼저 해주면 도움이 되는 것은?

- `left / 마음 먼저`: 자책하는 마음을 먼저 들어주는 것
- `right / 할 일 먼저`: 지금 할 수 있는 순서부터 같이 다시 잡는 것

근거: 정서·문제 중심 dyadic coping, 제품 가설.

위험: 책임 회피로 읽히거나 한쪽 답이 더 성숙해 보이는지 확인.

## 7. 32문항 풀의 통과 조건

- 전문가 검토에서 관련성·포괄성·이해 가능성 결함이 해결됨
- 인지면접에서 참여자가 의도한 축으로 문항을 설명함
- `둘 다` 또는 `둘 다 아님`이 반복되는 문항은 수정 또는 삭제
- 한쪽이 모범답안이라는 강한 지적이 반복되면 삭제
- 소득·시간·가족 구조·준비 경험이 답을 거의 결정하면 삭제 또는 조건부 문항으로 분리
- 순서 무작위화 후에도 선택 방향이 유지되는지 확인
- 탐색 표본에서 같은 축 후보가 실제로 함께 움직이는지 확인
- 독립 표본에서 선택한 16문항 구조를 다시 확인

이 문항 풀은 `근거가 있는 최종 검사`가 아니라, 근거를 만들기 위해 경쟁시킬 초기 연구 자산이다.
