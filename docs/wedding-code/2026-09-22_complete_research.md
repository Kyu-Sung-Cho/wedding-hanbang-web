# 웨딩코드 완성형 방향: 시장·문항 설계 근거

작성·원문 확인: 2026-09-22. 상태: **설계 연구 / 사람 검증 전 / 출시 승인 아님**.

## 판단

사용자가 원하는 “내가 원하는 결혼식과 준비 방식을 알아보고, 둘이 미리 맞춰 볼 수 있는 제품”은 만들 수 있다. 다만 “모든 웨딩 성향을 정확히 판정한다”는 무한한 범위의 약속은 이 자료로 뒷받침되지 않는다. 제품이 다룰 주요 결정 범위를 먼저 정의하고, 각 결과를 본인이 직접 답한 항목으로 설명하며, 빠진 영역과 미정인 답을 보여주는 완성형이 현실적이다.

**출처가 뒷받침하는 것:** 시각적 취향, 희망 조건, 지출 우선순위, 필요한 준비 도움을 직접 묻는 시장 사례가 있다. 문항의 단일 의미·명확한 응답 범주·실제 응답자 사전검증이 필요하다.

**출처가 뒷받침하지 않는 것:** 현재 웨딩코드의 문항 타당도, 한국 소비자 전체에 대한 포괄성, 특정 문항 수의 최적성, 결과 정확도, 숨은 성격 발견, 궁합·갈등·결혼 성공 예측. 경쟁사의 마케팅 표현도 우리 제품의 검증 증거가 아니다.

## 우리 제품으로 옮기는 범위

다음은 위 자료와 사용자 요구를 토대로 한 **설계 가설(I)** 이다. 검증된 요인 구조나 정해진 유형 분류가 아니다.

| 제품이 알려줄 것 | 직접 필요한 입력 | 결과에서 가능한 말 | 피해야 할 자동 추정 |
|---|---|---|---|
| 원하는 결혼식의 느낌 | 실제 공간·사진·색·장식 등에 대한 선호 | “이런 사진과 분위기를 골랐어요.” | 이미지 선호를 사치·절약·성격으로 번역 |
| 초대와 당일 경험 | 하객 규모 희망, 식사, 이동 편의, 대화·참여 방식 | “하객과 어떤 시간을 보내고 싶은지” | 하객 수를 외향성·인간관계 능력으로 번역 |
| 사진과 의상·꾸밈 | 사진 촬영 방식, 의상·헤어·메이크업의 원하는 요소 | 실제 고른 취향과 아직 미정인 요소 | 여성/남성 역할을 미리 가정하거나 품목 하나로 전체 스타일 결정 |
| 식의 진행과 의미 | 꼭 넣거나 빼고 싶은 절차, 참여 방식, 중요하게 여기는 장면 | 선택한 장면과 서로 확인할 구체적 질문 | 전통 선호를 보수적 인격, 간소한 식을 낮은 애정으로 해석 |
| 지출 우선순위와 조정 | 더 쓰고 싶은 항목·덜 신경 쓰는 항목, 직접 정한 한도, 조정 의향 | “어느 항목을 먼저 지키고 싶은지” | 성향 점수에서 실제 예산·분담금·감당 능력 생성 |
| 비교·결정 방식 | 후보를 보고 결정하고 싶은 절차 | “함께 기준을 정할 때 이런 방식을 원했어요.” | 성실함·합리성·계획성 등 우열 판정 |
| 역할·공유·일정 | 원하는 분담, 맡긴 결정 범위, 진행 공유 시점 | 서로 정하면 좋은 담당·시점·범위 | 참여 의향을 실제 기여량이나 애정으로 판정 |
| 가족과 도움 | 상의할 대상과 결정 범위, 받고 싶은 도움 | 직접 말하고 싶은 요청과 확인할 기준 | 가족의 실제 의견·속마음, 상대의 잘못·갈등 위험 추정 |

신혼집·혼수·신혼여행은 별도 계획 영역이다. 사용자 요구에 따라 이후 연결할 수 있지만 이 자료만으로 “웨딩 전부”에 이미 포함됐다고 말하지 않는다. 예식을 하지 않거나 특정 품목을 쓰지 않는 사람의 경로도 범위 표에 포함해야 한다.

## 선택지와 문항 설계 권고

사용자가 원한 다섯 단계 경험은 유지할 만하다. 그러나 **모든 정보에 동의 문장을 강제할 필요는 없다.** 준비 방식은 문장에 동의하는 정도, 취향은 사진·대상별 선호, 이미 정한 날짜·인원·금액은 직접 입력이 더 명확한지 검토한다. 이는 질문에 맞는 응답을 쓰는 제품 가설이며 실제 비교 검증이 필요하다.

동의형 문장은 “지금 결혼을 준비한다면”의 의향 또는 실제 행동 중 하나로 시제를 고정한다. 낮은 동의는 반대 성향의 증거가 아니다. “예산을 지키면서 예쁘고 하객도 편한 식을 원한다” 같은 문장은 서로 다른 목표가 섞이므로 나눈다. 다수에게 바람직하게 들리는 일반론만 반복하지 않는다.

비용과 분위기, 함께 찾기와 맡기기, 경청과 실무 도움은 동시에 중요할 수 있다. 둘 다 높은 답을 모순으로 처리하지 않는다. 원인이 다른 문항을 단순히 비슷하게 들린다는 이유로 제거하지도 않으며, 같은 의미의 바꿔 쓰기를 검증 없이 “정확도를 높이기 위한 반복”이라고 설명하지도 않는다.

모든 항목을 서열대로 줄 세우게 하기보다 각각의 선호를 답하고, 필요할 때 본인이 특히 지키고 싶은 항목을 따로 표시하게 하는 방향을 검토한다. 강제 선택 개수와 순위는 과학적 기준이 아닌 인터페이스 결정임을 명시한다. 모두 중요하거나 아직 모르겠다는 답도 가능해야 한다.

## 결과 해석과 재미의 경계

결과는 단순 답안 목록에서 더 발전할 수 있다. 다만 새로운 사실을 지어내는 대신 **함께 고른 답의 관계를 근거와 함께 설명**해야 한다.

예시(합성 사례): 공간 분위기를 중요하게 보고 사진 취향도 구체적으로 골랐으며 식사에는 아직 결정을 못 했다면, “공간과 사진에는 원하는 모습이 있고, 식사는 아직 열어두고 있어요. 먼저 두 사람이 좋아하는 공간 사진을 같이 보면 어떨까요?”라고 설명할 수 있다. “감성적인 완벽주의자”라는 성격으로 바꾸지는 않는다.

개인 결과에는 직접 선택한 핵심 항목, 그 근거 답, 함께 높게 나온 바람, 미정인 영역, 다음에 해볼 일을 포함한다. 결과가 맞지 않으면 답을 고치거나 해당 설명을 부정할 수 있어야 한다. 커플 결과에는 각자의 선택을 나란히 놓고, 겹치는 구체적 선택과 서로 더 물어볼 부분을 보여준다. 다른 답은 잘못도 위험도 아니다.

**전체 성향 총점·궁합 백분율·희귀 유형·확신도·심리 진단은 만들지 않는다.** 본인 선택으로 정한 우선순위와 시스템의 문항 정렬 규칙도 구분한다. 숫자 차이로 제시하는 편의상 범주는 심리적 의미가 검증된 임계값이 아니다.

공유·저장·아모라 연결은 본인이 확인한 범위로만 한다. 두 사람이 같은 답을 했어도 합의가 자동 성립한 것은 아니다. 결과를 예산·할 일·일정에 반영하는 시점에는 구체적인 변경 내용을 다시 확인받는다.

## 사람 검증 게이트

내부 AI 검수·유닛 테스트·브라우저 QA는 기능과 문구의 결함을 찾는 증거다. 실제 소비자 이해도·재미·유용성의 대체 증거가 아니다.

1. **범위 감사:** 예식 준비 초기/진행 중, 가족 참여 유무, 예식·특정 품목 계획 없음 등 서로 다른 맥락을 포함해 빠진 결정·강제 가정을 점검한다. 항목별 수집 목적과 결과 연결이 없으면 삭제한다.
2. **인지면접:** 문장을 자기 말로 다시 설명하고, 어떤 장면을 떠올렸는지, 다른 답도 해당했는지, 중립과 모름을 어떻게 구별했는지 확인한다. 결과 카피가 답보다 더 나아가 해석됐는지 질문한다. 오해가 반복되는 문장은 수정 후 다시 확인한다.
3. **개인 사용성:** 완료·중단 지점과 이유, 반복·피로·어색한 말, 실제 새롭게 정리한 기준, 결과를 부정한 이유를 관찰한다. “잘 맞네요” 한마디나 만족도만으로 통과시키지 않는다.
4. **커플 사용성:** 각자 독립 응답 후 비교한다. 어떤 대화가 실제로 생겼는지, 차이를 비난으로 읽는지, 다음 결정에 쓸 수 있었는지 확인한다. 한 사람이 다른 사람의 답을 대신한 경우를 구분한다.
5. **주장 감사:** 위 관찰과 버전별 수정 내역이 기록된 후에만 그 범위의 이해도·유용성을 말한다. 잠재 성향 측정·점수·유형이 필요해지면 별도의 측정 전문가 설계와 통계 검증을 거친다.
