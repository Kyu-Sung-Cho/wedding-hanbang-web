# 웨딩코드 v2.0: 문장형 5점 응답 설계

2026-09-22 · 내부 설계·문항 감사 문서

## 목적과 상태

기존 v1.2는 한 장면에서 “무엇을 먼저 말하거나 할지”를 보기 중 하나로 고르는 방식이었다. 보기 두세 개가 실제로 모두 해당할 수 있어 응답자가 임의로 첫 행동 하나를 골라야 했고, 준비 분담·가족 참여·도움 문항은 비슷한 장면을 반복했다. 팀 피드백 PDF의 “AI가 쓴 말투”, “상황을 이해하기 어렵다”, “보기 여러 개가 맞는다”, “무엇을 보는지 모르겠다”는 지적을 이 구조와 대조했다.

v2.0 후보는 한 문장에 한 의미를 담고, 같은 5점 척도로 문장마다 답하게 한다. 문항별 답과 건너뛴 상태를 보존하고 네 주제에서 대화를 시작할 문장을 찾는다. 이 도구는 성격검사, 공식 MBTI 검사, 궁합 판정, 결혼 성공 예측이 아니다. 실제 소비자 인지면접·커플 사용성·측정 전문가 검토는 아직 실행하지 않았으므로 확정·완벽·validated라고 표시하지 않는다.

## 후보 방식 비교와 채택 이유

| 방식 | 장점 | 결함·위험 | 판단 |
|---|---|---|---|
| 기존 장면 forced-choice | 결혼 준비 장면이 구체적이고 답을 바로 고를 수 있음 | 한 화면에 비용·조건·분위기·의미가 섞임. B/C는 같은 주체 결정을 반복하고 D는 실제로 순차적으로 함께 할 수 있는 행동을 양극에 둠. 첫 행동을 묻기 때문에 평소 선호인지 상황 영향인지 분리되지 않음 | 레거시 링크와 문항은 보존하되 새 문항으로 사용하지 않음 |
| 한 문장 + 5점 응답 | 복수 선택 대신 문장별 가까운 정도를 답함. 1~5와 건너뜀을 보존해 같은 합계가 서로 다른 응답을 숨기지 않음. 사용자가 말한 MBTI식 응답 경험에 가까움 | 동의 쪽으로 답하는 경향, 사회적으로 좋아 보이는 답을 고르는 경향, 중간 응답의 개인차가 남음. 5점 형식만으로 타당도가 생기지 않음 | **채택. 문항별 답을 결과와 커플 비교에 그대로 사용** |
| 양극 forced-choice 또는 양극 점수 | 두 방향을 한눈에 비교하기 쉬움 | 실제로 함께 높을 수 있는 선호를 거짓 양자택일로 만들고, 한쪽 점수가 낮다고 반대 성향이라고 오해하게 함. 비용과 분위기처럼 다른 구성개념을 양극으로 묶음 | 거부. v2.0에는 양극 점수·코드·유형을 만들지 않음 |

MBTI 공식 자료가 말하는 자기보고 선호와 본인 확인을 참고했지만, 웨딩코드가 MBTI 문항이나 이론을 복제하는 것은 아니다. 화면에서 가상의 두 성향을 정답처럼 제시하지 않고, 실제로 답한 문장을 보여준다.

## 응답 계약

문항마다 같은 순서의 다섯 버튼을 노출한다.

1. 전혀 그렇지 않아요
2. 그렇지 않은 편이에요
3. 어느 쪽도 아니에요
4. 그런 편이에요
5. 매우 그래요

정답이 없는 자기보고라는 안내를 문항 위에 둔다. 아직 모르거나 해당하지 않으면 별도의 “지금은 답하기 어려워요”로 건너뛴다. 건너뛴 항목은 3점으로 바꾸지 않고 공유 문자열에도 제외 상태로 남긴다. 답하지 않은 항목을 강제로 답하게 하지 않으며, 모든 문장을 건너뛴 경우에도 결과 화면에서 “아직 답한 문장이 없어요”라고 말하고 추론을 하지 않는다.

문항은 화면에서 네 주제가 섞여 보이도록 번갈아 보여준다. 이는 점수 균형을 주장하기 위한 것이 아니라 같은 종류의 질문이 연달아 반복되는 피로를 줄이기 위한 UI 선택이다.

## 확정 후보 16문장

문항의 “목적”은 내부 원고 감사용이다. 소비자에게 측정한 심리 특성으로 노출하지 않는다. 결과에는 문장별 후속 질문과 주제별 대표 질문을 대화 시작점으로 보여준다. 이는 중요도나 성격을 자동 판정하는 추천이 아니다. 1~2점 답을 반대 성격으로 번역하지 않는다.

### 결정할 때 중요하게 보는 기준

|---|---|---|---|

| C2 | 예약하기 전에 취소·변경 조건을 먼저 확인하는 편이다. | 예약 변경·취소 조건을 확인하려는 정도 | 예약 전에 함께 확인하고 싶은 조건은 무엇인가요? |
| C3 | 예식장을 고를 때 전체적인 분위기가 마음에 드는지 먼저 보는 편이다. | 예식장의 시각적 분위기를 먼저 살피는 정도 | 예식장을 고를 때 각자 가장 먼저 보는 것은 무엇인가요? |
| C4 | 마음에 드는 항목이 예산을 넘으면 다른 항목의 비용을 줄여서라도 선택하고 싶은 편이다. | 좋아하는 항목을 위해 다른 항목의 예산을 줄일 의향 | 예산을 넘는 후보가 마음에 들면, 어떤 방법으로 결정하고 싶은가요? |

### 도움을 받을 때 필요한 것

모든 도움 문항은 “내가 상대에게 받고 싶은 도움” 관점으로 통일했다. 상대의 실제 행동, 애착 유형, 갈등 유형을 측정하지 않는다.

| ID | 화면 문장 | 이 문장에서 확인할 것 | 결과 다음 질문 |
|---|---|---|---|
| H1 | 결혼 준비가 힘들 때 해결책보다 먼저 내 이야기를 들어주길 바라는 편이다. | 해결책 전 경청을 원하는 정도 | 준비가 힘들다고 말할 때, 상대가 처음에 어떻게 반응해 주면 좋겠나요? |
| H2 | 준비하면서 의견이 부딪힌 뒤에는 내가 어떤 점에서 불편했는지 먼저 물어봐 주길 바라는 편이다. | 다툼 뒤 내 불편한 점을 질문받기를 원하는 정도 | 의견이 부딪힌 뒤 다시 대화할 때, 어떻게 시작해 주면 좋을까요? |
| A1 | 준비할 일이 몰리면 상대가 내가 맡은 일의 일부를 맡아주길 바라는 편이다. | 구체적인 실행 부담을 나눠 받기를 원하는 정도 | 할 일이 몰렸을 때, 상대에게 맡기고 싶은 일이 있나요? |
| A2 | 준비 결정이 막히면 상대가 지금 먼저 할 일 하나를 골라주길 바라는 편이다. | 다음 행동을 정리받기를 원하는 정도 | 결정이 막혔을 때 상대가 어떻게 도와주면 좋을까요? |
## 문항별 잔여 감사

아래는 새 문장끼리 다시 읽은 내부 감사다. “통과”는 문항을 공개 후보로 둘 수 있다는 뜻이지, 소비자 이해도 검증을 마쳤다는 뜻이 아니다.

최종 결과 카피 재검수에서 다음을 수정한다. 의향 문항의 낮은 응답을 실제 행동이나 상대 행동으로 바꾸지 않는다. 예를 들어 O1의 낮은 응답은 “맡은 사람이 혼자 결정하지 않는다”가 아니라 “세부 내용까지 결정해도 괜찮다는 쪽에는 가깝지 않다”다. H1은 '내가 듣기'가 아니라 '상대가 내 이야기를 들어주기'로 관점을 보존한다. 고·중·저 응답에 공통으로 사용하는 후속 질문은 특정 답의 행동을 권하지 않고 원하는 방식·시점·범위를 묻는다. 점수 합산·유형 추론은 추가하지 않는다. 이 수정은 원문 의미를 보존하기 위한 카피 게이트를 통과한다.

C3 대안은 '사진과 공간' 유지와 '예식장' 한 대상으로 좁히기를 비교해 후자를 채택했다. C4는 총예산 증액과 항목 간 예산 조정 중 후자를 채택해 지불 능력 해석을 줄인다. O2는 비교 대상 없는 '더 편하다'와 '진행 중/완료 후' 명시를 비교해 후자를 채택했다. 단, 이 내부 판단을 실사용자 검증으로 표현하지 않는다.

| 문항 | 판정 | 남은 주의점 |
|---|---|---|
| C1 | 통과 | 추가 비용까지 포함한 전체 금액을 확인하는 문장이다. C2와 시점은 가깝지만 확인 대상이 다르므로 결과에서 하나의 성향으로 합치지 않는다. |
| C2 | 통과 | 예약을 취소하거나 변경할 때 붙는 조건을 확인하는 문장이다. 법률·환불 가능성을 판정하는 문장으로 확장하지 않는다. |
| C3 | 주의와 함께 통과 | 예식장의 전체 분위기를 묻는다. 선호하는 구체적 분위기나 웨딩 취향 전체를 알아냈다고 말하지 않는다. |
| C4 | 주의와 함께 통과 | 총예산 증액과 항목 간 조정을 혼동하지 않도록 다른 항목의 비용을 줄이는 상황으로 한정했다. 예산을 정하지 않았으면 건너뛸 수 있으며, 감당 가능한 금액이나 지불 능력은 알 수 없다. |
| T1 | 통과 | 업체를 각자 따로 찾는지 처음부터 함께 보는지를 묻는다. 함께 찾아야 한다는 정답을 제시하지 않는다. |
| T2 | 통과 | 후보를 고르기 전 기준을 맞추는지를 묻는다. T1의 정보 탐색 방식과 구분해 결과에서 문장별로 보여준다. |
| O1 | 통과 | 담당자가 세부 내용을 결정해도 되는 범위를 묻는다. 위임이 방임이나 검토 금지를 뜻한다고 설명하지 않는다. |
| O2 | 통과 | '더 편하다'의 비교 대상을 진행 중 공유로 명시했다. O1의 결정 권한과 다르며, 진행 중 절대 공유하지 않는다고 해석하지 않는다. |
| U1 | 통과 | 부모님 의견을 듣는 것과 마지막 선택을 분리한다. 부모님을 배제하거나 무시하는 태도로 번역하지 않는다. |
| U2 | 통과 | 부모님과 이야기하기 전 커플 기준을 세우는 순서를 묻는다. 부모님과 상의하지 않는다는 뜻으로 확대하지 않는다. |
| F1 | 통과 | 양가 부모님이 중요하게 보는 조건을 초반에 확인하는 문장이다. 부모님이 최종 결정권을 갖는다고 해석하지 않는다. |
| F2 | 통과 | 양가 부모님과 관련된 결정을 부모님과 미리 상의하는지를 묻는다. 부모님이 최종 결정권을 갖는다고 해석하지 않는다. |
| H1 | 통과 | 정서적 경청을 먼저 받고 싶은 정도다. 공감이 실제 갈등 해결을 보장한다고 말하지 않는다. |
| H2 | 통과 | 준비 중 의견 충돌 뒤 내가 불편했던 점을 묻는지를 확인한다. 상대의 갈등 유형이나 감정 상태를 진단하지 않는다. |
| A1 | 통과 | 준비할 일이 몰릴 때 내가 맡은 일의 일부를 나누고 싶은지를 묻는다. 상대가 모든 일을 대신해야 한다고 해석하지 않는다. |
| A2 | 통과 | 준비 결정이 막힐 때 지금 할 일 하나를 고르는 도움을 묻는다. 상대가 모든 결정을 대신해야 한다는 뜻으로 번역하지 않는다. |

## 결과 해석 계약

응답값 1~5는 문항별로 그대로 보존한다.

- 4~5: “이 문장에 가깝게 답했어요”
- 3: “중간으로 답했어요”
- 1~2: “이 문장과는 거리가 있다고 답했어요”
- 건너뜀: “아직 답하지 않았어요”

낮은 응답은 반대 성격, 무관심, 준비 부족으로 읽지 않는다. 같은 주제에서 4~5와 1~2가 함께 나와도 “둘 다 중요하다”라고 합산하지 않고, 어느 문장에 어떻게 답했는지 각각 보여준다. 주제에 답한 문장이 없으면 “이 주제에는 아직 답한 문장이 없어요”라고 한다. 3점만 있는 주제는 “이 주제의 문장에는 중간으로 답했어요”라고 한다.

현재 구현 후보의 결과 요약은 네 주제와 문항별 응답을 보존한다. 향후 결과 모델에 요약문·문항별 follow-up·누락 상태를 넣더라도 위 계약을 넘지 않아야 한다. 특히 둘 다 건너뛴 문항은 “둘 다 중요”나 “비슷하다”로 세지 않고 “둘 다 아직 답하지 않았어요”로 제외한다. 한 사람만 건너뛴 문항은 비교하지 않고 “한 사람은 아직 답하지 않았어요”로 표시한다.

커플 비교는 같은 문항을 기준으로만 한다.

- 0~1점 차이: “비슷하게 답했어요”
- 2점 이상 차이: “답한 정도가 달랐어요”
- 한 사람만 건너뜀: “한 사람은 아직 답하지 않았어요”
- 둘 다 건너뜀: 비교 대상에서 제외

이 차이는 누가 맞는지, 누가 더 좋은 준비자인지를 말하지 않는다. 후속 질문은 “왜 그런 성격인가요?”가 아니라 “이번 항목에서 어떤 조건이나 경험 때문에 이렇게 답했는지 서로 말해볼까요?”처럼 실제 결정으로 이어지게 한다.

예산 관련 후속 질문은 금액 추천이나 적정 예산 계산이 아니다. C1·C2·C4의 답을 바탕으로 꼭 지킬 항목, 확인할 계약 조건, 더 쓰고 싶은 경험과 줄일 항목을 대화로 정리하는 안내다.

## 근거와 한계

### 외부 자료에서 확인한 사실

- Myers & Briggs Foundation은 MBTI를 자기보고 선호와 본인 확인의 도구로 설명하고, 선호를 우열로 보지 않는다. 공식 도구의 문항·이론·명칭을 웨딩코드에 복제하지 않는다.
- Pew Research Center의 질문 작성 지침은 쉬운 말, 구체적인 문장, 한 문항에 한 생각을 권한다. 동의/비동의 척도에는 한쪽으로 답하는 경향이 생길 수 있다고 설명한다.
- AERA/APA/NCME의 검사 기준은 점수 해석과 사용 목적에 대한 타당도 근거가 필요하다고 설명한다. 5점 버튼을 썼다는 사실만으로 타당도가 생기지 않는다.
- The Knot의 Wedding Vision/Style Finder는 사진·무드·예산·우선순위를 직접 고르게 해 웨딩 계획의 참고자료로 사용한다. 이런 취향 도구가 성격 유형이나 커플 성공을 증명한다는 근거로 사용하지 않는다.
- 이번 문서에는 검증된 한국 시장 대표 통계나 공식 국내 웨딩 심리검사 표준을 추가하지 않았다. 확인하지 않은 시장 규모·소비자 선호를 사실처럼 쓰지 않는다.

### 제품 내부 판단과 남은 한계

- 사회적 바람직성: “함께 확인하고 싶다”, “들어주길 바란다” 같은 문장은 좋아 보이는 답을 유도할 수 있다. 정답·우열을 없애고 낮은 응답을 성격으로 번역하지 않지만, 이 위험을 제거했다고 말할 수는 없다.
- 동의 응답 편향: 전 문항이 같은 5점 척도라 읽기 쉽지만, 무조건 동의하는 응답 경향을 보정하는 검증은 아직 없다. 문장을 억지로 반대로 쓰지 않아 이해도를 우선했다.
- 맥락 제한: 문항은 결혼 준비의 견적·업체·부모님·커플 대화를 다룬다. 일반 성격, 연애 만족도, 애착, 갈등 유형을 측정하지 않는다.
- 취향 범위 제한: C3은 예식장의 전체 분위기를 가볍게 확인하는 문장이다. 하객 규모·장소·식사·사진·의상·예식 형식·전통성 같은 구체적인 취향 전체를 대신 판단하지 않으며, 별도 웨딩 취향 도구에서 나눠 다룬다.
- 예산 범위 제한: 실제 금액·지역·하객 수·지원금이 문항에 없다. 결과는 금액 추천, 견적 적정성 판정, 예산 배분을 제공하지 않는다.
- 가족·관계 다양성: 부모님이 없거나 참여하지 않거나, 양가가 아닌 가족·지인이 중요한 경우가 있다. 화면에서 해당하지 않는 문장은 건너뛸 수 있다고 안내하고, 가족 참여가 높거나 낮다고 관계의 옳고 그름을 말하지 않는다.
- 실제 검증 미완료: 소비자가 같은 뜻으로 읽는지, 16문항이 충분히 흥미로운지, 커플 대화를 실제로 돕는지는 인지면접·파일럿·사용성 검토가 필요하다. 자동 테스트 통과를 사람 검증의 대체물로 쓰지 않는다.

## 웹 배포 범위와 회귀 확인 (2026-09-22)

사용자 요청에 따라 공개 `/wedding-code` 기본 진입과 랜딩 안내를 문장형으로 배포한다. 기존 버전이 명시된 공유 링크는 해당 버전으로 연다. DB·Storage·운영 환경변수·AI 모델은 변경하지 않는다. 라운지의 저장형 준비 스타일과 별도 취향 도구는 이번 문장형 응답을 자동 저장하거나 가져오지 않는다.

배포 전 추가로 확인한 세 경계는 다음과 같다.

- 결과에서 다시 답하면 일반 진입과 공유 진입 모두 화면·응답을 초기화한다. 여러 번 다시 답해도 같다.
- 마지막 문항에서 선택한 답을 건너뛰면 결과와 완료 이벤트의 응답 수에서 모두 제외한다.
- 두 번째 사람이 모두 건너뛴 경우 초대 링크를 커플 결과 링크처럼 제공하지 않고, 공유할 수 없는 이유를 안내한다.

재시작·건너뛰기·빈 커플 공유는 진입 컴포넌트를 포함한 회귀 검사로 확인한다. 링크 검사에서는 유효한 버전에 중복 키를 넣어 거절하는지도 확인한다. 검증 영수증, 최종 소스 SHA, 원격 CI, Vercel 미리보기 및 운영 확인은 배포 PR에 기록한다. 롤백은 이 웹 변경을 revert하는 방식이며 DB 롤백은 필요 없다.

실제 사람 인지면접·실기기 검증·성향 측정 타당화는 배포와 별개로 미완료다. 웹 배포 성공을 해당 검증의 완료로 표현하지 않는다.
