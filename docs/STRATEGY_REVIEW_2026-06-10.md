## 0. 한 줄 결론

**포지셔닝("웨딩 거래 신뢰 인프라")은 유효하고 그 자리는 비어 있다. 그러나 현재 실행 방향(AI 페르소나로 커뮤니티 채우기)은 그 포지셔닝과 정면 모순이며, 2026년 6월부터 시행된 공정위 심사지침 위반 소지가 있다. 이걸 먼저 해체하고, "계약금 보내기 전 손해 방지" 단일 쐐기로 좁혀야 먹힌다.**

## 1. 시장이 주는 기회 (먹힐 근거)

1. **수요는 살아 있고 커지는 중**
   - 혼인 건수 3년 연속 반등: 2023년 19.4만 → 2024년 22.2만(+14.8%) → 2025년 24만 건(+8.1%, 7년 만에 최대). 단, 2026년 2월 -4.2%로 꺾이는 신호 있음.
   - 결혼식장+스드메 평균 계약액 2,101만원(소비자원 참가격, 2025), 강남 3,409만원. 주택 제외 직접 결혼비용 약 5,900만원(듀오 2026).

2. **규제 타이밍이 정확히 지금**
   - 2025-11-12 가격 표시 의무화 고시 시행(미공개 시 과태료 최대 1억) → **2026-05-12 계도기간 종료, 지난달부터 실제 제재 시작**.
   - 2025-04 공정위 결혼준비대행 표준약관 제정 → 계약서 진단의 **공인 비교 기준선**이 됨.
   - 소비자원이 2026년 5~6월 결혼서비스 피해 집중신고 기간 운영 중 → 소비자 경각심·언론 관심 최고조.
   - 결혼서비스법(법률)은 아직 **미제정** — 제정 추진 단계 (2026-02 성평등가족부 간담회).

3. **피해는 급증하는데 해결책은 공백**
   - 결혼준비대행 피해구제: 2021년 92건 → 2025년 356건 (4년간 3.9배).
   - 피해 사유 **57.8%가 계약해제 거부·과다 위약금**.
   - 참가격은 지역 평균만 격월 공개(업체별·실시간 비교 불가), 조사 시점 대행업체 86.8%가 가격 미공개.
   - "내 견적·내 계약서가 정상인가"라는 개별 질문에 답하는 서비스가 **없음**.

4. **경쟁사는 구조적으로 이 자리에 못 온다**
   - 웨딩북(투자 158억, 인증신부 20만, 2026-01 AI 플래너 출시): 수익이 업체 광고/중개 → "계약하지 마세요"라고 못 말함.
   - 다이렉트결혼준비(네이버 카페 41~70만 회원): 제휴업체 수익 모델, AI 없음.
   - 아이웨딩: 모회사(화장품) 집중으로 정체. 웨딩의여신: 사실상 정체.
   - 신규 AI 서비스(메링·푸딩·웨딩톡·웨딩플로우·웨딩핏·네이버 웨딩클럽): 전부 플래닝 편의에 집중, **"업체 돈을 안 받아서 계약 보류를 권할 수 있는 중립 진단"** 포지션은 빈자리.

## 3. 🚨 가장 긴급: 커뮤니티 AI 페르소나 시스템 (즉시 조치)

코드 분석 결과 (`apps/web/src/lib/community/agents/`):

- 페르소나 20종 중 18종이 `publicMode: "persona"` — 일반 예비부부로 위장 (`badge: "member"`, `rank: "sprout"`, AI 표시 없음, `ad_disclosure: "general"`).
- persona 글은 정규식 게이트만 통과하면 **무검수 자동 게시**(autoPublish 기본 true).
- 봇이 인간 글에 **좋아요 투표** → 공개 upvote_count 오염(주간 베스트 랭킹 왜곡).
- **동기방(cohort_messages)까지 침투** — 같은 결혼월 신부 행세, 기만 민감도 최고 공간.
- 출처 "검증"은 URL 형식 검사뿐.
- 증거가 DB에 자필로 남는 구조: `agent-*@agents.hanbang.ai`, `account_kind: "community_agent"`, 활동 로그.

**법적 리스크**: 공정위 추천·보증 심사지침 개정 — AI 가상인물 표시 의무 + **가상 체험담 전면 금지**가 **2026년 6월(이번 달)부터 본격 시행**. 직원 가짜 리뷰 선례(오아, 과징금 1.4억). 적발 시 "신뢰 인프라" 미션 자체가 사망 (Sports Illustrated·몰트북 코스).

**조치 (코드를 버리라는 게 아니라 전환)**:
1. persona 18종 신규 생성 중단, 봇 투표 비활성화, 동기방 침투 중단.
2. 기존 봇 콘텐츠 처리 방침 결정 (삭제 or AI 표시 소급).
3. official 2계정을 "웨딩한방 계약메모 (운영자·AI 작성 표시)" 공개 큐레이션으로 전환 — 오늘의집 초기 에디터 모델. **명시하면 자산, 숨기면 부채.**
4. 프로필/포스트 레벨 AI 배지 + `ad_disclosure`에 AI 값 추가.

## 4. 전략: 어떻게 해나갈 것인가

### 4.1 진입 쐐기 (wedge) — 후보 비교

| 후보 | 절박함 | 데이터 콜드스타트 | 경쟁 |
|---|---|---|---|
| A. 견적 진단 ("이 가격 정상?") | 높음 | 불리 (비교 DB 필요) | 참가격·계산기들이 부분 대체 |
| **B. 위약금 계산기 + 계약서 독소조항 스캐너** | **최고** (돈이 걸린 순간) | **유리** (표준약관이 공인 기준선, 가격 DB 불필요) | **없음** |
| C. AI 피팅/예산 시뮬레이션 | 낮음 | 보통 | 웨딩핏·푸딩 선점 |

**선택: B.** 피해의 57.8%가 위약금·계약해제. 입력(계약일·총액·해지 시점·계약서) → 출력("표준약관 기준 환급액 X원, 당신 계약서는 Y원 요구 — 차액 Z원, 위험 조항 2개"). 룰 기반이라 1인이 법적 단정 없이("확인 필요" 언어) 안전 운영 가능. 결과 화면이 그 자체로 공유되는 콘텐츠. A(견적 진단)는 B 유입 유저의 견적서가 쌓이면 2~3개월 뒤 자연히 켜짐.

### 4.2 GTM (1인 + $500/mo, 6개월)

- **1~2개월: 도구 단독 가치 + 첫 100명.** 위약금 계산기를 로그인 없는 단독 페이지로. "스드메 위약금", "웨딩홀 계약 해지 환불" 등 롱테일 SEO 15~20페이지(피해 집중신고 기간 뉴스재킹 — 지금이 적기). 네이버 지식iN·뽐뿌웨딩·인스타에서 위약금 질문에 **운영자 실명으로** 정성 답변. 계약서 50건 무료 정밀 리뷰(Wizard of Oz) DM 제안.
- **3~4개월: 콘텐츠 엔진 + 1,000명.** 무료 리뷰에서 나온 실제 독소조항 익명화 → 릴스/쇼츠 "계약서에 이 문장 있으면 멈추세요" 주 3개. 상위 성과 릴스만 월 $250 부스팅. 동기방은 2개만 열고 본인이 매일 상주(블라인드식 좁은 코호트 밀도).
- **5~6개월: 깔때기 완성.** 계산기 → "아모라에게 내 상황 묻기" → 라운지 저장 전환율 측정. 견적서 100건 쌓이면 견적 진단(A) 오픈 + "서울 스드메 견적 리포트" 발행 → 언론 피칭 + 업체 역제안 자료. 목표: MAU 1,000~2,000, 누적 진단 500건.

### 4.3 수익화

- **1차 (5개월차, 누적 진단 300건)**: 소비자 단건 결제 — "계약 전 정밀 진단 리포트" 건당 14,900원 (무료: 자동 스캔 요약 / 유료: 조항별 상세 + 업체에 보낼 질문 리스트 + 협상 문구). 업체 돈을 안 받으므로 P1 무손상. 2,000만원 계약 앞에서 1.5만원은 저항 없음. 지불 자체가 PMF 검증.
- **2차 (9~12개월, 검증 업체 16곳 후)**: 업체 검증 프로필 + 자격 검증 리드 라우팅 월 구독(5~15만원).
- **영구 금지**: 유료 순위·프리미엄 노출. 구 전략서(`VENDOR_AND_PAYMENT_STRATEGY.md`)의 "프리미엄 노출" 수익원은 P1과 정면 충돌 → **문서를 deprecated로 명시 처리할 것.**

### 추가할 것 TOP 5
1. **계약서 위험 진단 (표준약관 대조)** — 난이도 중. 메인 웨지인데 L3가 비어 있음 (quoteCheck.ts는 견적만).
2. **추가금(HiddenFee) DB + 공개 페이지** — 난이도 소~중. 원본비·헬퍼비·얼리스타트비·보증인원. 참가격의 공백. SEO 자산 (화해 성분 DB 포지션).
3. **가격공개 의무화 준수 추적기** — 난이도 중. 업체별 공개 여부/충족도 추적. 계도기간 막 끝난 **지금이 유일한 타이밍 윈도우**. 업체 아웃리치 명분까지 생성.
4. **AI·출처 표시 인프라 (Phase 0)** — 난이도 소. 배지, ad_disclosure AI 값, 출처 티어·confidence 라벨. 컴플라이언스이자 차별화.
5. **익명 견적 카드 제출 루프** — 난이도 중. 견적서 → 익명화 → 지역/카테고리 비교 카드. 1~2번 자리잡은 뒤.

### TestFlight — 지금 아님
유저 0명 단계의 웨지 검증은 모바일 웹으로 충분. 1~3순위가 전부 웹 작업. 예외: 제출이 1~2일 내 끝나면 "제출만 하고 동결" 허용(심사 레퍼런스 확보). 앱 재개 조건: 웹 주간 진단 30건+ 4주 연속.

## 6. 90일 로드맵 (순서 기반)

- **S1. 에이전트 위장 해체 + AI 표시** → 통과: 위장 콘텐츠 신규 0건, 기존 콘텐츠 방침 결정.
- **S2. 견적 진단 v1 전면 배치** — 랜딩 히어로를 "계약금 보내기 전, 이 견적이 정상인지 3분 확인"으로 → 측정: 주간 진단 건수, 진단→라운지 저장 전환율. 주 10건 + 저장 30% 도달 시 S3.
- **S3. 계약서 진단 v1 (표준약관 대조)** → 통과: "덕분에 위약금 조항 고쳤다" 사례 3건 — 이게 첫 마케팅 자산.
- **S4. 가격공개 준수 추적 + 업체 아웃리치 (주 10건으로 축소)** → 측정: 응답률, 8주 8곳 온보딩.
- **S5. 격월 시장 리포트 1호** ("서울 스드메 추가금 리포트") → 측정: 리포트 유입→진단 전환율.

**관통 원칙**: 90일간 새 기능 카테고리를 늘리지 않는다. 모든 작업이 "계약금 입금 전 손해 방지" 한 문장으로 환원되는지 매번 검사.
