# 커뮤니티 = 유입+전환 엔진 통합 청사진 (2026-06-10)

> 파운더 과제: 커뮤니티를 백지에서 재설계 — (1) 어떤 기능으로 유저를 끌어들이고 (2) 어떻게 아모라·라운지를 쓰게 할 것인가. 새 기능 허용, 서비스 전체 레벨업, 시장성.
> 프로세스: 조사 4건(전환퍼널 코드/유입현실/소셜메커닉/콜드스타트) → 설계 3렌즈(유입엔진/저밀도소셜/전환머신) → 심사 3인(그로스투자자/1인운영/28세신부) → 통합.
> 전제: 친언니 OS(아모라 모멘트 루프)는 리텐션 코어. 본 문서는 그 **유입+전환 레이어**. 가짜 유저/봇 영구 금지(공정위 2026-06 지침).

## 0. 핵심 통찰 — 세 설계가 하나의 엔진으로 수렴

3개 설계는 경쟁안이 아니라 **하나의 give-to-get 엔진의 세 축**이었다:
- 설계1 "시세 데이터 OS" = 유입축(SEO 착지점)
- 설계2 "코호트 동기화 피드(오늘의 한 질문)" = 저밀도 생존축
- 설계3 "시세 봉투(give-to-get)" = 전환 UX축

**4명 심사 만장일치 결론 2가지**:
1. **죽은 코드 2종을 켜는 게 신규 유입 0명이어도 즉시 가치를 내는 최우선 작업** (이미 만들어 둔 자산):
   - `AiCommentBox.tsx` — 아모라 가격 코멘트가 DB에 생성·저장되는데 **글 상세에서 렌더가 안 됨**(전 코드베이스 유일 참조가 자기 자신, dead render). 게다가 트리거가 `is_normal` 카테고리에만 묶여 정작 가격글(`tips_v2`/`tour_review`)엔 안 달림.
   - `buildChatHref()` (`ServiceCTA.tsx` L71-82) — "아모라에게 묻기"가 **글 제목+URL만 넘기고 본문·cost_data는 안 넘김**. 받는 쪽은 자동전송도 아님. 역방향 파이프(`buildCommunityAskDraft`/`redactCommunityDraftText`, 아모라답→구조화 글 자동생성+마스킹)가 이미 완성돼 있어 **방향만 뒤집으면** 그대로 재사용.
2. **공통 사망지점 = give-to-get 입력 마찰을 첫 방문자에게 너무 앞단에 둔 것.** 28세 신부 심사의 결정타: *"검색으로 막 들어온 사람에게 영수증부터 내놔라 하면 이탈한다"* (계약 전이라 영수증이 없거나/금액이 부끄럽거나/개인정보 불안).

→ **해소: 언락을 2단으로 분산.** 가벼운 1탭(오늘의 질문 투표)이 입구, 영수증/견적은 정밀층 보너스. **빈 금고는 항상 공개 시세 벤치마크로 채워** give-to-nothing 방지. 영수증 vision 자동 파싱은 법적·검수 부담으로 90일+ 강등. 선배 라우팅은 선배가 존재하는 100명+ 이후 보류.

## 1. 한 문장 포지셔닝

> **"결혼 준비, 남들이 실제로 얼마 냈는지 보고 시작하는 곳 — 같은 시기 신부들과 AI 친언니 아모라가 매일 챙겨주는."**

"결혼준비하려면 웨딩한방이지"가 되는 이유: **카페엔 묻혀 있고 계산기는 거짓말하는 "실거래가 분포"가 여기만 있고**, 보러 왔다가 아모라가 내 상황을 즉답하고 라운지에 자동 정리해주니 검색→정보→내 일정 관리가 한 번에 끝난다.

## 2. 전체 깔때기

```
[유입]  검색("강남 스드메 얼마") · 프로그래매틱 SEO · 지식iN 전문가답변(실명/AI표기) · 공유카드(친구 코호트)
                                    │
[커뮤]  시세 분포 / 가격글  →  분포 요약은 공개 · 개별·내 위치만 블러
          트리거① "내 위치 보려면 → 1탭 입력(투표/받은견적/예산계획)" = 가입
                                    │ 트리거② 개봉 후 "당신은 중앙값보다 +180만" → 불안
[아모라] "이 금액 적정한지 봐드릴까요?" → buildChatHref(본문+cost_data 주입) → 즉답(시세DB·숨은비용48·예절25, AI표기)
                                    │ 트리거③ 입력 데이터 = budget_items 자동 박제
[라운지] 빈 0% → 첫 실데이터 채워짐 → D-day/예산/일정 → decision_nodes 기록
                                    │
[리텐션] 아모라 모멘트 루프(D-3/D-1/D+1) + 동기방 "오늘의 한 질문" → 커뮤니티 재유입 (루프 닫힘)
```

전환 트리거 요약: **①가벼운 1탭으로 가입 → ②개봉 후 불안→아모라 호출(본문 주입 봉합) → ③입력=라운지 자동 박제 → 모멘트 루프가 다시 커뮤니티로.**

## 4. 커뮤니티 운영 모델 (하루 1시간)

- **콘텐츠 20분**: "오늘의 막막 Q" 1개를 운영자가 골라 비동행 플래너 5기능(순서·리마인드·비교기준·시세판단·결정보조)으로 댓글 시연 → 핀. 아모라 데일리 프롬프트는 자동 발행이라 검수만.
- **모더레이션 15분**: 신규 입력 이상치/스팸 검수(기존 신고 라우트). 텍스트 입력이라 OCR 검수 부담 없음.
- **큐레이션 15분**: 운영자 핀 1~2개, 주 1회 "아모라 시세 브리핑"(AI 표기).
- **유입 노동 10분**: 지식iN 결혼 카테고리 전문가답변 1건(실명/AI 표기), 하단 도구 링크.

**가짜 없는 콜드스타트 첫 100명**:
1. **단일 코호트 100% 집중** — *서울/경기 2026 가을본식* 한 곳을 원자 네트워크로. 전체 게시판 살리려 하지 말 것.
2. **빈 금고 방어** — 유저 0명이어도 봉투/분포는 공개 시세 벤치마크(시세DB+숨은비용48, 출처표기)로 항상 내용물. give-to-get은 "여는 전제"가 아니라 "정밀도 보너스".
3. **운영자 Wizard-of-Oz** — 인기 지역 1~2곳에 받은 견적 **30건**(영수증 100건 아님) 출처표기 손입력. 합법(실제 노동).
4. **합법 유입만** — 다이렉트결혼준비 카페·지식iN에 운영자 실명 정직글로 시드 분포 스크린샷 미끼. 봇/가짜유저/자작Q&A 전면 금지.
5. **30일 KPI 실측** — 손노동 채널 전환율을 주 단위로. "만들면 오겠지" 방지(그로스 투자자 심사 핵심 경고).

## 5. 시장성

**구조적 우위 (카페·웨딩북 복제 불가)**:
- 네이버 카페(다이렉트 70만): 시간순 텍스트 피드라 가격이 글마다 흩어져 **집계·분포가 구조적으로 불가능**. 제휴 플래너 130만원 수익모델이라 실시세 투명 공개는 자기 수익과 정면 충돌.
- 웨딩북: 업체 광고가 매출 → 실거래 분포를 까면 광고주 이탈(이해상충). D-day 또래 네트워크 없음.
- 웨딩한방만: 미션이 "거래 신뢰 인프라"(P1 Trust>매출)라 **실거래 투명성이 곧 제품**. (a)같은 백엔드 라운지 D-day + (b)31개 도구 아모라 즉답 + (c)코호트 구조를 한 화면에 합칠 수 있는 유일한 곳.

**6개월 후 (유저 수보다 "무엇이 쌓였나")**:
- 인기 지역×카테고리 수십 개의 실거래 시세 분포(표본 5건+) → SEO/입소문 복리 자산.
- 색인된 프로그래매틱 SEO 페이지 50~수백 개 → 매일 새 신부 유입.
- 단일 코호트가 "꽉 찬 방"으로 검증 → 복제 가능한 코호트 형성 레시피.
- `decision_nodes`에 누적된 결정 기록 → 모멘트 루프가 작동하는 관계 데이터. **경쟁사가 카피 못 하는 건 유저 수가 아니라 데이터·관계·시간이 엮인 해자.**

## 6. 버릴 것 / 하지 말 것

- **영수증 vision 자동 파싱을 30일에 넣지 말 것** — 법적·검수 부담이 1인 일일예산을 깸. 텍스트 견적으로 충분.
- **"수천 페이지" 양산 금지** — 신뢰도 누적 전 양산은 스팸 시그널. 50페이지로 시작.
- **0답 선배 라우팅·선배 배지 금지(지금)** — 선배 0명. 아모라 즉답만으로 0답 박멸.
- **비로그인 전체 블러 금지** — SEO 자해. 분포 요약은 공개, 개별·내 위치만 블러.
- **전체 게시판 활성화 시도 금지** — 단일 코호트에만 집중.
- **SEO를 "유입 전략"이라 부르지 말 것** — 색인 3~6개월. 100명까지는 100% 손노동, SEO는 "100명 이후 복리 자산".
- **가짜유저/봇/AI페르소나 위장 영구 금지**.

## 7. 다음 7일 첫 3가지 액션

1. **죽은 코드 2종 부활 (1~2일)**: `AiCommentBox`를 글 상세에 렌더 배선 + AI 코멘트 트리거를 가격글 카테고리로 확장(1줄). `buildChatHref()`에 `post.content`+`cost_data` 주입. **신규 유입 0명이어도 즉시 가치 — 이미 만든 자산을 켜는 일.**
2. **단일 코호트 선정 + 빈 금고 폴백 설계 (2~3일)**: *서울/경기 2026 가을본식* 확정. 공개 시세 벤치마크 폴백 먼저 구현(유저 0명이어도 내용물). 운영자 받은 견적 30건 손입력 시작.
3. **합법 유입 채널 실측 개시 (병행)**: 지식iN 전문가답변 등록 + 다이렉트 카페에 운영자 정직글 1개, 가입 전환 추적 시작. **이 손노동 전환율을 7일 내 첫 데이터로 잡는 게 전체 모델의 생사 분기점.**
