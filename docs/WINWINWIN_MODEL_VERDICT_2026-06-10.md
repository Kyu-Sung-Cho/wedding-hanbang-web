## 1. 가장 중요한 보정 (모델설계·회의론 공통 결론)

**"플래너 수수료 절감"이 아니라 "추가금 보증을 파는 에스크로 마켓플레이스"로 재정의해야 성립한다.**

- 절감 재원은 기본가 속 커미션이 아니라 **추가금 불확실성 제거**다. 소비자 인하 메커니즘 = 기본가 할인이 아니라 **추가금 41항목 사전 확정·캡**.
- 5%는 "중개비"가 아니라 **에스크로 + 표준약관 위약·환급 자동 적용 + "계약서에 없는 추가금은 플랫폼이 차액 보상" 보증의 보험료**. 이래야 소비자·업체가 플랫폼 내 결제를 *원해서* 하고, 탈중개가 막힌다.
- 슬로건 전환: "더 싸게"(다이렉트가 선점, 볼륨에서 짐) → **"추가금이 안 무서운 결혼 준비"**.

## 3. 실패 메커니즘 3개 (회의론)

1. **채널 보복** — 가설이 아니라 기록된 사실: 웨딩북이 가격 공개만 했는데 상위 컨설팅사들이 제휴업체에 거래 중단 압박(2018 공정위 신고, 서울경제 2019-05-25). 대응: 컨설팅 의존도 낮은 신규·비주류 업체 + 워크인이 원래 유리한 혼수(한복·예복·예물)를 1차 카테고리로, 플랫폼 전용 구성으로 직접 가격 비교 차단.
2. **탈중개** — 웨딩은 일생 1회라 누수 압력 최상급(플랫폼 누수 매출 30~80% 손실 사례). The Knot이 수수료를 포기한 이유. 대응: 감시가 아니라 플랫폼 내 결제가 이득인 구조(보증·에스크로·검증 배지·시세 데이터는 플랫폼 내 계약에만).
3. **1인 운영 + 법적 책임** — 결제 관여 시 전자상거래법 §20조의3 대행이행 책임, 정산 관여 시 PG 등록(자본금 3억, 미등록 형사처벌). 대응: 외부 PG 정산대행 구조(소비자→PG→업체 직정산) + 표준약관 기준 분쟁 자동화. 수백만원대 분쟁 중재가 1인 일일예산에 들어오는지가 미해결 과제.

## 4. 수수료 구조 확정안 (성립 시)

- 업체만 과금, 소비자 무료. **계약 성사 시에만**(에스크로 결제 완료 기준) — 리드비·견적발송비 금지(숨고식 불만+P1 충돌), 광고·상단노출 금지(구 전략의 `featured` 컬럼·프리미엄 노출 폐기).
- **단일 5%, 전 업체 동일, 공개.** PG ~3%는 업체 부담 분리 명시. 첫 12개월 0% 파일럿.
- 현실 1차 마일스톤: 건당 평균 400만 계약 × 5% = 20만원/건, 월 5건 = 월 100만원 (구 전략의 "월 300만"은 무근거 가정).
- **중립성 방화벽**: ①가격 통계는 입점 여부를 쿼리 레벨에서 못 읽게 절연 ②입점 업체 불리 데이터도 동일 노출(못 견디면 입점 거절 = P4 필터) ③"수수료 계약 업체" 라벨 상시(표시광고법 의무) ④업체 공시가는 `vendor_submitted` 별도 등급, 소비자 제보 통계와 혼합 집계 금지 — "공시가 200 / 제보 중위 230" 병렬 표기, 괴리 자체가 신뢰 신호 ⑤입점 계약서에 "통계 수정·삭제 요구 불가" 조항.

## 5. H4: 정확한 정보 제공 설계 (즉시 실행 가능)

**판정 재정의**: "정확한 견적 하나"는 불가능, **"조건 명시된 분포 + 비교 가능성의 정직한 선언"은 가능** — 후자가 소비자에게 실제 필요한 정보.

**견적 폼 최소 필드** (현재 스키마에 booking_channel이 없음 — **스키마 변경이 그로스보다 먼저**, 채널 미상 데이터는 소급 불가 오염):
```
booking_channel*: 워크인 | 플래너 동행/소개 | 대행사 패키지 | 플랫폼 | 모름
quote_stage*: 견적만 | 계약 완료
contract_ym*, wedding_ym, region*, vendor_category*, quote_price_manwon*
included_item_ids*: 41항목 체크(hiddenCosts 온톨로지)
planner_fee_manwon(선택), evidence_upload(선택→등급 상승)
```

**검증 등급**: L1 자가신고 / L2 견적서 인증 / L3 계약 인증(운영자 검수). 합산하되 분리 표기("12건 중 인증 5건").

**절대 금지**: 단일 평균 단정 / n<5 셀 수치화(코드 상수로 차단) / 구성 미통제 비교("플래너가 싸요" 단정 — 방향까지 틀릴 수 있음) / 업체 우열 단정 / 출처·시점 없는 수치 (현재 `hiddenCosts.ts`가 출처 연도 없음 — 즉시 보수).

**표기 문안 예**: "2026년 2분기 서울·스튜디오·워크인·계약 완료 **7건** 기준: 중위 180만원(범위 150~230만), 이 중 견적서 인증 3건." / 미달 시: "이 조건 제보가 2건이라 분포를 말씀드릴 수 없어요. 참고로 참가격 2025-04 조사 기준 전국 중간 290만원입니다."
